\section{The whole original family at its actual short outer run}

An empty step after $H$ lies before the actual assignment head of every
outer run shorter than the remaining suffix $S$. The selected companion
therefore receives an INITIAL boundary entry, rather than a future entry of
its own lower history. The entire specific-family initial-boundary producer

This is the ordered-boundary adaptation of the general step in
\cite{wlodarczyk05-hironaka,bierstone-milman08-functoriality}.

\begin{lemma}[Both actual original short order splits]
\label{hir:original-general-actual-short-splits}
\source{wlodarczyk05-hironaka,bierstone-milman08-functoriality}
\uses{hir:original-interior-empty-order-regime-run,hir:original-interior-empty-history}
\lean{Hironaka.HironakaOriginalOuterShortFamily.actual_general_short_splits}
\leanok
Let $M$ be originally well formed, let $H$ be its actual test head, and put
$r=\operatorname{regimeRun}(\operatorname{OrdRegime}(M,o),HS,y)$.
If $r<|S|$, the corresponding original run on $H\epsilon S$ is exactly $r$.
Both entire computed splits have the SAME actual stage and tail
$Q=\operatorname{tail}(S,r)$, with heads $H\operatorname{head}(S,r)$ and
$H\epsilon\operatorname{head}(S,r)$. The selected prefix has positive length.
\end{lemma}
\begin{proof}
The genuine whole original order-regime run dictionary is obtained from the
actual geometric cosupport and order dictionaries at every prefix. Its
short branch is literally $r$, so the new computed run is $r$. The actual
split-of-append identity at $r\leq |S|$ identifies both entire dependent split
records with the stated heads and common tail. The true selected prefix
length is $|S|-r>0$, so no prefix nonemptiness hypothesis is supplied.
\end{proof}

\begin{lemma}[Whole selected original short companion and actual tail]

\begin{proof}

actual masks identifies both entire restrictions of the SAME original $Q$.
No mask, record, lower-history or value equality is a caller premise.
\end{proof}

\begin{theorem}[Entire actual original family value on the short outer branch]
\label{hir:original-general-entire-short-family-value}
\source{wlodarczyk05-hironaka,bierstone-milman08-functoriality}
\uses{hir:original-general-short-whole-companion-diagram,hir:original-invariant-empty-actual,hir:original-interior-empty-full-family-monomial-leaf}
\lean{Hironaka.HironakaOriginalOuterShortFamily.actual_entire_outer_short_family_value}
\leanok
For every original successor depth $k+1$, original well-formed $M$, actual test
head $H$ and actual point $y$ with TRUE own-order outer run shorter than $|S|$,
\[
 R_{k+1}(M,H\epsilon S,y)
  =\operatorname{shiftFamily}(k+1,|M.E|+|H|)
      (R_{k+1}(M,HS,y)).
\]
No canonical new-history, arbitrary invariant transport, lower-order or
positive-companion restriction is supplied.
\end{theorem}
\begin{proof}
The short-run condition implies $S$ is nonempty. At actual nonmonomial order
zero, the genuine whole original monomial-leaf producer supplies the stated
family shift directly, with the actual insertion index. At positive outer
order, both actual whole splits from the preceding lemmas retain the SAME
original tail, and the whole new companion is the true initial-boundary
insertion in the old companion. The complete specific-family initial-boundary
identity for Step One follows from its genuine actual level, specialness and
run dictionaries. On the nonspecial branch, each true lower mask is equal and
each whole lower record receives its internally computed initial insertion
index. The complete actual lower family insertion theorem applies at every
recursive order. Its actual empty-prefix dictionary identifies this index
with zero on these true lower family values. This treats both genuine contact
choice at level zero and positive-member lower data, including missing-mask
infinity; no desired lower comparison is assumed. Thus the ENTIRE new companion
Step One value is the old one under
$\operatorname{pairShift}(\operatorname{shiftFamily}(k,0))$.
The whole order mask equality handles both the present and absent mask cases
of the general value. Its actual outer order is unchanged. Expanding the two
entire original general values therefore gives exactly the defining successor
family shift at $j$, which has the just-proved inner map. The proof keeps the
actual original $M,H,S$ rather than rebasing the statement.
\end{proof}
