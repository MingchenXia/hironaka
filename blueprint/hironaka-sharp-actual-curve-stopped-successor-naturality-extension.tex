\section{Actual stopped terminal maps commute with the genuine global successors}

\begin{lemma}[The genuine local successor preserves the same stopped terminal point]
\label{hir:sharp-actual-curve-stopped-prefix-successor-square}
\uses{hir:sharp-actual-curve-stopped-prefix-terminal-biholomorphism,hir:sharp-actual-stagewise-tower-comparison-unique,hir:sharp-actual-curve-uniform-successor-data}
\lean{Hironaka.HironakaSharpActualCurveStoppedSuccessorNaturality.stoppedPrefix_successor_square}
\leanok
Once a genuine finite history has stopped, its SAME constructed terminal
identifications at stages $k$ and $k+1$ intertwine its SAME actual local
successor map, on EVERY point. All actual empty padding positions remain
true blowup constructors; no terminal-map square is assumed.
\end{lemma}
\begin{proof}
Use the genuine full-history isomorphism of the actual uniform prefix at
$k+1$ with the original history followed by its true identity-empty tail.
Since the original literal length is at most $k$, the actual next padding
length equals the preceding padding length plus one. Normalize only this
true natural-number equality in the ENTIRE fixed full-history assertion.
The actual successor constructor equality exposes the true source last
step, and the target last step is the genuine identity-empty blowup.

Actual step inversion gives a full comparison of the two preceding
histories and the exact last-arrow square. The independently constructed
stopped terminal identification at $k$ is a comparison of exactly these
SAME full preceding histories over the same base. Genuine finite-history
universal uniqueness therefore identifies its map with the predecessor
map just obtained. In the last-arrow square the target arrow is literally
identity. Substituting the proved predecessor equality gives the asserted
point identity on EVERY actual source point. No uniqueness of arbitrary
maps over the original projection is used.
\end{proof}

\begin{theorem}[The actual stopped-open biholomorphisms commute with the same global successor]
\label{hir:sharp-actual-curve-stopped-open-successor-square}
\uses{hir:sharp-actual-curve-stopped-prefix-successor-square,hir:sharp-actual-curve-stopped-open-global-biholomorphism,hir:sharp-actual-curve-global-successor-quotient-map}
\lean{Hironaka.HironakaSharpActualCurveStoppedSuccessorNaturality.stoppedOpen_successor_square}
\leanok
On the ENTIRE actual successor-stage projection preimage of $U_k$, the
stopped terminal identification at $k+1$ equals the identification at $k$
after the SAME actual global successor. The actual original projection
identity supplies its domain in $U_k$, and monotonicity supplies its
domain in $U_{k+1}$. No global comparison or compatibility certificate is
an input.
\end{theorem}
\begin{proof}
An arbitrary point of this entire preimage has its original projection in
an actual chart with literal full length at most $k$, by the definition of
$U_k$. The whole saturated range dictionary gives an actual representative
in this chart at stage $k+1$. The exact previously constructed global
successor local formula identifies its image with the inclusion of the
SAME actual local successor image at stage $k$. The original projection
square and monotonicity independently supply both genuine stopped-open
subtype points.

Apply the exact stopped-open local formula at each stage to these actual
representatives. Both formulas use the SAME original terminal inclusion
and the SAME actual local history. The preceding local successor lemma
identifies their stopped terminal points. Applying that genuine terminal
inclusion and composing the exact local formulas proves the asserted
ENTIRE global square. Representation choices are irrelevant by the
already proved quotient independence, rather than an extra input.
\end{proof}

\begin{corollary}[Only original curve data supply the local stationary terminal history square]

positive ambient dimension internally give these squares over every
original point's actual chart at each stage equal to its literal local
history length plus any natural number. No input atlas, local history,

\end{corollary}
\begin{proof}

the stopped charts by the literal length inequality. Every successor

forming either stopped-open subtype point. Apply the preceding genuine
global square to the internally supplied atlas, actual stage and SAME
already constructed maps. This supplies compatibility of the local
stationary terminal identifications with the genuine global blowup
history, without any infinite maximum or deletion of original steps.
\end{proof}
