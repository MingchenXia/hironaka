\begin{lemma}[Actual transverse boundary coordinates genuinely exclude second-order vanishing on the same carrier]
\label{hir:sharp-actual-transverse-boundary-coordinate-not-second-order}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-actual-finite-relative-product-geometry-order-sum,hir:sharp-original-member-product-actual-normal-form}
\lean{Hironaka.HironakaSharpActualFirstGoodExceptionalTraceDensity.exists_actual_transverse_member_not_second_order}
\leanok
At each actual incident member of an SNC boundary transverse to an actual
closed smooth carrier $N$, construct a genuine holomorphic function in
THAT member's actual vanishing ideal whose restriction to $N$ does not
vanish to order two at the point. No derivative, order or coordinate
certificate is supplied.
\end{lemma}
\begin{proof}
The real simultaneous carrier/SNC flattening supplies an actual free
coordinate for this incident member whose index lies within the true
carrier plane. Actual hypersurface Hadamard division makes that coordinate
a genuine member of the ORIGINAL boundary ideal. Its actual first point
power and next-power exclusion follow from the genuine one-coordinate
monomial order theorem. The actual flattened carrier retraction fixes
this coordinate near the original point. If it vanished to order two on
$N$, true retraction transport would put the same original coordinate
in the second ambient point-ideal power, contradicting that next-power
exclusion. All maps are used only on their true chart neighborhoods.
\end{proof}

\begin{lemma}[Actual no-factor and reduced order one force genuine exceptional noncontainment]
\label{hir:sharp-actual-order-one-no-factor-exceptional-noncontainment}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-actual-transverse-boundary-coordinate-not-second-order,hir:sharp-actual-relative-principal-order-one-reduced-trace,hir:sharp-original-all-member-finite-chronological-no-exceptional-factor}
\lean{Hironaka.HironakaSharpActualFirstGoodExceptionalTraceDensity.actual_orderOne_no_factor_trace_outside_member}
\leanok
For a genuine coherent nonzero relatively principal ideal $I$ on the same
smooth carrier $N$, at a real point of its literal trace $S=N\cap V(I)$
with actual order one, suppose the actual no-common-member-factor witness
is known for an incident member of the TRUE transverse SNC boundary.
Then EVERY ambient neighborhood of the point contains a point of this
SAME trace outside that actual member. Nonincident members satisfy the
same conclusion directly. No noncontainment, trace transversality or
density certificate is assumed.
\end{lemma}
\begin{proof}
Construct BOTH actual reduced-ideal directions for $I$ from genuine
order-one contact. Suppose the literal trace lay in the boundary member
on some true ambient neighborhood. The preceding actual boundary
coordinate would then vanish on that literal trace and so belong to $I$.
Express it as a holomorphic cofactor times the genuine relative generator
of $I$ on $N$. This generator vanishes at the point. If the cofactor
vanished there too, the boundary coordinate would vanish to order two on
$N$, contradicting its independently constructed exclusion. Thus the
cofactor is a genuine unit. Its holomorphic inverse expresses the true
relative generator of $I$ as a multiple of an ACTUAL boundary-ideal
member. Substitution puts EVERY germ of $I$ in the actual boundary ideal's
relative span, contradicting the genuine no-factor witness. Negating
neighborhood containment gives the required actual frequent trace points.
For a nonincident boundary member, the chosen trace point itself lies
outside it and belongs to every neighborhood used for the frequency
criterion.
\end{proof}

\begin{theorem}[ONLY original inputs construct whole accumulated-boundary density on every actual FIRST-good lower trace]

\lean{Hironaka.HironakaSharpActualFirstGoodExceptionalTraceDensity.exists_original_first_good_exceptional_trace_density}
\leanok
ONLY original smooth positive pure carrier, true original SNC boundary,
whole-original-boundary density and a genuine finite template history

\end{theorem}
\begin{proof}
The genuine original reduced-trace theorem constructs the actual open and
each closed smooth lower carrier. Real finite template wellformedness

carrier. Original chronological geometry independently gives each SAME
member ideal's coherence, nonzero and relative generators. At every
FIRST-good trace point true factor rigidity constructs order one, and

position. The genuine open-embedding neighborhood filter identity carries
these frequent actual trace points to the SAME open lower carrier.
True pullback of SNC coordinate data proves the boundary remains SNC.

Finally finite closed-family avoidance is proved topologically. In any
true open neighborhood of a lower-carrier point, first choose a point
outside the first closed member by the constructed frequency. Its
intersection with that member's open complement is still an actual open
neighborhood of the chosen point. Apply induction to the remaining finite
closed list inside this smaller neighborhood. The resulting point lies
outside EVERY member while staying in the original lower carrier and

dense. Empty and empty-position boundaries are included. This does not
assert lower-carrier transversality or simultaneous SNC, FIRST Z equals
Sigma, higher original invariant descent, a sharp recursive driver,
exceptional tauD or termination.
\end{proof}
