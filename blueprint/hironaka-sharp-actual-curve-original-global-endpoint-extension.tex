\begin{theorem}[Every actual global projection fibre is genuinely nonempty]
\label{hir:sharp-actual-global-projection-surjective}
\uses{ana:blowup-surjective,hir:sharp-actual-original-endpoint-comparison-atlas,hir:sharp-actual-original-global-complex-endpoint}
\lean{Hironaka.HironakaSharpActualCurveOriginalGlobalEndpoint.gluedProjection_surjective,Hironaka.HironakaSharpActualCurveOriginalGlobalEndpoint.originalEndpointProjection_surjective}
\leanok
For a genuine actual endpoint-history family covering its base, the
SAME constructed global projection is surjective. In particular this
holds from ONLY the original curve/SNC/density data, without a caller
fibre, base-surjectivity or source-nonemptiness certificate.
\end{theorem}
\begin{proof}
Given an actual base point $x$, choose a genuine covering base open
containing it. Its original prefix and literal tail give a real finite
blowup tower. Apply the existing genuine blowup-sequence surjectivity
theorem to THIS tower at the actual subtype point over $x$. The result
is an actual endpoint $z$ of that same finite local tower, mapping to
that subtype point. Include $z$ through the actual global chart
inclusion. The already proved full projection square gives its global
image exactly $x$. No exceptional-set equality or fabricated fibre
point is used. Empty steps are literal blowups and remain in the tower.
The original-only consumer supplies its actual history family and true
cover internally.
\end{proof}

\begin{theorem}[The whole conventional strict curve maps onto the whole original curve]
\label{hir:sharp-actual-original-global-strict-image-equality}
\uses{hir:sharp-actual-original-global-projection-proper,hir:sharp-actual-original-global-good-isomorphism,hir:sharp-actual-original-global-curve-strict-closure,hir:sharp-original-multiboundary-defect-boundary-support}
\lean{Hironaka.HironakaSharpActualCurveOriginalGlobalEndpoint.image_conventionalStrictCurve_eq_original,Hironaka.HironakaSharpActualCurveOriginalGlobalEndpoint.image_gluedStrictCurve_eq_original}
\leanok
For ONLY the original positive ambient dimension, closed smooth pure
curve, actual ordered SNC boundary and genuine boundary-complement
density, the image of the EXISTING conventional strict transform under
the SAME actual global proper holomorphic projection is exactly the
ENTIRE original curve. The SAME independently glued strict curve has
that image too. There is no assumed density of an exceptional complement
on the transformed curve and no source fibre/lift supplied.
\end{theorem}
\begin{proof}
Continuity of the actual global projection and closedness of the
original curve put the closure of its nonexceptional inverse image
inside the whole inverse image of that original curve. This proves
one image inclusion directly from the conventional strict definition.
The strict curve is closed by its actual closure definition. The
already proved proper-map closed-image theorem therefore makes its
ENTIRE image closed in the original ambient manifold.

Take an actual original curve point outside the whole original boundary.
The original bad-locus support theorem places every original bad point
inside that boundary; contrapositively this point belongs to the true
original good set. The actual isomorphism-over-good theorem gives a real
preimage point over it, and its separate differential disjointness
assertion makes that point nonexceptional. Thus the point belongs to
the nonexceptional inverse image of the original curve, hence to its
conventional strict closure. This puts every original curve point off
the boundary in the actual strict-curve image.

The supplied ORIGINAL density of this boundary complement and the
already proved closedness of the image now put the ENTIRE original
curve inside that image. Together the two inclusions prove equality.
Finally the independently proved SAME global glued-curve/conventional
strict identity transfers the equality to the actual glued curve.
Neither image membership nor surjectivity of the curve restriction was
assumed. The geometric strict transforms of arbitrary original boundary
members are not silently replaced by conventional strict closures.
\end{proof}
