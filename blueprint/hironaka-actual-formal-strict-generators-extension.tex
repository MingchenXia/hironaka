\section{The genuine source formal strict ideal and its finite normalized vertex generators}

Keep the actual coordinate center $P=(X_i:i\in A)$, index $e\in A$,
true chart $\sigma_b$, and the internally constructed quotients $[F]_d$.
Here we use exactly the formal strict-transform definition in
\cite[\S7, p.~268, followed by Lemma~7.22 and Corollary~7.24]{bierstone-milman97-invent-math}:
for nonzero $F$ its center order is the largest $d$ with $F\in P^d$,

$[F]_{\mu_P(F)}$ for all nonzero $F\in I$. Zero members contribute only zero.
The definition uses the actual original series, true center powers and

\begin{lemma}[The actual coefficient support internally constructs the genuine finite center order]
\label{hir:actual-formal-center-order-from-support}
\uses{hir:actual-formal-coordinate-power-coefficient-kernel}
For every actual nonzero $F$, the genuine nonzero coefficient support has
a least $A$-weight, denoted $\mu_P(F)\in\mathbb N$, and
\[
 F\in P^d\Longleftrightarrow d\le\mu_P(F).
\]
In particular $F\in P^{\mu_P(F)}$ and $F\notin P^{\mu_P(F)+1}$.
For an actual monic vertex series $f_a$ explicitly satisfying
$f_a\in P^{w_a}$, where $w_a=\sum_{i\in A}a_i$, its actual center order
is exactly $w_a$.
\lean{Hironaka.HironakaActualFormalStrictGenerators.actualFormalCenterOrder,Hironaka.HironakaActualFormalStrictGenerators.actualFormalCenterOrder_witness,Hironaka.HironakaActualFormalStrictGenerators.actualFormalCenterOrder_le_weight,Hironaka.HironakaActualFormalStrictGenerators.mem_coordinate_power_iff_le_actualFormalCenterOrder,Hironaka.HironakaActualFormalStrictGenerators.mem_actualFormalCenterOrder_power,Hironaka.HironakaActualFormalStrictGenerators.not_mem_actualFormalCenterOrder_succ_power,Hironaka.HironakaActualFormalStrictGenerators.actualFormalCenterOrder_vertex}
\leanok
\end{lemma}
\begin{proof}
Since $F\ne0$, actual coefficient extensionality supplies a nonzero
coefficient. Its true $A$-weight makes the set of such natural weights
nonempty; natural well ordering supplies a least weight and an actual
nonzero coefficient at that weight. If $F\in P^d$, the genuine whole
coordinate-power kernel forbids this least weight from being less than
$d$. Conversely if $d$ is at most the least weight, every actual
coefficient of $A$-weight less than $d$ is zero; the SAME true whole
power kernel gives $F\in P^d$. Taking $d$ equal to the least weight
and its successor proves the asserted largest-order characterization.
For a monic actual $f_a$, its actual coefficient at $a$ is one, so the
least weight is at most $w_a$. Its explicit genuine power membership
and the just proved characterization give the opposite inequality.
Thus its actual source center order is $w_a$, without assuming it.
\end{proof}

\begin{theorem}[The exact source formal strict ideal equals the whole normalized-original-member ideal]
\label{hir:actual-formal-strict-ideal-normalized-member-identification}
\uses{hir:actual-formal-center-order-from-support,hir:actual-formal-blowup-normalized-member,hir:actual-formal-blowup-whole-normalized-member-ideal}
For an actual ideal $I\subset S$, define its genuine source formal
strict transform $I'_b$ by the actual span of
$[F]_{\mu_P(F)}$ for all actual nonzero $F\in I$.
Then the actual WHOLE ideal $I'_b$ equals the ideal spanned by
$[F]_d$ for EVERY $d\in\mathbb N$ and EVERY actual $F\in I\cap P^d$.
\lean{Hironaka.HironakaActualFormalStrictGenerators.actualNormalizedFormalMember_zero,Hironaka.HironakaActualFormalStrictGenerators.actualNormalizedFormalMember_lower_order,Hironaka.HironakaActualFormalStrictGenerators.actualFormalStrictTransform,Hironaka.HironakaActualFormalStrictGenerators.actualFormalStrictTransform_eq_normalizedOriginalMemberIdeal}
\leanok
\end{theorem}
\begin{proof}
Each source generator belongs to that whole normalized-member ideal,
because $F\in P^{\mu_P(F)}$; this proves one actual span inclusion.
Conversely take ANY actual normalized original member $[F]_d$ with
$F\in I\cap P^d$. If $F=0$, its true exceptional-product identity
and domain cancellation give $[F]_d=0$, hence membership in $I'_b$.
If $F\ne0$, the preceding characterization gives $d\le\mu_P(F)$.
The SAME actual exceptional-product identities give
\[
 X_e^d\bigl(X_e^{\mu_P(F)-d}[F]_{\mu_P(F)}\bigr)=\sigma_b(F)
 =X_e^d[F]_d.
\]
True domain cancellation therefore gives
$[F]_d=X_e^{\mu_P(F)-d}[F]_{\mu_P(F)}$. The second factor is literally
one of the source generators of $I'_b$, so this product belongs to that
actual whole ideal. The actual span property proves the reverse whole
inclusion. No independent analytic saturation equality is part of this
formal source definition or either inclusion.
\end{proof}

\begin{theorem}[Genuine finite source formal strict generators]
\label{hir:actual-formal-strict-ideal-finite-vertex-generators}
\uses{hir:actual-formal-strict-ideal-normalized-member-identification,hir:actual-formal-blowup-normalized-original-member-generation,hir:actual-formal-center-order-from-support}
Let $f_a$ be the internally chosen actual monic vertex series of an
actual ideal $I$ for any monomial order, and explicitly assume only the
actual source power memberships $f_a\in P^{w_a}$.
The genuine source formal strict transform is the actual WHOLE finite ideal
\[
 I'_b=\bigl([f_a]_{w_a}:a\text{ an actual vertex of }I\bigr).
\]
The exponent $w_a$ is the internally proved actual center order of the
SAME $f_a$. For degree-compatible vertices with $w_a=|a|$, these are
precisely the normalized generators in Corollary~7.24.
\lean{Hironaka.HironakaActualFormalStrictGenerators.actualFormalStrictTransform_eq_vertex_span}
\leanok
\end{theorem}
\begin{proof}
The preceding actual source-definition identification proves that $I'_b$
equals the WHOLE normalized-original-member ideal. Genuine whole
coordinate-power division already proves that every actual member of
that ideal is in the finite normalized-vertex span, and that every
actual normalized vertex belongs to the whole member ideal. Thus the
already proved BOTH whole ideal inclusions give the displayed equality.
The least-weight theorem identifies each vertex's genuine source center
order with $w_a$, making these literally the source strict transforms
of those actual vertices. This is a finite strict-generation producer
in the actual formal ring; geometric admissibility supplying the source
vertex memberships, transformed-standard-basis stability, the analytic
all-power-saturation bridge and general Bennett remain subsequent work.
\end{proof}
