\begin{lemma}[Original coherence internally gives one finite HS prefix on an actual compact carrier]
\label{hir:actual-original-compact-whole-hs-uniform-finite-prefix}
\uses{hir:actual-ambient-hs-whole-superlevel-analytic}
\lean{Hironaka.HironakaActualCompactFiniteHSPresentation.exists_actual_compact_whole_hs_uniform_finite_prefix}
\leanok
For ONLY original coherent $A$, actual compact $K$, and ANY original
threshold profile $h$, some actual $N$ satisfies
$\{H_A\ge h\}\cap K=\{H_A(\ell)\ge h(\ell):0\le\ell\le N\}\cap K$.
\end{lemma}
\begin{proof}
At every actual point, the independently proved local whole-HS theorem
internally supplies an actual open neighborhood and finite order giving
BOTH whole/prefix directions on that SAME neighborhood. These original
neighborhoods cover actual compact $K$. Choose a genuine finite subcover
and let $N$ be the actual maximum of its produced finite orders, taking
zero for an empty subcover. Whole membership gives every finite order.
Conversely any $x$ in $K$ satisfying the true $N$ prefix lies in a member
of the finite subcover; the actual prefix family is antitone, so it
satisfies that member's actual earlier prefix. The genuine local equality
therefore gives ALL original orders at $x$. Empty $K$ is retained.
No finite cutoff, cover or equations are caller data.
\end{proof}

\end{proof}
