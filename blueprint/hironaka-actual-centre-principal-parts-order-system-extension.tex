\begin{theorem}[Canonical whole original principal-parts truncations]
\label{hir:actual-centre-principal-parts-whole-order-system}
\uses{hir:actual-centre-joint-original-word-jet,hir:actual-hs-constant-centre-whole-principal-parts}

quotient map $R/(J+N_z^r)\to R/(J+N_z^q)$ is genuinely $B$-linear,
is surjective, and sends EVERY original numerator to its SAME class.
The maps have the identity and exact triple-order composition laws.
\lean{Hironaka.HironakaActualCentrePrincipalPartsOrderSystem.actualPrincipalPartsTruncation,Hironaka.HironakaActualCentrePrincipalPartsOrderSystem.actualPrincipalPartsTruncation_mk,Hironaka.HironakaActualCentrePrincipalPartsOrderSystem.actualPrincipalPartsTruncation_surjective,Hironaka.HironakaActualCentrePrincipalPartsOrderSystem.actualPrincipalPartsTruncation_refl,Hironaka.HironakaActualCentrePrincipalPartsOrderSystem.actualPrincipalPartsTruncation_comp}
\leanok
\end{theorem}
\begin{proof}
The genuine ideal power inclusion $N_z^r\subseteq N_z^q$ gives
$J+N_z^r\subseteq J+N_z^q$. Restrict these SAME original submodules to
the ORIGINAL tangent scalar action. The ordinary quotient factor map
is the asserted $B$-linear map; its value on every original numerator
is literally that numerator's lower class. Every lower class has its
original numerator as an upper preimage, proving surjectivity. For
identity and composition, induct on an arbitrary ENTIRE original upper
quotient class and use that SAME numerator equality. This proves the
laws on the whole module, with no coordinate choices or selected-array
representatives replacing the original quotient.
\end{proof}

\label{hir:actual-centre-principal-parts-whole-split-kernel}
\uses{hir:actual-centre-principal-parts-whole-order-system,hir:actual-centre-whole-principal-parts-finite-free}

\lean{Hironaka.HironakaActualCentrePrincipalPartsOrderSystem.exists_actualPrincipalPartsTruncation_split_kernel}
\leanok
\end{theorem}
\begin{proof}
Use the preceding actual finite-free principal-parts theorem at both
orders, retaining the SAME original whole ideal and scalar action.
The lower quotient is projective, so the genuine surjective original
truncation internally lifts its identity and supplies an actual
$B$-linear right inverse $s$. For the full upper module, the map

of the finite projective upper quotient. The retraction makes it finite,
and the split-module theorem makes it projective. Projective implies

makes the kernel free. No caller right inverse or kernel/freeness
certificate is assumed. A chosen split is asserted only to be $B$-linear;
no derivative or Spencer compatibility is inferred.
\end{proof}
