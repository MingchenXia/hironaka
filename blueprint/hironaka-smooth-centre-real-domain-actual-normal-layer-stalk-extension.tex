For an original ideal $A$ and subset $C$, write $I_A(V)$ and $J_C(V)$
for their entire actual section ideals on a true original open $V$.
The degree-$q$ section layer is defined FIRST as the literal image of
$J_C(V)^q$ in the actual ring $\mathcal O(V)/(I_A(V)+J_C(V)^{q+1})$.
