\section{A fixed actual coefficient contact model for every genuine original test extension}

Retain the SAME original maximal-order marked ideal and ANY of its genuine
test prefixes. One actual point of its current cosupport internally fixes
an original tangent open and function. Keep that choice while comparing
EVERY genuine original extension. This is the geometric coefficient-model
part of \cite[Step I, Cases A and B]{bierstone-milman08-functoriality},
adapted to the actual globally extended test histories rather than a
claim about all local histories which need not extend. It is a concrete
presentation ingredient in the sense discussed at printed page 222 of
\cite{bierstone-milman97-invent-math}.

The actual contact carrier is not assumed transverse to the entire retained
boundary, and the coefficient ideal can vanish identically on a contact
component. Consequently no lower invariant domain is asserted before the
separate member/component selection and nonzero analysis. In particular
this does not silently identify an arbitrary noncanonical prefix with an
earlier frozen canonical lower history.

\begin{theorem}[ONLY original maximal-order domain and test-prefix data construct the actual chosen contact geometry]
\label{hir:original-noncanonical-chosen-contact-geometric-presentation}
\source{bierstone-milman97-invent-math:page-0016}
\uses{hir:step-one-bridge,mc:contact-stage-kept,mc:contact-stage-tail,mc:contact-stage-dimension,mc:contact-stage-domain-masked}
\lean{Hironaka.HironakaOriginalNoncanonicalUniformContactPresentation.exists_original_test_chosen_contact_geometry}
\leanok
Let $M$ be an ORIGINAL maximal-order invariant-domain input of dimension
bound $k+1$, let $T_0$ be ANY actual ORIGINAL test prefix and let $y$ lie
in its current cosupport. These original inputs internally construct the
actual chosen original tangent open $U\ni T_0(y)$ and its chosen tangent
function $w$. Set $V=T_0^{-1}U$ and let $L$ be the actual kept-boundary
coefficient model on the strict transform of $M.N\cap\{w=0\}$, restricted
to $V$. Its carrier is genuinely closed smooth of dimension bound $k$,
its literal coefficient ideal is coherent, its mark is positive, and its
ENTIRE ordered boundary equals the actual current ORIGINAL boundary
restricted to $V$. Its cosupport is EXACTLY the trace on $V$ of the SAME
original current cosupport. No tangent/open/model/geometry/coherence/test
or cosupport dictionary certificate is supplied. Canonicality is absent.
\end{theorem}
\begin{proof}
Genuine homogenized coefficient equivalence internally carries the given
ORIGINAL test prefix to the actual homogenized coefficient test prefix,
with equal current cosupports. Thus the given actual point is a real
point of that actual coefficient cosupport. Original maximal order and
coherent smooth geometry produce a tangent direction at its actual
original projected point. Apply the actual fixed tangent choice only
AFTER that existence proof; it supplies the real open, point membership
and genuine tangent function.

Actual maximal-contact strict-transform geometry gives the true closed
smooth contact carrier on $V$. Its dimension bound drops from $k+1$ to
$k$ by the genuine contact hyperplane dimension theorem, not by an input
rank certificate. Coherence of the actual coefficient ideal at the stage,
followed by true open pullback, gives coherence of the literal model ideal.
The actual coefficient mark is positive. Coefficient formation and carrier
replacement keep the boundary; original and homogenized coefficient
records started with the SAME list, so their actual strict-boundary
recursions give equality of the ENTIRE ordered lists before restriction.
No position or empty member is deleted.

Use the genuine stage contact-tail theorem with the reflexive future
extension. Actual Giraud cosupport containment in the strict contact
carrier is proved for all actual original extensions, and the real
coefficient restriction theorem supplies BOTH cosupport directions.
Transfer through the already proved original/homogenized coefficient
cosupport equality. This gives precisely the asserted current trace
identity, so the chosen original point really lies in the model trace.
It does not supply nonzero restriction on every contact component or
transversality to every retained member.
\end{proof}

\begin{theorem}[ONE internally chosen original contact model works for EVERY genuine noncanonical original extension]
\label{hir:original-noncanonical-uniform-contact-test-presentation}
\source{bierstone-milman97-invent-math:page-0016}
\uses{hir:original-noncanonical-chosen-contact-geometric-presentation,mc:contact-stage-tail,mc:contact-stage-kept,hir:step-one-bridge}
\lean{Hironaka.HironakaOriginalNoncanonicalUniformContactPresentation.exists_original_test_uniform_contact_presentation}
\leanok
For ONLY the preceding original inputs, ONE such actual $U,w,L$ also has
the following property: for EVERY genuine ORIGINAL extension $T_0Q$,
the SAME actual restricted future tower $Q|_V$ is a genuine test history
of this fixed coefficient model $L$, and its actual transformed cosupport
is EXACTLY the trace of the SAME ORIGINAL cosupport after $T_0Q$.
The original prefix and extension need not be canonical. No choice of a
model depending on $Q$, desired model test, overlap or transformed
cosupport certificate is supplied.
\end{theorem}
\begin{proof}
Keep the actual open and tangent function already constructed from the
original prefix point; they are chosen BEFORE the future tower is given.
Let an arbitrary genuine ORIGINAL extension $T_0Q$ be given. The actual
homogenized coefficient equivalence internally supplies its genuine
coefficient test history and equal cosupport, preserving the SAME maps
and every original position. Apply the proved contact-stage tail theorem
to THESE actual data, with the already fixed $U,w$ and $V=T_0^{-1}U$.
Its Giraud argument supplies actual cosupport containment on the genuine
strict contact carrier at every future position. The real relative
coefficient restriction theorem therefore constructs model-centre
admissibility and the SAME restricted tower test internally, and gives
BOTH whole cosupport directions. Substitute the independently proved
original/coefficient cosupport equality. All actual future maps,
restrictions and ordered boundary positions remain unchanged.

The conclusion quantifies over genuinely extended ORIGINAL histories;
it does not claim that every tower over the local open extends globally,
or infer an unrestricted local test-equivalence from that false premise.
Lower-domain nonzero and boundary-transversality selection, comparison
with earlier frozen full ORIGINAL lower histories, complete noncanonical
recursive presentation equivalence, exceptional/infinitesimal semicoherence,
invariant decrease and general termination remain separate producers.
\end{proof}
