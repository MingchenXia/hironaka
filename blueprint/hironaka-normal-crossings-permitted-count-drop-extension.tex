\begin{lemma}[Every actual empty history preserves the intrinsic old count]
\label{hir:nc-actual-empty-history-intrinsic-count}
\lean{Hironaka.HironakaNormalCrossingsPermittedCountDrop.branchMultiplicity_empty_tower}
\leanok
For an actual empty-centre tower and an original NC carrier, the intrinsic
count of its literal current strict carrier equals the original count at
the actual projection. Any proof of that current carrier's NC property
computes this same count.
\uses{hir:nc-boundary-adapted-actual-empty-tower,hir:general-nc-biholomorphic-intrinsic-multiplicity}
\end{lemma}
\begin{proof}
The accepted genuine empty-history projection theorem internally supplies
its actual whole projection as a biholomorphism. The strict transform of an
original closed set along an empty tower is its actual projection preimage:
prove this by actual tower induction, using empty-centre subtraction and
closedness of the successive whole preimages. Thus actual biholomorphic
intrinsic-count transport applies to precisely the original and literal
current carrier. Carrier-set equality and proof irrelevance identify every
chosen current NC proof with this same genuine count. No count-preservation
certificate or chosen biholomorphism is supplied.
\end{proof}

\begin{theorem}[Only original data supply the actual global old high-cut control]
\label{hir:nc-original-phase-global-old-high-cut-control}
\lean{Hironaka.HironakaNormalCrossingsPermittedCountDrop.exists_original_phase_high_cut_control}
\leanok
Only the original coherent positive-mark compact-cosupport ideal and genuine
joint old-NC/retained-boundary data with positive highest bound $r$ are inputs.
They internally supply one actual finite original test phase, terminality of
this whole coefficient object $L$ and strict-$Z$ clearance, and a GLOBAL
adapted current old/born pair, with
\[
 \{y:r\le\operatorname{mult}_{H_T}(y)\}\subseteq\operatorname{strict}_T Z.
\]
No desired phase, current high-cut equality or history certificate is assumed.
\uses{hir:nc-original-coefficient-phase-global-old-born-carrier,hir:nc-old-block-current-high-subset-strict-original-high,hir:nc-actual-empty-history-intrinsic-count,hir:nc-highest-joint-retained-boundary-histories}
\end{theorem}
\begin{proof}
Internally construct the actual whole phase with its global current pair.
At a current high point mapping to original $Z$, construct genuine joint
branches on an actual original neighbourhood. They form the actual augmented
local test history retaining the entire boundary. Apply the true old-block
superlevel control to this same restricted history. Exact finite-union
strict-transform and open restriction identify its current old carrier with
the trace of the global current carrier. Actual intrinsic open transport
identifies the initial old count with the original old count, hence its
initial $r$-cut is exactly the literal trace of $Z$. Its produced strict-cut
membership is therefore membership in the global literal strict $Z$.

If instead the original image is outside $Z$, restrict to its genuine open
complement. All actual centres lie above $Z$, so this SAME restricted history
is empty. The preceding actual empty-history count identity and intrinsic
open transport identify the current old count with the original count at
that image. Being outside $Z$ makes it strictly below $r$, contradicting a
current high point. These two cases prove the whole stated inclusion, with
no branch labelling inferred from incidence or value certificate.
\end{proof}

\begin{theorem}[The same actual phase genuinely lowers the old count on a neighbourhood of its whole current cosupport]
\label{hir:nc-original-phase-whole-cosupport-count-drop}
\lean{Hironaka.HironakaNormalCrossingsPermittedCountDrop.exists_original_phase_permitted_count_drop}
\leanok
The same original-only inputs produce one actual phase and an actual open
$U$ containing its ENTIRE current original controlled cosupport. The literal
current old carrier on $U$ is adapted to the entire current boundary trace
and its old branch multiplicity is at most $r-1$ throughout $U$.
\uses{hir:nc-original-phase-global-old-high-cut-control}
\end{theorem}
\begin{proof}
Use the actual phase just constructed and take the true open complement
$U$ of its closed literal strict $Z$. Whole original cosupport clearance
places every current permitted point in $U$. The proved current high-cut
inclusion implies every point of $U$ has old count strictly below $r$.
Actual intrinsic open transport therefore gives the bound $r-1$ on this
SAME genuine open and preserves the whole boundary-adapted pair. No point
outside the permitted neighbourhood is repaired. Extending the next real
history on this open to the original ambient space and performing the
finite iteration remain separate obligations; no general G9 closure is
claimed from this one true count drop.
\end{proof}
