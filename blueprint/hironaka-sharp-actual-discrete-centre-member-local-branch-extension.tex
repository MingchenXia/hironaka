\section{Genuine local member branches for an actual discrete blowup centre}

An actual global discrete centre can contain both points on an original
member and points away from it. It is incorrect to assume that the entire
centre lies in every original member. Resolve these genuine local branches
and retain the true ambient strict traces of
\cite[Remark~12.6, pp.~293--295]{bierstone-milman97-invent-math}.

\begin{lemma}[Actual zero-dimensional centre geometry constructs both real local incidence branches]
\label{hir:sharp-actual-discrete-centre-member-source-open-branches}
\uses{hir:sharp-actual-curve-strict-projection-local-inverse}
\lean{Hironaka.HironakaSharpActualDiscreteCentreMemberLocalBranch.exists_actual_discrete_centre_member_open_branch}
\leanok
Let $C$ be genuinely regular of dimension zero at each of its actual
points and let $H$ be actually closed. For EVERY $p\in C$, an actual
source open $U\ni p$ is internally constructed such that its centre trace
is precisely the singleton $p$. If $p\in H$, this true centre trace is
contained in the actual $H$ trace. If $p\notin H$, that entire $H$ trace
is empty. No selected open, local branch or centre-containment certificate
is input.
\end{lemma}
\begin{proof}
True zero-dimensional regularity gives an actual isolating neighborhood
of $p$ in $C$. If $p\in H$, retain that neighborhood; its actual centre
trace is the point $p$ and hence lies in $H$. If $p\notin H$, intersect
it with the genuine open complement of $H$. It still contains $p$,
still isolates the actual centre, and now misses the entire member.
Both singleton directions follow from genuine point membership.
\end{proof}
