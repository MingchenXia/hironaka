\section{Actual remainder test towers on the selected-component complement}
The original contact tail is a true test tower of the enlarged contact model.
Its original centres can meet components removed from the remainder. Passing
to the actual complement of the selected component union removes precisely
this obstruction and retains the entire remaining carrier. The resulting
maps are the actual open restrictions of the original maps. On this open,
historical boundary members may remain nonempty outside the carrier. Entire
ordered marked-record equality with the original contact model is therefore
asserted only on the original mask, where these members really miss every point.

\begin{definition}[The actual selected-component complement]
\label{hir:zero-contact-remainder-actual-open}

\end{definition}

\begin{theorem}[The actual original restriction is a genuine remainder test tower]
\label{hir:zero-contact-remainder-restricted-test-tower}
\leanok
\lean{Hironaka.HironakaStepOneZeroContactRemainderTestTower.remainder_restricted_isGeoTestTower}
\uses{hir:zero-contact-remainder-actual-open,hir:zero-contact-remainder-open-ideal-dictionary,hir:zero-contact-remainder-all-literal-clipped-centres}
For actual closed smooth $L.N$, coherent $L.ideal$, $k\leq\#L.E$ and a genuine
parent test tower $T$, the SAME original tower restricted to $G$ is a genuine
test tower of the actual remainder restricted to $G$. At every literal prefix,
its entire carrier, ideal and mark equal those of the full parent transform
restricted to the corresponding inverse image of $G$. Its boundary is its own
actual ordered boundary, with $k$ empty historical entries and real exceptions.
Its WHOLE marked record equals the actual ambient remainder transform restricted
to that inverse image; this last comparison is between the SAME remainder.
\end{theorem}
\begin{proof}
Initially the carrier identity is $A=L.N\cap G$, the actual ideal and mark
were retained, and the candidate boundary is precisely the parent boundary
after dropping its first $k$ entries and prefixing $k$ empty entries. The
genuine full parent test tower restricts to a genuine full parent test tower
on $G$, by actual open blowup restriction and coherent controlled pullback.

For any genuine test tower, dropping an initial boundary block preserves
admissibility: every remaining incident member is an original member in its
original adapted coordinates. Prefixing empty entries also preserves
admissibility, since they have no incident member at any point. The literal
strict-transform and exceptional-append recursion preserves those empty
entries and all new actual exceptions. Induct on the original restricted
tower: its genuine last centre keeps the same closed smoothness and cosupport,
and the restricted adapted coordinates prove normal crossings with the
actual padded dropped boundary. Hence every actual restricted centre is
admissible for the candidate and every actual restricted map is its true blowup.

Replacing only the boundary leaves all transformed carrier, ideal and mark
fields unchanged. Apply this actual recursion to the initial restricted
record identity and then the parent coherent open-transform identity. This
gives the exact three fields at every literal prefix, without asserting
whole boundary equality on $G$.
The true closed strict partition supplies the same carrier equality for the
ambient remainder restricted to that inverse image; the preceding entire open
ideal producer supplies its ideal equality and the mark is unchanged. The
empty-prefix/drop/map identities give equality of its own boundary with the
restricted candidate boundary. These four fields prove the whole-record
restriction identity for the SAME remainder, not for the full parent.
\end{proof}

\begin{theorem}[The actual restricted map blows up the true clipped centre trace]
\label{hir:zero-contact-remainder-restricted-clipped-blowup}
\leanok
\lean{Hironaka.HironakaStepOneZeroContactRemainderTestTower.remainder_original_centre_trace_and_blowup}
\uses{hir:zero-contact-remainder-restricted-test-tower,hir:member-tail-actual-clopen-strict,hir:zero-contact-remainder-clipped-admissible}
At any actual parent test prefix followed by its true admissible centre and
blowup, the centre's trace on the corresponding inverse image of $G$ equals
the trace of its intersection with the true remaining strict carrier.
This actual traced centre is admissible for the current restricted remainder,
and the SAME actual restricted original map is a blowup along this clipped trace.
\end{theorem}
\begin{proof}
The original centre lies in the full current carrier. The true closed component
partition gives the strict remaining carrier as the intersection of the full
strict carrier with the projection preimage of the initial remaining union.
A point over $G$ cannot project into the selected union. If it lies in the
full strict carrier, its projection lies in the initial full carrier, hence
in the initial remaining union. Thus every traced original centre point
lies in the actual remaining strict carrier, proving the two centre traces
equal. The reverse inclusion is immediate from the intersection.

Apply the preceding genuine test-tower producer to the actual original tower
with this last step appended. Its actual last test condition proves
admissibility of the traced centre for the actual current restricted candidate.
Actual open restriction of the original blowup satisfies the genuine blowup
universal property along the traced original centre. Substitute the proved
trace equality to obtain the SAME genuine restricted map as a blowup along
the clipped trace. No statement is made about the unrestricted original map.
\end{proof}
