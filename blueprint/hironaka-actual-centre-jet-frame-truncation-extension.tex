\begin{definition}[A fixed linear representative in the entire original germ ring]
\label{hir:actual-fixed-entire-scalar-jet-representatives}
\uses{hir:actual-fixed-whole-scalar-jet-range,hir:actual-entire-point-quotient-pivot-frame}

inverse of the original scalar jet map restricted to its actual image.
It maps the existing $\mathrm{scalarJetRange}(n,q)$ into the ENTIRE
original holomorphic germ ring. Its original scalar jet is exactly
the input array. Restricting it to any existing constant row-kernel
quotient model gives a representative whose whole quotient coordinates
are that model element at every actual point where the original pivot
is nonzero and the original functions are holomorphic.
\lean{Hironaka.HironakaActualCentreJetFrameTruncation.actualScalarJetRepresentative,Hironaka.HironakaActualCentreJetFrameTruncation.scalarJet_actualScalarJetRepresentative,Hironaka.HironakaActualCentreJetFrameTruncation.wholeCoordinates_fixed_representative}
\leanok
\end{definition}
\begin{proof}
The existing original scalar jet map onto its actual image is
surjective. Complex vector spaces are projective, so the genuine
surjective linear map has a linear right inverse; choose it once.
The defining right-inverse equality proves equality of the actual
whole jet arrays. An existing fixed quotient model is literally a
subspace of this same scalar jet image with the selected rows zero.
The original inverse-pivot projection fixes every such array.
Consequently the entire original germ representative has exactly
the specified original whole quotient coordinates. There is no
point-dependent inverse choice and no map from arbitrary origin
germs to nearby germs.
\end{proof}

\begin{theorem}[The genuine frame transition is the whole original quotient truncation]
\label{hir:actual-whole-quotient-frame-truncation}
\uses{hir:actual-fixed-entire-scalar-jet-representatives,hir:actual-holomorphic-pivot-whole-kernel,hir:actual-entire-point-quotient-pivot-frame}

\lean{Hironaka.HironakaActualCentreJetFrameTruncation.actualJetFrameTruncation,Hironaka.HironakaActualCentreJetFrameTruncation.actualJetFrameTruncation_wholeCoordinates,Hironaka.HironakaActualCentreJetFrameTruncation.actualJetFrameTruncation_surjective,Hironaka.HironakaActualCentreJetFrameTruncation.actualJetFrameTruncation_quotient_factor}
\leanok

\begin{proof}
The upper whole coordinates of the fixed representative agree with
the upper whole coordinates of the original numerator. Their
difference is therefore in the ENTIRE proved upper coordinate
kernel, which is exactly the same actual ideal $I_p$ plus the genuine

lower whole coordinates of the representative and original numerator

\end{proof}
