\section{The actual zero/nonzero contact split and whole remainder commute with smooth base change}

Use the literal pulled-back holomorphic ideal and the actual inverse-image
carrier under a genuine smooth holomorphic submersion, of possibly different
ambient dimensions. The selected zero and remaining nonzero component unions

\begin{theorem}[Actual pullback nonzero reflects, and true submersion pullback preserves it]
\label{hir:actual-contact-nonzero-smooth-pullback-iff}
\source{bierstone-milman97-invent-math:page-0016}
\uses{ana:restricted-ideals,hir:submersion-relative-nonzero}
\lean{Hironaka.HironakaOriginalContactRemainderSmoothNaturality.isNonzeroAlongAt_of_pullback,Hironaka.HironakaOriginalContactRemainderSmoothNaturality.isNonzeroAlongAt_pullback_submersion_iff}
\leanok
For an ANY actual carrier $N$, an actual holomorphic germ ideal $I$, a
map continuous at $y$, and the independently defined true ideal pullback,
nonzero along the actual inverse-image carrier at $y$ implies nonzero
along $N$ at $f(y)$. No coherence or smooth-carrier assumption is required
for reflection. If $f$ is a genuine holomorphic submersion and $I$ is
coherent, BOTH nonzero conditions are equivalent. Ambient dimensions may
differ; zero dimensions and empty carriers are included.
\end{theorem}
\begin{proof}
For reflection, suppose every original ideal germ is eventually zero along
$N$ at $f(y)$. Let a genuine pulled-back ideal germ be given. Its actual
finite span expression has finitely many original ideal germs composed
with $f$, multiplied by genuine holomorphic coefficients, with a real
neighborhood equality to the given germ. Continuity at $y$ pulls back each
original eventual zero relation. Intersect these finitely many actual
neighborhoods and the true span-equality neighborhood. Every summand is
zero on the entire inverse-image carrier there, so the given pulled-back
germ is eventually zero along it. This contradicts any actual frequent
nonzero witness and proves reflection, without an ideal or nonzero
certificate. For preservation, genuine submersion local sections give the
actual neighborhood-filter image equality. Compose an actual original
nonzero germ with $f$; true ideal pullback gives its membership and the
filter equality transports frequent nonzero carrier values. Combine the
two independently proved implications.
\end{proof}

\begin{theorem}[WHOLE actual selected and remaining component unions pull back under genuine submersions]
\label{hir:actual-contact-selected-remaining-smooth-preimage}

\uses{hir:actual-contact-nonzero-smooth-pullback-iff,hir:zero-contact-selected-zero-germ,hir:submersion-relative-regular-geometry,hir:crossdim-literal-marked-pullback,hir:dimtwo-unselected-smooth-components}
\lean{Hironaka.HironakaOriginalContactRemainderSmoothNaturality.selectedComponents_preimage_submersion,Hironaka.HironakaOriginalContactRemainderSmoothNaturality.remainingComponents_preimage_submersion}
\leanok
For a genuine closed smooth marked carrier, coherent ideal and positive
mark, under ANY actual holomorphic submersion, the selected component
union of the literal pulled-back record equals the inverse image of the
original selected union. The remaining component union likewise equals
the actual inverse image of the original remaining union. No global
surjectivity, connected-fibre, component-bijection or desired set equality
is input; no canonicality is used.
\end{theorem}
\begin{proof}
Actual submersion geometry internally makes the true inverse-image carrier
closed smooth; genuine ideal pullback supplies coherence, and the literal
record retains its positive mark. At a point of this actual carrier, the
proved zero-germ criterion identifies selected-component membership with
failure of nonzero along the carrier. Apply that criterion to BOTH real
records, and then use the preceding BOTH-direction nonzero dictionary.
This proves selected membership equality at every carrier point. Outside
the carrier, neither selected union can contain the point, because each
actual component is contained in its carrier. Thus the equality holds on
the entire ambient manifold, not just on a chosen component or open image.

The true remaining union equals the carrier minus the actual selected
union for each genuinely closed smooth carrier. Substitute the already
proved whole selected equality and the literal inverse-image carrier.
Inverse image preserves set difference, giving the asserted remaining
equality. No claim that global components themselves are in bijection is
needed or inferred.
\end{proof}

\begin{theorem}[ALL FOUR fields of the actual kept-position contact remainder commute with smooth pullback]
\label{hir:actual-contact-remainder-whole-marked-smooth-naturality}

\lean{Hironaka.HironakaOriginalContactRemainderSmoothNaturality.contactRemainderMarked_markedPullback}
\leanok
Under ONLY the preceding original geometric hypotheses, the literal smooth
pullback of the actual contact remainder equals the actual contact
remainder of the literal smooth pullback, as an ENTIRE marked record.
The same number of historical empty positions, every actual remaining

\end{theorem}
\begin{proof}
The preceding theorem gives equality of the actual carriers. Actual
inverse-image mapping of finite lists commutes with dropping the same
number of positions; mapping an actual empty member gives an actual empty
member, and mapping a replicated list preserves its exact length. Thus
both literal boundary lists have the SAME historical empty entries and
ordered suffix, without deleting or reindexing any position. The ideal
on both sides is the SAME independently defined genuine ideal pullback,
since contact remainder changes only carrier and boundary; the mark on
both sides is the unchanged actual integer. These are the four literal
field equalities, hence equality of the whole marked record.

This is genuine smooth base-change locality for the actual geometric
component split and remainder. It does not assert that arbitrary local
tests extend globally, compare earlier frozen FULL original lower
histories, infer exceptional or infinitesimal semicoherence, or prove
higher invariant decrease or general termination.
\end{proof}
