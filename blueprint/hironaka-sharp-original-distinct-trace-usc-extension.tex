\section{Actual coherent trace-germ persistence and genuine DISTINCT-count upper semicontinuity}

The first-phase $Z=\{\nu>t\}$ of Bierstone--Milman printed page 294 has
invariant strata whose germs remain in $Z$. We construct the required true
DISTINCT-count upper semicontinuity from actual coherent original restricted
ideals, rather than assuming a branch-count or stratum-saturation certificate.
This alone does not prove global analytic closedness of $Z$.

\begin{lemma}[Real coherent restricted germ equality persists on a true neighborhood]
\label{hir:sharp-original-coherent-restricted-germ-equality-persistence}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-original-multiboundary-distinct-proper-trace-germs,hir:monomial-part-along}
\lean{Hironaka.HironakaSharpOriginalDistinctTraceUSC.eventually_coherent_germ_le,Hironaka.HironakaSharpOriginalDistinctTraceUSC.eventually_coherent_germ_eq,Hironaka.HironakaSharpOriginalDistinctTraceUSC.eventually_original_traceGerm_rel}
\leanok
The SAME whole germ-membership inclusion between two genuine coherent ideals
at an actual point persists near that point; both directions give genuine
nearby germ equality. For original smooth carrier and SNC boundary, equality
of two actual restricted holomorphic member trace-ideal predicates therefore
persists near the SAME original point.
\end{lemma}
\begin{proof}
Take a true finite coherent generator family for the source ideal. Its actual
germs at the reference point belong to the target ideal by the given true
pointwise inclusion. Genuine coherent germ continuation keeps every actual
finite generator in the target near the point. The source's BOTH nearby
finite-span directions and the target's actual span closure then transport
membership of EVERY source germ near that point, not merely the displayed
generators. Applying this in both directions proves the genuine germ equality.
Actual original smooth carrier and SNC members internally give coherence of
their genuine restricted extensions; those members are literally holomorphic
germs with the SAME original whole restricted-span predicate. Thus actual
trace equivalence gives precisely the true coherent point-germ equality and
its internally constructed near-point persistence.
\end{proof}

\begin{theorem}[The actual DISTINCT proper original trace-germ count is upper semicontinuous at every carrier point]
\label{hir:sharp-original-distinct-proper-trace-count-usc-all-points}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-original-coherent-restricted-germ-equality-persistence,hir:sharp-original-member-order-proper-incidence-all-points}
\lean{Hironaka.HironakaSharpOriginalDistinctTraceUSC.distinct_count_le_of_rel_and_proper,Hironaka.HironakaSharpOriginalDistinctTraceUSC.eventually_distinctProperTraceGermCount_le}
\leanok
For ONLY genuine original smooth carrier and SNC divisor, the true count of
DISTINCT proper original trace germ-ideal classes is upper semicontinuous along
the carrier at EVERY point, including bad points. No density or desired
quotient-injection/count witness is input.
\end{theorem}
\begin{proof}
Intersect the true persistence neighborhoods for all finitely many original
pairs of equivalent trace germ ideals. Thus every actual old equivalence also
holds at a nearby point. Closedness of every original member simultaneously
ensures no nonincident original position becomes incident nearby; by the true
restricted unit dictionary this means the actual nearby proper positions are
a subset of the original proper positions. The identity on original positions
now induces a GENUINE map from old quotient classes to nearby quotient classes,
since the real old relation is preserved. Every nearby proper class is in the
image of an old proper class. Actual finite-image cardinality therefore gives
the SAME true nearby DISTINCT count at most its reference value. The proof
retains true quotient classes and makes no raw-count substitution at bad points.
\end{proof}

\begin{theorem}[The true original first-phase defect contains the germ of its actual order and invariant stratum]
\label{hir:sharp-original-distinct-defect-actual-order-invariant-strata-saturated}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-original-distinct-proper-trace-count-usc-all-points,hir:sharp-original-deep-product-actual-centre-in-distinct-defect-phase,hir:canonical-centres}
\lean{Hironaka.HironakaSharpOriginalDistinctTraceUSC.eventually_originalDistinctDefectPhase_of_same_order,Hironaka.HironakaSharpOriginalDistinctTraceUSC.eventually_originalDistinctDefectPhase_of_same_invariant}
\leanok
At any point of the actual original FIRST-phase $Z$, nearby original carrier
points with the SAME true product trace order remain in $Z$. In particular the
germ of the SAME original constructed full product-invariant value stratum
is contained in $Z$. No order/invariant-constancy or saturated-stratum
certificate is input.
\end{theorem}
\begin{proof}
The preceding actual count theorem gives $t(y)\leq t(x)<\nu(x)$ near the actual
reference point. At a true same-order carrier point $\nu(y)=\nu(x)$ this forces
$t(y)<\nu(y)$, namely membership in the literal SAME $Z$. Taking the first
coordinate of a SAME actual successor original full invariant-value equality
gives precisely true original product-order equality, by the actual identity
history and empty auxiliary boundary. Thus the entire genuine full-value
stratum germ likewise remains in $Z$. These are actual internally constructed
stratum neighborhoods; they do not prove global $Z$ analyticity, admissibility
of maxima restricted to the whole $Z$, dynamic strict-trace transforms,
recursive-intersection completion, exceptional monomial cleanup or termination.
\end{proof}
