geometry therefore supplies its true current wellformedness and nonzero

since these fields depend only on the same original fields and the
actual maps. At length zero, the nonmonomial part depends only on the
restricted ideal, so the assertion follows in BOTH germ directions.

For a real next step, first apply genuine invertible monomial-division

its actual TOTAL ideal. Substituting these equalities gives BOTH whole
residual directions for the next controlled and zero-mark records.
This induction retains every actual map, empty step and ordered position.
\end{proof}
