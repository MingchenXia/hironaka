\begin{lemma}[Actual common-open base maps supply both smaller-window identities]
\label{hir:sharp-actual-chosen-overlap-window-dictionary}
\uses{hir:sharp-actual-curve-overlap-original-data,hir:sharp-actual-nested-comparison-base}

windows $U|_O$ and $V|_O$ in both directions. The internally constructed

\end{lemma}
\begin{proof}

biholomorphism is constructed by the real nested-restriction producer.
Both it and the original common-open base map have the same original
ambient point at every source point. Two subtype extensionality equations

No smaller-window identity or comparison is assumed.
\end{proof}
