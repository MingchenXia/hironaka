\end{theorem}
\begin{proof}
Compose the internally constructed actual local terminal arrow with the
original target local inclusion. Both maps are holomorphic. The original
inclusion's whole projection formula and the local arrow's whole original
projection identity prove the asserted pointwise global equality.

For the full Cartesian law, fix a complex manifold $W$, a holomorphic
map $a$ to the actual nested source base, and a holomorphic map $b$ to
the original global target satisfying the original-base cone equation.
Every image of the actual nested base map lies in the true target open
$V_j$. The cone equation puts the entire image of $b$ in the true inverse
image of $V_j$ under the original global target projection. Saturation
identifies this inverse image with the actual range of the original
$j$-th local inclusion. Regard $b$ as a holomorphic map to that actual
open range, then compose it with the proved genuine local inverse
biholomorphism. This constructs an actual holomorphic $b_j:W\to D_j$.
Its inclusion is exactly $b$ pointwise. The whole original range projection
dictionary turns the original-base cone into the true local cone over
$V_j$, as an equality in the literal target subtype.

Apply the actual local Cartesian law to $(a,b_j)$ to obtain the unique
holomorphic lift to the genuine restricted source terminal chart. Its
source leg is unchanged. Its target leg, followed by the original local
inclusion, is exactly $b$. For any other global candidate, actual local
inclusion injectivity turns its target leg into the finite local target
leg $b_j$. It is therefore a candidate for the same true finite local
cone, and the finite law identifies it with the constructed lift. Thus
the full original global target square is Cartesian; the sought entire
global source arrow and its overlap compatibility are never assumed.
\end{proof}
