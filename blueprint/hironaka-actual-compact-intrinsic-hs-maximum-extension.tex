\begin{lemma}[A countable family of actual upper semicontinuous natural values has a lexicographic maximum on a nonempty compact carrier]
\label{hir:actual-countable-usc-compact-lexicographic-maximum}
\uses{hir:actual-ambient-hs-whole-superlevel-analytic}
\lean{Hironaka.HironakaActualCompactIntrinsicHSMaximum.exists_actual_compact_countable_usc_lexmax}
\leanok

superlevels are closed, there is an actual $y\in K$ such that no actual
$x\in K$ has a lexicographically larger profile $(f_i(x))_{i\ge0}$.
Moreover $f_i(y)\le f_i(x)$ for EVERY $i$ holds on $K$ exactly when the
ENTIRE two actual profiles agree.
\end{lemma}
\begin{proof}
Work on the actual compact subtype $K$, avoiding any extra ambient
Hausdorff or closed-carrier premise. Start with the full compact subtype.
At stage $i$, actual upper semicontinuity gives a genuine attained
maximum of $f_i$ on the preceding nonempty compact closed set. Intersect
that set with the actual closed superlevel at this attained value. The
result is again closed, compact and nonempty. These actual sets decrease.
Compactness supplies a point in their full countable intersection.
For any competing point whose first $i$ coordinates agree with this point,
induction puts it in the $i$th actual maximizing set. Its $i$th coordinate
is therefore bounded by the chosen point's coordinate. The first
differing coordinate rules out a lexicographically larger profile.
If all competing coordinates dominate, induction gives the reverse
inequality at each successive coordinate, hence equality at EVERY order.
The converse is immediate. No maximizing profile, bound or nested-set
certificate is a caller premise.
\end{proof}
