\section{Each original dimension part has its own canonical elementary family}

Each part below uses its own literal vanishing ideal, regular locus,
good open and bad set. No sequence resolving the whole mixed-dimensional
carrier is substituted for a part's own sequence.

\begin{definition}[Independent pure elementary output with a fixed original target]
\label{hir:original-independent-pure-boundary-output}
\lean{Hironaka.HironakaOriginalCanonicalDimensionPartResolution.HasIndependentPureBoundaryResolution}
\leanok
The output for original pure carrier $A$, dimension $k$ and SNC boundary
$E$ retains an actual full canonical terminal tower $P$, its actual
first-good-open-meeting prefix $T$, and the actual remainder. Its own
bad set is $F_A=(A\setminus\operatorname{Reg}_k A)\cup(A\cap\bigcup E)$.
The same $T$ has whole admissibility, SNC, closed regular strict carrier,
normal crossings, the entire exceptional/new-boundary inclusions,
properness, surjectivity and isomorphism off $F_A$.

The target precedes every smooth map $b:Y\to X$. For each such map the
output internally contains the actual pullback of $P$, the actual
pullback $Q$ of this SAME $T$, and an independently stopped intrinsic
source prefix $S$ in the pulled full terminal history. The source has
its own genuine canonicality, stopping maximum and entire boundary;
its own bad set is exactly $b^{-1}F_A$. Its unique comparison with $Q$
gives the true holomorphic Cartesian square, upper submersion, whole
strict-carrier and ordered filtered-boundary identities. The source
has its own complete elementary geometry. This is a transparent
conclusion property, never an existence premise.
If the original boundary is empty, the SAME selected target and
source satisfy the literal equalities exceptional locus equals whole
final boundary support equals inverse image of their OWN singular set.
\end{definition}

\begin{theorem}[Original compact pure data fix the target before every independent smooth source]
\label{hir:original-compact-pure-fixed-target-independent-family}
\uses{hir:original-independent-pure-boundary-output,hir:original-pure-boundary-canonical-first-prefix,hir:original-pure-boundary-independent-intrinsic-comparison}
\lean{Hironaka.HironakaOriginalCanonicalDimensionPartResolution.exists_original_compact_pure_fixed_target_family}
\leanok
Let $A$ be an original compact analytic carrier, $k<n$, with
$A\subseteq\overline{\operatorname{Reg}_k A}$. Let $E$ be an original
SNC boundary with $A\subseteq\overline{A\setminus\bigcup E}$.
These original data internally produce the entire independent pure
output above, with one target fixed before all smooth sources. No
source compactness or supplied source history is required. Empty
carriers and empty sources use the genuine canonical empty branches.
\end{theorem}
\begin{proof}
The original compact pure producer gives its actual full canonical
terminal tower and a prefix $T$ ending just before its first whole
maximum meets the original good open. Fix this actual target and all
its whole geometric fields now.

For any smooth $b$, construct the actual pullbacks of both the full
terminal tower and this fixed prefix. The genuine whole singular-ideal
pullback dictionary identifies the pulled marked input with the
intrinsic source vanishing ideal. Actual canonicality and terminality
transfer to the pulled full tower. At a source point submersivity
gives $m\ge n$, hence $k+(m-n)<m$. The actual relative regularity and
boundary-density dictionaries supply the pure source data. The genuine
terminal-prefix producer therefore selects an independently stopped
prefix $S$ inside this actual source full history. If the source has
no points, its real identity prefix and the all-empty canonical full
history give the required branch, without inventing a dimension bound.

Compare this genuine $S$ with the actual pullback $Q$ of the already
fixed $T$ by the original independent intrinsic-prefix comparison.
It constructs the unique actual endpoint map, its entire ordered
filtered-boundary identity, whole strict square, upper submersion and
full holomorphic Cartesian universal property. The same comparison
transfers the target strict-carrier regularity and normal crossings
to the source's own entire boundary. The actual source centres lie
over its intrinsic cosupport and avoid its good open, so their original
images lie in precisely its own bad set. The whole exceptional-divisor
support formula, canonical testness and actual blowup-sequence
properties give source admissibility, both whole new-boundary
inclusions, the singular inverse-image inclusion, properness,
surjectivity and isomorphism off that same bad set. Intrinsic regularity
reflection identifies it exactly with $b^{-1}F_A$. No new source
compact driver or comparison certificate has entered the construction.
For an empty initial boundary, the new-boundary list is the entire
final boundary and the intrinsic bad set is exactly the own singular
set. The exceptional-to-boundary, boundary-to-bad and
bad-to-exceptional inclusions therefore give both literal equalities
by antisymmetry, on the SAME target and source.
\end{proof}

\begin{theorem}[Compact dimension parts use their own canonical pure families]
\label{hir:original-dimension-part-own-compact-canonical-family}
\uses{hir:original-compact-pure-fixed-target-independent-family,hir:embedded-resolution-dimension-parts}
\lean{Hironaka.HironakaOriginalCanonicalDimensionPartResolution.exists_dimensionPart_compact_canonical_family,Hironaka.HironakaOriginalCanonicalDimensionPartResolution.exists_dimensionPart_compact_ambient_canonical_family,Hironaka.HironakaOriginalCanonicalDimensionPartResolution.exists_dimensionPart_compact_empty_boundary_family,Hironaka.HironakaOriginalCanonicalDimensionPartResolution.exists_dimensionPart_compact_ambient_empty_boundary_family}
\leanok
Let $W$ be compact and analytic, and let $k<n$. Put
$A=\overline{\operatorname{Reg}_k W}$. For any original SNC boundary
$E$, assume explicitly the per-part density
$A\subseteq\overline{A\setminus\bigcup E}$.
Then this original part has the fixed-target independent pure family
above, with its OWN input $I_A$ and OWN bad set $F_A$.
The same holds in a compact ambient manifold without a separate
compactness premise on $W$.
For empty original boundary the SAME target and source satisfy
the exact old equalities $\operatorname{Exc}=\bigcup E_{\rm final}
=f^{-1}(A\setminus\operatorname{Reg}_k A)$, with the corresponding
shifted source dimension. No density premise is then needed.
\end{theorem}
\begin{proof}
The actual original dimension-part theorem gives analyticity of $A$
and $A\subseteq\overline{\operatorname{Reg}_k A}$. The part is closed
and contained in the original closed $W$, hence compact. Apply the
preceding original pure family theorem to this exact $A$, dimension
$k$, boundary and disclosed per-part density. No singular set of the
whole $W$ is used. For compact ambient space, original analyticity
makes $W$ closed and compact, giving the same application. The
proper-dimension assumption remains the original $k<n$; an empty
part within this scope is handled by the preceding actual empty branch.
When $E$ is empty, the per-part boundary density is simply the genuine
inclusion $A\subseteq\overline A$. The preceding output's two literal
exceptional support equalities apply to that same selected family.
\end{proof}

\begin{theorem}[Prescribed local domains and compact neighbourhoods for each own part]
\label{hir:original-dimension-part-own-local-canonical-family}
\uses{hir:embedded-resolution-dimension-parts,hir:original-local-pure-boundary-internal-source-producer,hir:original-local-pure-boundary-compact-neighbourhood-internal-source}
\lean{Hironaka.HironakaOriginalCanonicalDimensionPartResolution.exists_dimensionPart_prescribed_local_canonical_family,Hironaka.HironakaOriginalCanonicalDimensionPartResolution.exists_dimensionPart_compact_neighbourhood_canonical_family}
\leanok
Let $W$ be any original analytic carrier, $k<n$, $A=W^{(k)}$,
and let $E$ have the same explicit per-part density as above.
Every prescribed original open $U$ contained in an actual compact
set has the genuine independent local pure output for $A|_U$.
For every compact $K$, one actual open neighbourhood $U$ of $K$
with compact closure and its own target are internally chosen before
all smooth sources of that SAME $U$. Their ideals, regular sets and
bad sets concern the restricted part $A|_U$, with no compactness
premise on $W$ or on the smooth source.
\end{theorem}
\begin{proof}
Use the same actual original part analyticity and pure regular density.
For the prescribed $U$, apply the original local independent pure
producer to this $A$, the actual compact host and the given inclusion
$U\subseteq L$. Its whole result retains that same domain and this
part's intrinsic vanishing ideal and bad set. For compact $K$, the
original pure neighbourhood theorem internally chooses an open
superset with compact closure and applies that same prescribed-open
construction. The target remains before every smooth source in its
quantifier order. The explicit density premise remains per-part;
it is never replaced by a statement about the whole mixed carrier.
\end{proof}
