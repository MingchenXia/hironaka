\begin{theorem}[Component-own-order special and count histories]

\leanok

is an analytic zero-dimensional exception E contained in Z. Each genuine

\begin{proof}
The actual attained-minimum order producer gives a discrete analytic order
exception and, on each real nonempty global component B, its true attained
minimum q. Its proper analytic excess at q+1 is the source of the order
exception, so no upper bound on orders is needed.

For a component with q positive consider the finite family of the preceding
actual positive-special predicates at that fixed q, indexed by all literal
heads and further literal prefixes. Include the actual count predicates at
all thresholds from zero to the relevant finite original-member-list length.

most zero. These actual excesses are all contained in B. For each finite index
the true locally finite component family therefore restricts to a locally
finite excess family, whose union is analytic and zero-dimensional. Their
finite union has the same properties and lies in Z. Components with q zero
contribute an empty family. Unite this exception with the order exception
and the actual all-order-run history exception.

Outside the union each positive special predicate has exactly its whole-
component truth value. Likewise every finite count threshold has its whole-
component truth value. The count is bounded by the actual list length, so
threshold equality at the two attained counts forces count equality. At any
positive level s, equality of counts and positive-special predicates gives
literal equivalence of the actual regime condition level=s and not special,
even at prefix images whose count is zero. The true tower run recursion then
gives equality of stepRegime runs. The existing genuine all-order history
producer gives equality of all order runs and their own-order evaluation on
the same final exception. The component mark q is its actual minimum; a
single finite family is used for this q on this B, and local finiteness of
B makes the varying-component construction analytic without any finite
assumption on the set of marks.
\end{proof}
