\section{Actual computed zero-mask full curve values on nested original opens}

The contact-history comparison in the dimension induction of
\cite[Section~5, Step~I.B]{bierstone-milman08-functoriality} must compare
the unchanged full value of the actual computed lower record with its
genuine smaller contact window. The computed large mask is fixed by the
original regime run; it cannot be replaced by a convenient chosen mask.
We first prove the required noncanonical nested-open transport from real
tower geometry and the already proved ANY-test curve-value formula.

\begin{theorem}[Genuine nested open restriction preserves every positive-depth full curve value on ANY original TEST]
\label{hir:original-any-test-curve-full-value-nested-opens}
\uses{bcalc:restrict-nested,hir:original-any-test-curve-full-value-open-naturality,hir:original-any-test-curve-full-value-tower-isomorphism}
\lean{Hironaka.HironakaOriginalComputedZeroMaskCurveValues.original_curve_any_test_full_value_nested_opens}
\leanok
Let $P$ be an actual marked ideal with coherent ideal on the original
ambient manifold, $V\subset W$ actual opens, and $T$ an actual tower.
Assume only that the actual restriction $P|_W$ is a genuine bound-one
domain and $T|_W$ is its genuine TEST. Internally construct the genuine
bound-one domain and TEST on $V$. At EVERY endpoint of $T|_V$ its actual
cosupport membership is equivalent to membership of the SAME underlying
endpoint in the actual cosupport of $T|_W$. At such a point EVERY positive
recursive-depth unchanged original full value on $V$ equals the value on
$W$. No canonicality, nested comparison, smaller domain/TEST/cosupport or
full-value certificate is supplied.
\end{theorem}
\begin{proof}
Let $B=W\cap V$, regarded as an open of $W$. First restrict the genuine
domain and TEST on $W$ to $B$. The actual identity-on-points
biholomorphism $B\simeq V$ and actual tower isomorphism identify the doubly
restricted tower with $T|_V$, preserving every map and empty position.
True coherent pullback composition identifies the ENTIRE transported
marked record with $P|_V$, including its ordered boundary. Transport of
the genuine domain and TEST through this actual isomorphism supplies
the asserted domain and TEST on $V$ before any value comparison.

The genuine tower-isomorphism cosupport dictionary followed by the
genuine open-restriction cosupport dictionary gives BOTH membership
directions at the same underlying original endpoint. At such a point
apply the proved ANY-test full curve-value isomorphism theorem to the
actual identity-on-points isomorphism, and then apply the proved ANY-test
full curve-value open-restriction theorem from $W$ to $B$. Their
composition gives the asserted equality at EVERY positive recursive
depth. Only genuine TESTs are used; the canonical-only invariant
restriction interface is never invoked.
\end{proof}

\begin{theorem}[ONLY original zero-regime data supply the actual computed large mask and all full values on every genuine smaller mask]
\label{hir:original-computed-zero-mask-curve-full-values}
\uses{hir:original-any-test-curve-full-value-nested-opens,hir:original-any-test-actual-computed-zero-mask-history,mc:contact-stage-domain}
\lean{Hironaka.HironakaOriginalComputedZeroMaskCurveValues.actual_original_computed_zero_mask_curve_full_values}
\leanok
ONLY an original bound-two maximal-order domain, ANY genuine original
TEST and an actual current cosupport point in the zero nonspecial
regime internally supply the ACTUAL regime-run split, ACTUAL computed
large zero mask $W$, unchanged computed lower record $J$ and genuine
restricted original tail. Its bound-one domain, TEST and actual
cosupport point are internally proved. For EVERY actual open $V\subset W$
containing the actual head image, internally construct the true smaller
kept contact domain, genuine restricted tail TEST and actual smaller
cosupport point. At the SAME original endpoint, its unchanged full
original value equals that of the ACTUAL computed large lower record
for EVERY positive recursive depth. No caller lower record/domain/TEST,
canonicality, smaller cosupport or desired value equality is input.
\end{theorem}
\begin{proof}
Apply the original-input zero-mask-history producer to the GIVEN
original TEST, actual current cosupport and actual zero nonspecial
regime. This internally constructs the true regime-run split, actual
computed large mask membership, actual lower bound-one domain, real
restricted tail TEST and BOTH whole cosupport directions. In particular
the same original endpoint belongs to the actual computed lower
cosupport.

The actual coefficient TEST head is supplied internally by genuine
coefficient equivalence and the real head-tail decomposition. The
original coherence theorem therefore proves coherence of the actual
global contact-parent ideal on the head-stage manifold. By the original
zero-mask definitions, its actual restriction to the computed mask is
EXACTLY the computed lower record, including all four marked fields.
For any actual smaller open as in the statement, apply the first
theorem to THIS actual global contact parent, actual large mask and
same original tail, using the internally proved large domain and TEST.
Its BOTH cosupport dictionary and the internally constructed large
cosupport point supply the smaller point. The all-depth full-value
equality is then the first theorem's actual conclusion, with the
unchanged computed lower parent identified by its defining equality.

This closes a genuine local-to-computed-record value bridge in the
zero-contact branch with original carrier bound two. It does not assert
the whole upper GENERAL comparison, a positive-member history bridge,
higher-dimensional noncanonical full-value locality, exceptional or
infinitesimal semicoherence, or the full global scheduling theorem.
\end{proof}
