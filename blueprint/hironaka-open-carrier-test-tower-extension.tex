\section{Actual test towers extend from a closed carrier inside an original open}
\label{sec:open-carrier-test-tower-extension}

\begin{theorem}[Original open equality gives entire current-record equality on actual restricted histories]
\label{hir:original-open-equal-current-test-records}
\lean{Hironaka.HironakaOpenCarrierTestTowerExtension.current_open_record_eq}
\leanok
Let $A,B$ be original marked data on the same ambient manifold, with coherent
ideals and closed smooth carriers. Suppose their ENTIRE original records
restrict equally to an actual open $G$. On any actual finite tower which is
a test tower for both, the ENTIRE transformed records restrict equally to
the actual inverse-image open $G_T$.
\uses{hir:general-restrict-open}
\end{theorem}
\begin{proof}
For each original datum the actual whole transform-restriction theorem
identifies its transformed record restricted to $G_T$ with the transform
of its original restricted record along the SAME actual restricted tower.
The original record equality identifies the latter two whole transforms.
Compose these exact equalities. This retains every ideal germ, carrier,
ordered boundary entry and marking, without assuming a current equality.
\end{proof}

\begin{theorem}[Every actual closed-carrier test history is a genuine parent test history]
\label{hir:original-open-carrier-test-history-extension}
\lean{Hironaka.HironakaOpenCarrierTestTowerExtension.isGeoTestTower_parent}
\leanok
In the same original situation suppose the carrier of $A$ lies entirely
inside $G$ and the two original WHOLE ordered boundary lists agree.
EVERY actual test tower of $A$ is then a true test tower of $B$ on the SAME
ambient spaces with the SAME actual centres and projections. No parent test
history, parent centre or transformed-ideal certificate is supplied.
\uses{hir:original-open-equal-current-test-records,hir:general-restrict-open}
\end{theorem}
\begin{proof}
Induct on the actual finite tower. At the empty history parent testness is
literal. Suppose it has been proved for a prefix. Every point of its next
actual $A$-centre lies in the current carrier of $A$. The true strict-carrier
projection inclusion sends this point into the original carrier of $A$,
hence into $G$. Thus the ENTIRE centre is contained in the actual open $G_T$.

At this prefix the induction hypothesis supplies both actual test histories,
so the preceding theorem proves equality of their ENTIRE current restricted
records. Coherent cosupport restriction then transports the true $A$-centre
cosupport membership to the parent $B$-cosupport, point by actual point in
$G_T$. The centre's closed smooth geometry is the same. Whole boundary
transform depends only on the original WHOLE ordered list and the literal
centres and maps; the original list equality therefore identifies the two
whole current boundary lists. The actual centre normal-crossings witness
for $A$ is consequently the parent witness as well. These are every genuine
parent centre-admissibility field, so appending this SAME actual blowup gives
the parent test step. The induction retains all chronological empty slots
and assumes no parent history at any stage.
\end{proof}
