\begin{lemma}[Actual minima and actual first higher component values produce a genuine proper analytic jump subset]
\label{hir:actual-full-value-component-proper-analytic-jump}
\uses{hir:original-all-depth-arbitrary-full-history-global-analytic,hir:invariant-order,hir:dimension-part-global-component-union,rem:thin-dimension-drop}
\source{bierstone-milman97-invent-math:page-0095}
\lean{Hironaka.HironakaOriginalFullValueVariationLocus.exists_actual_component_minimum_analytic_jump}
\leanok
Let $f$ have a true well-founded linear value order and genuine analytic FULL
cuts on an actual carrier. For every actual global component $B$ of a
pure-$q$ analytic subset of that carrier, internally construct its ACTUAL
minimum value $a_B$ and its literal jump subset
$E_B=\{x\in B:a_B<f(x)\}$. This SAME subset is genuinely analytic, is proper
in $B$, and has dimension at most $q-1$. No generic value, next value,
proper-subset, order bound or analytic jump certificate is input.
\end{lemma}
\begin{proof}
The genuine global component is nonempty. Original well-foundedness applied
to its ACTUAL value image supplies a least member, genuinely attained at a
real component point, and gives $a_B\le f$ on ALL of $B$. If no value exceeds
$a_B$, the literal jump subset is empty. Otherwise well-foundedness applied
to the actual attained higher values supplies a real least higher $c_B$.
On $B$, $a_B<f(x)$ holds EXACTLY when $c_B\le f(x)$: one direction uses
minimality in the actual higher image, the other $a_B<c_B$. Consequently
$E_B$ is the genuine intersection of analytic $B$ with the ACTUAL global
$c_B$-cut. The minimum-attaining point proves $B$ is not contained in that
cut BEFORE dimension drop is invoked. If an open part of $B$ lay in $E_B$,
it would meet the genuine regular-locus component whose closure is $B$.
The PROVED analytic continuation theorem would put that ENTIRE component,
and hence its closure, in the actual cut, contradicting the minimum point.
Thus the proper intersection is genuinely thin in $B$. Actual geometric
purity bounds its dimension by $q$; the proved thin analytic dimension-drop
theorem gives $\dim E_B\le q-1$.
\end{proof}

\begin{proof}
