\section{The genuine one-dimensional Step One value on every ORIGINAL test}

At dimension one the original maximal-order Step One algorithm has no
nonempty nonspecial lower branch. Prove this directly from actual masked
geometry, without borrowing the canonical-history value interface, for the
dimension induction in \cite[Section~5]{bierstone-milman08-functoriality}.
This is an actual value theorem on every original TEST, not a statement
that arbitrary lower TESTS are canonical.

\begin{theorem}[ONLY original one-dimensional maximal-order ANY-test data force the actual special leaf and exact original Step One value]
\label{hir:original-any-test-curve-stepone-special-value}
\uses{hir:step-one-value-masked-basic,hir:step-one-lower-domain,hir:step-one-compare}
\lean{Hironaka.HironakaOriginalAnyTestCurveStepOneValue.original_curve_step_one_special_of_test,Hironaka.HironakaOriginalAnyTestCurveStepOneValue.original_curve_step_one_value_of_test}
\leanok
ONLY an ORIGINAL maximal-order invariant-domain marked ideal $M$ of bound
one, ANY genuine ORIGINAL test $T$ and an actual point $y$ of its current
ORIGINAL cosupport imply that $y$ is genuinely special. Consequently the
ACTUAL unchanged masked Step One value using the original bound-zero
inductive invariant is exactly $(\operatorname{level}(y),\top)$.
No canonicality, lower canonical TEST, special-point certificate or desired
value equality is an input.
\end{theorem}
\begin{proof}
Original coefficient equivalence internally constructs the SAME actual
coefficient-homogenized TEST and actual cosupport membership. Suppose the
point were not special. At THIS current stage it is in the regime of its
actual level by definition. The true masked lower-domain theorem therefore
constructs its actual OWN mask membership and its actual lower marked ideal
in dimension bound zero. This statement uses actual TEST geometry only.

Now use the REFLEXIVE tail at this SAME stage. It is genuinely a lower
TEST without ANY centre condition or canonicality hypothesis. The actual
masked lower cosupport dictionary, applied to this reflexive tail and the
actual original level, puts the SAME current point in its true lower
cosupport. But the independently constructed dimension-zero domain has
EMPTY cosupport along every actual TEST, in particular the reflexive one.
This is a contradiction. The point is therefore genuinely special.
Unfold the ACTUAL original masked Step One definition at this proved
special point. It gives exactly the asserted pair; no property of higher
noncanonical lower values is invoked.
\end{proof}

\begin{theorem}[ONLY original smooth inputs produce the actual Step One value comparison on every original one-dimensional maximal-order test]
\label{hir:original-smooth-any-test-curve-stepone-value}
\uses{hir:original-any-test-curve-stepone-special-value,hir:smooth-all-branches-original-special-regime,hir:smooth-bar-record,hir:submersion-relative-control-original-all-heads}
\lean{Hironaka.HironakaOriginalAnyTestCurveStepOneValue.actual_smooth_curve_step_one_value_of_test,Hironaka.HironakaOriginalAnyTestCurveStepOneValue.exists_original_smooth_curve_step_one_value_of_test}
\leanok

of the preceding one-dimensional maximal-order input, EVERY actual source
point mapping into the target ORIGINAL cosupport has the genuine original
source Step One value equal to the actual dimension embedding of the

The final producer takes ONLY the original domain/maximal order, ANY
original target TEST and the genuine smooth base map. It internally
constructs the SAME actual source Cartesian TEST before providing this
value equality at EVERY relevant actual source point. No source history,
source canonicality, lower invariant comparison or special certificate is
supplied. Positive original ambient/source dimensions are explicit.
\end{theorem}
\begin{proof}
The first theorem proves the actual target special-point property directly
from the ORIGINAL test. Genuine coefficient equivalence internally supplies
the SAME target coefficient TEST. The real all-branch special-point
dictionary on the actual smooth Cartesian history supplies the ACTUAL
source special-point property, before evaluating its function. The true
whole original boundary dictionary supplies equality of the actual original
levels, retaining every original and empty position.

Unfold the unchanged actual source and target masked Step One definitions.
Both now evaluate in their PROVED special branches. The genuine recursive
dimension map preserves the level and maps the actual top lower entry to
top, so these actual values satisfy the asserted equality. This proof uses
neither canonical value invariance nor a desired lower comparison.
For the original-only final producer, the genuine original smooth-tower
constructor first supplies the actual source tower, real Cartesian square
and ORIGINAL source TEST. Apply the just-proved actual-history comparison
to it at each actual source point. This keeps every actual map, centre and
empty step and completes the original-input construction.

The full GENERAL invariant also uses a companion chosen at the original
order-run year. Its genuine companion TEST/domain/cosupport must still be
constructed internally on a noncanonical history before this leaf theorem
can be applied there. General full-value nonincrease, arbitrary positive
member-centre containment, exceptional or infinitesimal semicoherence and
general termination remain OPEN.
\end{proof}
