\begin{theorem}[The actual union of local strict sets has exactly the prescribed local pullbacks]
\label{hir:sharp-actual-glued-strict-set-local-dictionary}
\uses{hir:sharp-actual-endpoint-transition-strict-set-membership,hir:sharp-actual-endpoint-topcat-glue-core}
\lean{Hironaka.HironakaSharpActualCurveGluedStrictSets.gluedStrictSet,Hironaka.HironakaSharpActualCurveGluedStrictSets.mem_gluedStrictSet_iff,Hironaka.HironakaSharpActualCurveGluedStrictSets.preimage_gluedStrictSet}
\leanok
For ANY original closed set B, form the actual union of the inclusion images
of its SAME local finite-history strict transforms. The inverse image of
this actual global subset under EVERY real local inclusion is exactly the
corresponding entire local strict set. No set-descent or compatibility
certificate is an input.
\end{theorem}
\begin{proof}
A local strict point belongs to its own actual inclusion image, giving one
direction. Conversely, an included point in the union has a genuine local
strict representative from some actual chart. Equality of the two actual
included points is, by the genuine TopCat gluing relation, witnessed by a
point in their actual overlap with the true OLD transition taking one
representative to the other. The already proved BOTH strict-set membership
dictionary transports strict membership through this actual OLD map.
The real subtype point equalities then give membership in the requested
whole local strict set. Taking pointwise membership gives the exact inverse
image equality, not merely a containment or a chosen representative equation.
\end{proof}

\begin{theorem}[The genuine glued strict set is globally closed and lies over B]
\label{hir:sharp-actual-glued-strict-set-closed-over-original}
\uses{hir:sharp-actual-glued-strict-set-local-dictionary,hir:sharp-actual-endpoint-glued-projection}
\lean{Hironaka.HironakaSharpActualCurveGluedStrictSets.isClosed_gluedStrictSet,Hironaka.HironakaSharpActualCurveGluedStrictSets.gluedStrictSet_subset_preimage}
\leanok
The actual glued strict set is closed in the true glued space and is
contained in the inverse image of the original closed B under the ACTUAL
global projection. No global closedness or projection-support certificate
is assumed.
\end{theorem}
\begin{proof}

of B is closed and genuine tower strict transforms preserve closedness.

when all actual local inclusion inverse images are open. Apply this to the
complement of the constructed global set. The first theorem identifies

Equivalently, a real local representative of a point outside the global set
has an actual open-complement neighborhood whose open inclusion image is
disjoint from the entire global set. No global closedness is supplied.

For a point in the glued set, choose its real local strict representative.
Genuine finite-history strict-transform containment puts its actual local
projection in the original B trace. The true component and append-projection
equations identify this with the actual global projection, proving the stated
whole global containment without asserting surjectivity onto B.
\end{proof}
