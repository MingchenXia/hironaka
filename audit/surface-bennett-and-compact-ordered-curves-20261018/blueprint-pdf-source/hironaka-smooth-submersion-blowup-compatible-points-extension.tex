\begin{lemma}[Actual target direction chooses the matching pair of charts]
\label{hir:submersion-blowup-compatible-target-chart-point}
\leanok
\lean{Hironaka.HironakaSmoothSubmersionBlowupCompatiblePoints.exists_actual_target_matching_point}
\uses{hir:submersion-adapted-actual-product-shrink,hir:submersion-adapted-blowup-entire-monomial-dictionary,bex:monomial-chart}
Let $f:Y^{n+r}\to X^n$ be a genuine submersion at $y$, and let an actual
flattening $\Phi$ at $fy$ carry the whole local centre to the coordinate plane
of dimension $k$, with $\Phi(fy)=0$. For an actual target blowup point $z$
with $z.\mathrm{base}=fy\in C$, internally produce matching actual blowup
charts $c,c'$, an actual product open $R\times S$, and an actual source
blowup point $p$. They satisfy $z\in c.\mathrm{source}$,
$p\in c'.\mathrm{source}$, $p.\mathrm{base}=y$, and
$\mathrm{flatChartMap}(c,c')(p)=z$, with the exact product targets and whole
original base projection square. No chart, pivot or compatible-point output
certificate is supplied.
\end{lemma}
\begin{proof}
The actual target direction is not tangent to the true centre. The genuine
flattening tangent dictionary therefore supplies a normal index $j\ge k$
whose differential on this actual direction is nonzero. Internally adapt
the actual submersion coordinates to this SAME $\Phi$ and shrink them to the
actual product target $R\times S$, with $0\in R$, $0\in S$ and source centre
flattened in fibre-first coordinates. Restricting $\Phi$ to $S$ preserves its
entire coordinate functions and the actual chosen direction differential.
Hence the monomial target chart with this actual $j$ contains $z$: its base
is the actual central point, and its true extended pivot value is nonzero.
The source chart uses the corresponding actual normal index after block
rotation. The genuine monomial/block formulas prove its target is exactly
$\mathrm{split}^{-1}(R\times c.\mathrm{target})$, with the whole inverse
base projection square. Set
\[w=\mathrm{split}^{-1}(0,c.\mathrm{toFun}(z)),\qquad p=c'.\mathrm{invFun}(w).\]
The actual chart target and $0\in R$ give $w\in c'.\mathrm{target}$ and
$p\in c'.\mathrm{source}$. Since $z.\mathrm{base}=fy$, the monomial target
base coordinates are exactly $\Phi(fy)=0$. The genuine source monomial/block
identities therefore give monomial source coordinates zero. The actual
source flattening sends its centre $y$ to zero and has its actual inverse
there, so $p.\mathrm{base}=y$. The true right inverse of $c'$ and the true
left inverse of $c$ give the displayed actual map identity, including points
on the entire exceptional divisor. No parameter inversion occurs.
\end{proof}

\begin{theorem}[Every actual compatible pair has a source blowup point]

\end{proof}

canonical compatible-point witness are internally produced, not hypotheses.
\end{proof}
