\begin{lemma}[Actual normalization on a true subcarrier retains the genuine relative generator through open restriction]
\label{hir:sharp-actual-subcarrier-open-relative-generator}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-original-first-good-other-member-trace-nonzero}
\lean{Hironaka.HironakaSharpActualFirstGoodLowerProduct.actual_subcarrier_open_relative_generator}
\leanok
For a coherent actual ideal relatively generated by $f$ along $N$ at an
actual point, an actual subcarrier $S\subset N$ and a true ambient open,
the WHOLE carrier-normalized open pullback to $S$ is relatively generated
by the SAME actual restricted $f$. Both full germ directions hold,
including all germs vanishing on $S$. No principal restriction or model
certificate is supplied.
\end{lemma}
\begin{proof}
First restrict each actual generator relation from $N$ to $S$. A genuine
finite span in the original ideal then substitutes these true relations
to become a span of $f$ on $S$. Conversely $f$ is a genuine member of the
original ideal, so every span of $f$ on $S$ belongs to its actual
normalization. This proves BOTH normalized germ directions on the true
ambient carrier. For the open pullback, use the proved BOTH-direction
normalized-ideal extension dictionary. An actual ambient cofactor restricts
to a holomorphic cofactor on the open. Conversely extend an open cofactor
by zero; it is holomorphic at the actual point, and the true open
neighborhood filter identity carries its relation back. The extensions
agree with the original functions on the real open, so BOTH directions
retain the same restricted generator and all normal germs.
\end{proof}

\begin{theorem}[The actual finite remaining lower product is a genuine invariant input]
\label{hir:sharp-original-first-good-actual-lower-product-domain}

\lean{Hironaka.HironakaSharpActualFirstGoodLowerProduct.actualRemainingLowerProduct,Hironaka.HironakaSharpActualFirstGoodLowerProduct.exists_original_first_good_lower_product_domain}
\leanok
ONLY the same original inputs construct, on the SAME computed open and

\end{theorem}
\begin{proof}

dimension. These are the real original domain fields, not supplied

\end{proof}
