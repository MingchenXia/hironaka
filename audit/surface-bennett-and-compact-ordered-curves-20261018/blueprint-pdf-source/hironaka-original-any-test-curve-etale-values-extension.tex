ambient dimensions agree its dimension bound is still one. The real

and ENTIRE current marked-record pullback identity, preserving carrier,

positive recursive depth. The order equality identifies the actual zero
and positive cases, the whole monomial dictionary identifies the zero
case, and both positive cases have the same actual computed special leaf
$(0,\infty)$. Thus the original full values themselves agree, without
invoking the canonical-only invariant naturality interface.
\end{proof}
