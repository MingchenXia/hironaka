\begin{lemma}[True original member incidence detects positive contact budget]
\label{hir:sharp-original-curve-budget-incidence-positivity}

\lean{Hironaka.HironakaSharpActualCurveContactBudgetDomination.actual_normalized_vanishing_order_positive_iff,Hironaka.HironakaSharpActualCurveContactBudgetDomination.original_curve_budget_positive_iff_incident,Hironaka.HironakaSharpActualCurveContactBudgetDomination.original_curve_budget_eq_zero_of_no_incidence}
\leanok
ONLY the original curve/SNC/density and ANY genuine original test internally
give, at EVERY actual current carrier point $x$, zero actual budget when
no original strict member contains $x$, and positive actual budget when
at least one original strict member contains $x$.
\end{lemma}
\begin{proof}

genuine discrete centres and each actual current strict member's closed

actual normalized vanishing ideal contains the unit germ. Its true

actual first point power, contradicting its value one at $x$.
For an incident member, every genuine relative finite-span germ vanishes
at $x$: evaluate the actual span on the true carrier at $x$, where each
vanishing-ideal generator is zero. The true mark-one cosupport dictionary
therefore proves its actual ordinary order at least one. Summing the zero
orders gives the first assertion. A genuine incident original position
and nonnegative finite summands give the second assertion. No branch
count, order value or support certificate is supplied.
\end{proof}
