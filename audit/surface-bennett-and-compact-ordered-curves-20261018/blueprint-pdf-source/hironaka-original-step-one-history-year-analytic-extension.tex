\[

$L_{s,r}(T)=A_s(T)\cap\{\operatorname{regimeRun}(\operatorname{stepRegime}(J,s),T)\le r\}$.

\begin{lemma}[The entire true lower history has exact zero and successor run equations]
\label{hir:original-step-one-history-year-whole-step-dictionaries}

\[

\begin{proof}
A current baseline point maps to old cosupport with old level at least $s$.
If that old point belongs to the literal original nonspecial level-$s$
regime, the original run grows by exactly one. Otherwise its old level
is strictly larger than $s$, or its level equals $s$ and it is special;
these are exactly $Z_s(T)$, and the original run resets to zero.

For the zero identity, run at most zero excludes the increment alternative,
so precisely the reset set is necessary and sufficient. For the successor
identity, an increment has run at most $r+1$ exactly when its old run is
at most $r$, retaining the inherited old baseline. A reset has zero run
and satisfies every successor bound. Conversely an old $Z_s$ point
resets, while an old $L_{s,r}$ point either increments its bounded run or
resets. These cases prove both directions of the entire identities and
retain every actual special, nonspecial and empty chronological step.
\end{proof}
