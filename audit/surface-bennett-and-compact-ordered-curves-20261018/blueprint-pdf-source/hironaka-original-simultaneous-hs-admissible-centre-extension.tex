Bierstone--Milman\cite{bierstone-milman97-invent-math}, Lemma 13.7,
printed page 300, requires genuine centres on which the original invariant

\begin{lemma}[A true finite family of original coherent ideals attains an actual simultaneous whole-profile maximum on any nonempty compact set]
\label{hir:actual-finite-family-compact-all-hs-constant-cut}
\uses{hir:actual-original-compact-intrinsic-hs-lexicographic-maximum,hir:actual-ambient-hs-whole-superlevel-analytic}
\source{bierstone-milman97-invent-math:page-0094}
\lean{Hironaka.HironakaOriginalSimultaneousHSAdmissibleCentre.finiteReferenceHSCut,Hironaka.HironakaOriginalSimultaneousHSAdmissibleCentre.exists_actual_finite_compact_constant_hs_cut}
\leanok
ONLY a finite family of actual coherent original ideals and an ACTUAL
nonempty compact set $K$ internally select $a\in K$ such that the literal
componentwise ALL-order upper cut on $K$ equals the ENTIRE simultaneous
profile equality locus. If $K$ is analytic, this actual cut is nonempty,
analytic and compact. Empty ideal families are included. No selected point,
maximum, HS-profile, finite-order or cut certificate is input.
\end{lemma}
\begin{proof}
Use the actual finite enumeration and genuine natural pairing to enumerate
EVERY pair consisting of a family position and an HS order by one countable
sequence; unused codes have the actual constant zero coordinate. Original
coherence gives true upper semicontinuity of EACH EXISTING intrinsic HS
coordinate. On the actual compact subtype, the proved nested-coordinate
maximum construction internally selects a genuine point. If another point
dominates EVERY actual family/order coordinate, it dominates EVERY code;
the actual whole-profile maximum dictionary forces equality at ALL codes.
Evaluate the genuine code of EACH position/order for the reverse dictionary.
The actual cut is $K$ intersected with FINITELY many true all-order HS
superlevels. Those are independently analytic, hence closed. Their literal
intersection contains $a$ and is a closed subset of the true compact $K$.
This supplies all geometry before the cut is used as a centre input.
\end{proof}

\begin{theorem}[ONLY original-domain, actual canonical prefix, compact current cosupport and finite coherent-family inputs construct a genuine ORIGINAL-admissible centre with ALL simultaneous profiles constant]
\label{hir:original-current-compact-full-invariant-simultaneous-hs-first-centre}
\uses{hir:actual-finite-family-compact-all-hs-constant-cut,hir:original-all-depth-arbitrary-full-history-global-analytic,hir:original-full-reference-original-only-auxiliary-marked-domain}
\source{bierstone-milman97-invent-math:page-0094}
\lean{Hironaka.HironakaOriginalSimultaneousHSAdmissibleCentre.exists_original_current_compact_simultaneous_first_centre}
\leanok
For an ACTUAL canonical prefix of the ORIGINAL marked input, assume ONLY
that its true current cosupport is nonempty and compact, and supply any
finite family of actual coherent ideals on that current original manifold.
Internally construct a nonempty smooth closed centre $C$ admissible for the
SAME actual current ORIGINAL marked record. The ORIGINAL full invariant
is constant on $C$ at its actual GLOBAL current maximum; EVERY member's
EXISTING intrinsic HS profile is constant there at EVERY order.
No desired centre, global maximum, auxiliary domain, original admissibility
or simultaneous-constancy certificate is input. The selected centre is not
claimed to equal the original invariant's entire maximum locus.
\end{theorem}
\begin{proof}
The actual original invariant USC and true current compactness internally
attain its genuine GLOBAL maximum $b$. Its literal maximum locus $L$ is
nonempty, compact and smooth closed by the PROVED original admissible-level
geometry. It equals the actual full threshold at $b$ in BOTH directions,
so the independently proved arbitrary original-history threshold theorem
gives its true GLOBAL analyticity. Apply the preceding simultaneous
whole-profile producer on THIS actual $L$. It constructs a genuine point
and a nonempty analytic compact simultaneous cut $S\subset L$ on which
ALL positions and orders are constant.

The original current cosupport is genuinely thin; hence this actual $S$
is ambient thin. Its genuine coherent reduced vanishing ideal, true
universal carrier, mark one and SAME original current ordered boundary
therefore form a real auxiliary original-domain input, internally.
Choose the actual global maximum of its true canonical invariant on its
compact cosupport $S$. The PROVED original producer gives a nonempty smooth
closed centre NC with that SAME actual ordered boundary. Its true cosupport
containment gives $C\subset S\subset L$. Thus it lies in the ORIGINAL current
cosupport and has NC with the ORIGINAL current boundary: these are exactly
the remaining real original marked-admissibility fields. The containment
in $L$ makes the original FULL value constant, and containment in $S$ makes
EVERY original HS order in EVERY family position constant. No comparison
between the original and auxiliary invariant is assumed.
\end{proof}
