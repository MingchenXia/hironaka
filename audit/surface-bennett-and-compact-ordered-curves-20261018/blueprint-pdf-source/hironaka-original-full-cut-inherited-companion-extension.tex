\section{Actual FULL original cuts induce entire companion Step One cuts}

A next companion TEST alone does not supply the whole Step One cut needed
by recursive member/contact preparation. We derive this exact input from
unchanged original FULL values and the true fixed-companion threshold
dictionary, retaining its original order head, mask and every history position.

\begin{theorem}[Original whole FULL cuts construct actual companion membership and all Step One bounds]
\label{hir:original-full-cut-inherited-companion-stepone-cut}
\uses{hir:original-frozen-companion-domain-whole-cosupport,hir:original-frozen-companion-whole-value-dictionary}
\lean{Hironaka.HironakaOriginalFullCutInheritedCompanion.original_full_cut_inherited_companion_values}
\leanok
Let $n>0$, $M\in\mathrm{DOMAIN}(k+1)$, and let $T$ be CAN for the unchanged
original full invariant of depth $k+1$. Fix an actual old upper cosupport
reference $y$ with actual positive nonmonomial order $q$. Compute its original
order-regime head $H$, tail $S$, actual order mask $W$ and companion $J$.
Take a genuine next ORIGINAL-admissible centre $C$ whose FULL value at EVERY
point of $C$ is at least the original FULL value at EVERY old upper cosupport
reference. At EVERY actual centre trace point $c\in S^{-1}W$ over $C$, prove
\[
 c\in\operatorname{cosupp}J_{S|_W},\qquad
 \forall p\in\operatorname{cosupp}J_{S|_W},\quad
 \operatorname{StepOne}_{k}(J,S|_W,p)
 \le\operatorname{StepOne}_{k}(J,S|_W,c).
\]
The SAME original companion and actual canonical tail serve all points.
No companion membership, Step One cut or numerical comparison certificate
is a caller input.
\end{theorem}
\begin{proof}
Original canonical data supplies the genuine frozen companion DOMAIN,
maximal order and Step One CAN prefix, its real reference mask point, and
the entire companion cosupport dictionary. In particular the actual old
reference gives a true companion cosupport point.

Take any actual old companion cosupport point $p$. Its genuine fixed-record
value formula expresses the original FULL value at its underlying upper
point as $(q,\operatorname{inr}(\operatorname{coe}\operatorname{StepOne}_k
(J,S|_W,p)))$. The whole original cut at that upper point therefore places
EVERY actual centre trace point in this literal original FULL superlevel;
actual original admissibility supplies its original upper cosupport.
Apply the proved ENTIRE original fixed-companion threshold dictionary with
this exact finite Step One threshold. It internally uses the real mask/order
bound and original value formula to give BOTH actual companion membership
and the true finite-to-top inequality at the centre trace point. Reflect
that inequality through the genuine finite-to-top order embedding to obtain
the original Step One bound. First apply this argument to the actual
reference point to construct centre companion membership; then apply it to
EVERY actual old companion point for the entire cut. Neither point chooses
another companion or lower reference.
\end{proof}

\begin{theorem}[Actual original preparation supplies complete genuine companion preparation data]
\label{hir:original-full-cut-genuine-companion-stepone-preparation}
\uses{hir:original-full-cut-inherited-companion-stepone-cut,hir:original-full-value-cut-next-companion-test-domain,hir:original-frozen-companion-domain-whole-cosupport}
\lean{Hironaka.HironakaOriginalFullCutInheritedCompanion.original_full_cut_prepared_companion_data}

\end{theorem}
\begin{proof}
The real original frozen-companion producer supplies the initial DOMAIN,
maximal order and SAME old Step One CAN prefix. The original full-cut
companion TEST producer applies to the actual original blowup and the cut
at the actual reference point, constructing the genuine appended companion

constructs actual companion membership and the bound from EVERY old Step
One value at every actual centre trace point. Those two outputs are exactly
the definition of membership in the whole Step One maximum locus on the
old companion cosupport. No lower numerical cut, desired TEST or point is
assumed. This is the real companion preparation input for the further

FULL value naturality, next canonicality, exceptional semicoherence or
general preparation termination.
\end{proof}
