\section{Genuine full-cut source preparation preserves the GIVEN prefix}

Recursive comparison of independent source choices needs an actual source
canonical prefix followed by a true source preparation. We construct it from
the given actual smooth Cartesian history and original target cuts, rather
than adding source canonicality or a numerical comparison as a certificate.
The source centre may be empty if the actual map misses the target centre.

\begin{theorem}[Actual old Cartesian histories internally transport the whole original preparation cut]
\label{hir:original-full-cut-genuine-source-preparation-data}
\uses{hir:smooth-original-recursive-family-values-canonical,hir:submersion-relative-control-joint-tower,hir:smooth-actual-value-recursive-dimension-maps}
\lean{Hironaka.HironakaOriginalFullCutSourcePreparation.original_full_cut_source_data}
\leanok
Let $n,m>0$, $M\in\mathrm{DOMAIN}(k)$, and let $T$ be CAN for the original
depth-$k$ full invariant. Take ANY GIVEN actual smooth Cartesian history
$h:f,Q,T,g$. Take a genuine ORIGINAL-admissible target centre $C$ above the
original FULL value of EVERY old target cosupport reference. Set
$r=m-n$ and $K=f^*M$. Internally construct original DOMAIN$(r+k)$, actual
source TEST and original source CAN of the SAME $K,Q$, real original source
admissibility of the actual centre $g^{-1}C$, and the ENTIRE source cut
\[
 \forall x\in\operatorname{cosupp}K_Q\;\forall c\in g^{-1}C,\qquad
 \operatorname{inv}_{r+k}(K,Q,x)\le\operatorname{inv}_{r+k}(K,Q,c).
\]
No source CAN, cut, nonempty centre or numerical isomorphism is supplied.
\end{theorem}
\begin{proof}
The actual given tower constructor supplies the true initial submersion.
Original domain pullback produces the genuine source dimension bound with
its added fibre dimension. The original actual recursive family theorem
internally transports OLD canonicality and exact FULL values along this
SAME given history. Genuine relative controlled-history transport supplies
its actual source TEST, entire current marked-record pullback and BOTH
current cosupport directions.

Actual current submersion and target original centre admissibility pull
back its true closed smooth geometry, upper cosupport condition and normal
crossings. The entire current-record equality identifies this with actual
source admissibility for $K_Q$, rather than for a rebased record.
Take any source cosupport reference and actual source centre point. The
whole cosupport dictionary puts the former's actual image in target
cosupport; target admissibility puts the latter's actual image there too.
Original old FULL-value naturality applies at BOTH exact points. The genuine
strictly monotone dimension-family map preserves the target cut inequality,
and the two true value identities give the claimed ORIGINAL source cut.
Neither surjectivity nor existence of a source centre point is assumed.
\end{proof}

\begin{theorem}[The SAME given source prefix receives a genuine actual next preparation blowup]
\label{hir:original-full-cut-actual-source-prefix-extension}
\uses{hir:original-full-cut-genuine-source-preparation-data,hir:submersion-cartesian-tower-actual-history,ana:blowup-existence,bcalc:inv-domain-stable}
\lean{Hironaka.HironakaOriginalFullCutSourcePreparation.exists_actual_full_cut_source_extension}
\leanok
Under exactly those SAME original inputs, take an actual target blowup
$\pi$ along $C$. Internally construct an actual source blowup $\rho$ along
$g^{-1}C$ and its true holomorphic lift, so the SAME GIVEN source prefix
$Q$ is extended by this real step and is actually Cartesian over $T\pi$.
The source step is proper and holomorphic, its actual appended source
history is a genuine TEST, and its actual transformed record is well formed
with the literal ordered whole strict-boundary-plus-exceptional SNC list.
The OLD source CAN and entire source cut are already constructed; next
source CAN is not asserted.
\end{theorem}
\begin{proof}
The first theorem constructs actual old source domain, TEST, canonicality,
source admissibility and the whole source cut. Genuine domain transport
along its actual old TEST supplies current source DOMAIN. Its cosupport
has empty interior by the original nonzero-domain theorem, so the actual
admissible centre, a subset of that cosupport, also has empty interior.
Actual blowup existence on this true closed smooth centre now supplies the
source manifold and real blowup; no compactness or desired lift is input.

Use the actual current submersion and TWO genuine blowups in the actual
universal lift constructor. It extends the SAME given Cartesian history,
with the original target step and the real source centre trace. Actual
source admissibility appends its genuine source TEST. The actual blowup
itself supplies properness and holomorphicity; genuine marked-transform
wellformedness supplies the exact ordered SNC list. Empty source centres
remain real steps. No replacement source prefix, fabricated nonempty centre,
source cut certificate or new canonicality is used.
\end{proof}
