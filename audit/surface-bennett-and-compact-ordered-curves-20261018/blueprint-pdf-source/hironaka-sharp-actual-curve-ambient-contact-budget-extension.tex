\section{A genuine decreasing ambient-contact budget above actual exceptional-difference points}

The literal $\tau_D$ of \cite[Lemma~12.8, p.~295]{bierstone-milman97-invent-math}
need not decrease at every blowup: a remaining exceptional power can require
several steps. On a curve the genuine ambient contact orders give an
independent natural-valued budget. This chapter proves its decrease for
ACTUAL original-admissible steps; it does not supply a selected centre or
replace the refined monomial driver by a desired decrease certificate.

\begin{theorem}[The actual original-member ambient-contact budget loses exactly the actual incident-position count]
\label{hir:sharp-original-curve-actual-ambient-contact-budget-recurrence}
\uses{hir:sharp-original-curve-mixed-new-exceptional-exponent-evolution}
\lean{Hironaka.HironakaSharpActualCurveAmbientContactBudget.actualAmbientContactBudget,Hironaka.HironakaSharpActualCurveAmbientContactBudget.actualAmbientIncidentPositions,Hironaka.HironakaSharpActualCurveAmbientContactBudget.original_curve_actual_contact_budget_evolution}
\leanok
Define the ACTUAL ambient-contact budget, independently of any decrease,
by the literal sum over ORIGINAL member positions
\[
 B_T(x)=\sum_{i\in\operatorname{Fin}|E|}
  \operatorname{ord}_{N_T,x}
   (\operatorname{Res}_{N_T}\mathcal I_{\operatorname{strictAlong}(T,E_i)}),
\]
and define $A_T(x)$ as the actual finite set of ORIGINAL positions whose
literal ambient strict member contains $x$.
ONLY original closed smooth curve $W$, actual ambient SNC $E$, true
whole-family density, ANY ORIGINAL mark-one product test $T$, an ACTUAL
next original-admissible centre $C$ and the SAME genuine blowup $\pi$
internally give, at EVERY new strict-carrier point $z$ above $C$,
\[
 B_{T'}(z)+|A_T(\pi z)|=B_T(\pi z),\qquad T'=T\mathbin{+}(C,\pi).
\]
This is the sum of TRUE ambient trace orders, not residual orders or a
distinct-trace quotient count; all original positions and multiplicities
are retained, including the empty-family case.
\end{theorem}
\begin{proof}
The preceding original-only genuine mixed-centre theorem internally
supplies, for EACH original position, its actual new ambient trace order
plus the true incidence indicator equal to its actual old normalized
ambient trace order. Sum THESE genuine equations over the literal finite
original index set. The actual step equations for the unchanged geometric
template and EXISTING ambient strictAlong identify the summed new terms
with the independently defined new budget. True finite sum distributivity
and the genuine indicator/cardinality identity identify the remaining
sum with the ACTUAL filtered original-position cardinality. Thus the
displayed equation is proved from the real geometry, not supplied as an
input invariant property.
\end{proof}

\begin{theorem}[The genuine natural budget strictly decreases above every actual old exceptional-difference point]
\label{hir:sharp-original-curve-actual-tauD-point-contact-budget-strict-drop}
\uses{hir:sharp-original-curve-actual-ambient-contact-budget-recurrence,hir:sharp-original-curve-actual-tauD-exact-support}
\lean{Hironaka.HironakaSharpActualCurveAmbientContactBudget.original_curve_contact_budget_strict_drop_above_actual_difference}
\leanok
Under the SAME ONLY original hypotheses and ACTUAL original-admissible next
step, if $z$ is on its true new carrier, $\pi z\in C$ and
$\pi z\in\Delta_T$ for the independently defined actual $I/J$ exceptional
difference, then
\[
 B_{T'}(z)<B_T(\pi z).
\]
No budget-decrease, nonempty-index or desired exceptional-difference
support certificate is supplied. Membership in the genuinely defined old
difference is the literal point condition, not an assumed transformation law.
\end{theorem}
\begin{proof}
The independently proved exact actual difference support identifies the
old point with a point of the actual carrier, an actual accumulated
exceptional member and at least one LITERAL original ambient strict
member. The last condition supplies a genuine ORIGINAL position in
$A_T(\pi z)$; hence that actual finite cardinality is positive. The first
theorem independently gives the exact budget equation on this SAME blowup
at this actual point. Natural-number arithmetic with this positive
cardinality yields the strict inequality. No assertion that $\tau_D$
itself drops is made.

The actual choice of centres INSIDE $\Delta_T$, their ORIGINAL positive
record admissibility, the full old-exponent dictionary and a global
refined driver/termination remain separate OPEN producers. In particular,
mere containment in the current carrier does not establish original
positive-record admissibility. FIRST $Z$, this actual difference and full
sharp $\Sigma$ remain distinct, and the real $I=D J$ normalization is
retained throughout.
\end{proof}
