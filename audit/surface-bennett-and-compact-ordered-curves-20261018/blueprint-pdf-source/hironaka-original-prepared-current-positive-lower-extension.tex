\section{Actual newly computed positive lower data after a genuine cut}

The old positive reference record and the newly computed record need not have
the same regime head. A true next lower TEST must therefore be constructed
before its current domain or point is used. We retain the literal original
Step One function, selected-member record, masks and every empty position.

\begin{theorem}[Real increment or reset constructs the computed positive lower TEST]
\label{hir:original-prepared-current-positive-lower-test}
\uses{hir:original-positive-stepone-cut-actual-lower-test,hir:step-one-value-masked-basic,hir:regime-run,hir:step-one-seq}
\lean{Hironaka.HironakaOriginalPreparedCurrentPositiveLower.current_positive_lower_test_after_cut}
\leanok
Let $n>0$, let $M$ have original DOMAIN$(k+1)$ and maximal order, and let
$T$ be an actual CAN prefix for the unchanged original Step One invariant
built from the original depth-$k$ invariant. Take a genuine next
ORIGINAL-admissible centre $C$ and actual blowup $\pi$. Suppose that for
EVERY old nonspecial current cosupport point of positive level its original
Step One value is at most the value at EVERY point of $C$.
Fix an actual new upper cosupport point $z$ and any positive regime label
$s+1$. In the ACTUAL new history $P=T\pi$ compute
\[
 r=\operatorname{regimeRun}(\operatorname{stepRegime}_{s+1},P,z),\quad
 H=\operatorname{head}(P,r),\quad S=\operatorname{tail}(P,r),\quad
 W=\operatorname{lowerMask}(M,s+1,H,Sz),\quad
 J=\operatorname{lowerMarked}(M,s+1,H,Sz).
\]
Then the actual restricted $S|_W$ is a genuine TEST of this SAME computed
$J$. No lower TEST, regime equation or new canonicality is an input.
\end{theorem}
\begin{proof}
Old original canonicality gives the actual upper TEST. Genuine next
admissibility extends this TEST. Current upper membership and genuine
cosupport inheritance give old upper membership of $\pi z$.
Decide the actual OLD predicate
$\operatorname{stepRegime}_{s+1}(T,\pi z)$.
If it holds, it supplies the actual old positive level and nonspeciality.
The stated real whole-cut condition applies to this exact old point, so the
proved old positive-cut theorem constructs the actual extended TEST of its
SAME old selected lower record. The literal original regime recursion makes
its new run the old run plus one. Genuine head/tail successor equations then
identify the NEW computed head and tail with that exact old head and its
appended blowup. Its selected mask and record consequently agree literally,
and the constructed TEST is precisely the required NEW computed TEST.
If the old predicate fails, the literal original recursion makes the NEW
run zero. Its actual tail is reflexive, including the real current endpoint
and its original selected record. Its actual restricted tower is reflexive,
so it is a genuine TEST directly. No step or empty position is deleted, and
no implication from next TEST to next CAN is used.
\end{proof}

\begin{theorem}[Actual positive current lower domain and membership are constructed]
\label{hir:original-prepared-current-positive-lower-domain-point}
\uses{hir:original-prepared-current-positive-lower-test,hir:step-one-canonical-tail,hir:step-one-value-masked-basic,hir:step-one-compare,hir:regime-run}
\lean{Hironaka.HironakaOriginalPreparedCurrentPositiveLower.current_positive_lower_data_after_cut}
\leanok
Under exactly those original hypotheses, let the actual new upper cosupport
point $z$ be nonspecial with actual level $s+1$. For the SAME newly computed
$H,S,W,J$, internally construct all of
\[
 J\in\mathrm{DOMAIN}(k),\quad S|_W\text{ is TEST of }J,\quad
 J_{S|_W}\in\mathrm{DOMAIN}(k),\quad
 Sz\in W,\quad (z,Sz\in W)\in\operatorname{cosupp}J_{S|_W}.
\]
Moreover at EVERY actual endpoint-mask point $p$ one has BOTH directions
\[
 p\in\operatorname{cosupp}J_{S|_W}\ \Longleftrightarrow\
 p\in\operatorname{cosupp}M_P\ \text{and}\
 \operatorname{level}(M,P,p)=s+1.
\]
The point in the lower cosupport is an output, not a hypothesis.
\end{theorem}
\begin{proof}
Actual original admissibility and coefficient-homogenized equivalence first
give the genuine extended bar TEST and its whole current cosupport equality.
Thus the actual new upper point belongs to this bar cosupport. Its genuine
nonspeciality gives the real start-of-regime head predicate and head
cosupport, with the actual current level. Transport the stated level equation
through this genuine dependent head/tail data, retaining its exact point.
The head of the genuine bar TEST is again a genuine TEST. The actual
masked-lower domain theorem applied at that exact head supplies its true
mask membership and original DOMAIN$(k)$; its dimension bound comes from the
original DOMAIN$(k+1)$, with no caller lower-domain certificate.

The first theorem constructs the true newly computed restricted lower TEST
before any lower current domain is asserted. Genuine domain transport now
gives its actual current DOMAIN$(k)$. Apply the proved whole masked lower
cosupport dictionary using this real TEST, the constructed head cosupport,
regime and mask point. The literal head/tail append equation and actual bar
cosupport equality yield the displayed iff at EVERY actual mask point.
The original upper point and its stated actual level then give actual lower
membership by the reverse implication. No current lower point, next CAN,
lower maximum, arbitrary noncanonical full-value law, zero-contact bridge,
or general preparation termination is assumed or concluded.
\end{proof}
