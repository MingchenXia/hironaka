\section{Prepared bound-two FULL values on actual open histories}

The first numerical slice of joint SOURCE-bound induction is bound two.
After one genuine original-admissible preparation above the full old cut,
the appended history is an actual TEST; its next canonicality is not known.
We prove locality of the unchanged original FULL values on its genuine open
restrictions. This is a prepared-history result at every depth $d+2$,
not an assertion about arbitrary noncanonical histories or larger bounds.

\begin{theorem}[Actual open restriction preserves prepared bound-two FULL values]
\label{hir:original-prepared-bound-two-open-full-locality}
\uses{hir:original-domain-two-prepared-full-general-smooth-values,hir:original-untested-source-open-actual-cartesian-history,hir:original-zero-fibre-value-maps-identity}
\lean{Hironaka.HironakaOriginalPreparedBoundTwoOpenLocality.prepared_bound_two_full_value_restrict_open}
\leanok
Let $n>0$, let $M\in\mathrm{DOMAIN}(2)$, and let $T$ be CAN for the
unchanged original depth-two FULL invariant. Let $C$ be a genuine
ORIGINAL-admissible centre above the FULL value of every old cosupport
reference, and let $\pi$ be an actual blowup along $C$.
Write $P=T\pi$. For ANY actual ambient open $U$, ANY actual endpoint
$z$ of the literal restricted history $P|_U$ whose underlying point is in
the current cosupport of $M_P$, and EVERY $d\in\mathbb N$, prove
\[
 \operatorname{inv}_{d+2}(M|_U,P|_U,z)
   =\operatorname{inv}_{d+2}(M,P,|z|).
\]
The source record is the actual smooth marked pullback along the open
inclusion, and the source tower is exactly the literal restriction, with
all empty positions retained. No source TEST, value identity or next CAN
is supplied as a certificate.
\end{theorem}
\begin{proof}
Induction on the actual original history constructs its open-inclusion
Cartesian history: each restricted centre and blowup is the real inverse
image and actual restricted blowup, and its actual terminal map is the
subtype inclusion. Apply the proved prepared bound-two FULL smooth-value
theorem to this SAME restricted source history. The stated entire old
cut supplies its positive-reference subcondition. Thus the unchanged
source FULL value at depth $(n-n)+d+2$ equals the genuine dimension-family
map of the target value at depth $d+2$.

Now $n-n=0$. The genuine zero-fibre dimension-family map is the identity
on EVERY recursive value, proved by recursion on the actual value type.
Transporting the equality only along the true natural-number equality
$0+(d+2)=d+2$ gives the claimed equality. Its left transport is the
actual original invariant at the equal depth, by equality elimination.
This uses no attained-value proxy or arbitrary comparison certificate.
\end{proof}

\begin{theorem}[Nested actual open restrictions have the SAME prepared FULL value]
\label{hir:original-prepared-bound-two-nested-open-full-locality}
\uses{hir:original-prepared-bound-two-open-full-locality}
\lean{Hironaka.HironakaOriginalPreparedBoundTwoOpenLocality.prepared_bound_two_full_value_nested_open}
\leanok
Under exactly those same original inputs, let $V\subseteq U$ be genuine
ambient opens. At every actual endpoint $z$ of $P|_V$ lying in the
original current cosupport and every depth $d+2$, the unchanged FULL
value on $P|_V$ equals the unchanged FULL value on $P|_U$ at the actual
included endpoint $\langle |z|,V\subseteq U\rangle$.
Both source records are the true original marked open pullbacks.
\end{theorem}
\begin{proof}
The inclusion $V\subseteq U$ proves actual membership of the SAME
underlying endpoint in the terminal open of $P|_U$, using the literal
definition of the terminal inverse image. Apply the first theorem to
$V$ and to $U$ at those exact endpoints. Both resulting right sides are
the SAME original post-step FULL value at the SAME underlying point.
Transitivity with the inverse of the second equality gives the result.
No new canonicality, numerical tower-isomorphism axiom, artificial
endpoint, or deleted empty centre is used. In particular this comparison
is available for actual OWN-small and OWN-large opens when their source
carrier bound is two. Larger-source induction and its contact-model
comparison remain separate obligations.
\end{proof}
