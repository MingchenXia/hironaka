\section{The actual companion middle between two genuine order-run starts}

\begin{theorem}[Construct the real middle, ALL earlier-mask avoidance and the whole companion rebase]
\label{hir:original-finite-order-cut-actual-middle}
\uses{hir:original-finite-order-cut-history,hir:original-finite-order-cut-before-run-start,hir:original-finite-order-cut-companion-rebase,hir:step-one-nearby,bcalc:companion-rebase}
\lean{Hironaka.HironakaOriginalFiniteOrderCutMiddleHistory.orderCutTower_head,Hironaka.HironakaOriginalFiniteOrderCutMiddleHistory.exists_actual_middle_of_order_cut}
\leanok
Let an original DOMAIN$(b)$ marked ideal in positive ambient dimension
have a literal finite order-cut history. Fix a genuine current cosupport
point of positive order $q$, and any second actual endpoint whose actual
order-$q$ run is at least as long. Internally construct the actual middle
tower from the second run's head to the first run's head. Its genuine head
and tail concatenations are the original heads and tails, every centre
misses the actual earlier order mask, and the original companion formed
at that earlier head transported across this true restricted middle is
whole-relative-ideal equivalent to the actual companion formed at the
later head on the SAME inverse-image open. No middle, avoidance,
canonicality or rebase certificate is a caller input.
\end{theorem}
\begin{proof}
Actual prefix recursion first preserves the literal order-cut recipe at
every genuine head. If the two run lengths are different, use the true
split theorem to expose the ONE actual step from the stage immediately
before the shorter run starts, and split again between that preceding
stage and the earlier head of the longer run. The first step really has
length one, by the actual head-length equations and the genuine run-length
bound. Hence its true tower constructor supplies the actual centre,
projection and blowup proof. Append it to the other actual middle; the
two literal split equations give BOTH required original concatenations.

The already proved genuine before-run theorem puts the original reference
image immediately before its run in the actual cosupport with order at
least $q+1$. Rewrite this image through the two TRUE split equations. The
internally inherited cut recipe for the actual shorter head lets the
proved all-centre threshold and avoidance theorem apply to this very
middle-with-last-step. The earlier mask itself supplies its genuine
order-$q$ bound, so every actual middle centre is avoided. If the two runs
are equal, the actual split theorem instead constructs a genuine
zero-length middle. Its length equation proves actual centre avoidance;
no original history position is deleted or compressed.

In either case the true original head and concatenation TESTs give
DOMAIN on the earlier head and the real middle TEST. Apply the actual
companion-rebase theorem to the internally proved ALL-centre avoidance.
Finally, genuine whole transform concatenation identifies the transported
original record with the original transform at the later head. This yields
the stated whole relative-ideal equivalence on the SAME actual open.
There is no assertion that a numerical invariant descends across arbitrary
noncanonical lower histories; that further numeric interface and the
global driver remain open.
\end{proof}
