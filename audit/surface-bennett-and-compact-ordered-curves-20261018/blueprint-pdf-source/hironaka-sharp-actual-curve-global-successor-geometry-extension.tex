identifies this composite with the actual global successor. Local equality
therefore proves its holomorphicity at the original point.

For surjectivity represent an arbitrary preceding global point by a real
preceding local point. The actual next arrow is a genuine original blowup;
its actual one-step blowup sequence is surjective. Choose the supplied
actual next local point and include it into the genuine next quotient.
The real local component formula sends that global point to the given
preceding point. This covers the entire preceding quotient, including
all exceptional fibres and real empty-identity stages.
\end{proof}
