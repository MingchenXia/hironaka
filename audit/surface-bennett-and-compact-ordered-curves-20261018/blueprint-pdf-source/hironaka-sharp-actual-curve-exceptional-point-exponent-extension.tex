\section{The actual remaining exceptional factor on a curve has the computed contact exponent}

The factor in $I'=D'J'$ is an actual greatest exceptional factor, not a
replacement residual. Compute its genuine exponent and every relative
member germ from the old contact using the real first-step geometry.
This supplies a numerical input for the separate $\tau_D$ phase of
\cite[pp.~293--295]{bierstone-milman97-invent-math}.

\begin{theorem}[A genuine transverse curve member makes nearby divisibility exactly the actual point order]
\label{hir:sharp-actual-curve-member-exponent-equals-point-order}
\source{bierstone-milman97-invent-math:page-0087}
\uses{hir:sharp-actual-transverse-curve-member-isolating-open,hir:exponent-along,hir:sharp-original-empty-boundary-ordinary-trace-order-dictionary}
\lean{Hironaka.HironakaSharpActualCurveExceptionalPointExponent.actual_curve_member_divExp_eq_ordinaryTraceOrder}
\leanok
For an actual closed smooth carrier, actual SNC boundary transverse to it,
ANY coherent ideal nonzero along the whole carrier, and an actual incident
point where the carrier is a genuine curve, the TRUE exponent along that
actual member equals the EXISTING ordinary trace order at that point.
No isolating neighborhood, order or exponent certificate is supplied.
\end{theorem}
\begin{proof}
Genuine simultaneous SNC coordinates, actual curve dimension uniqueness
and the real free member coordinate supply an actual neighborhood where
the member's trace on the carrier is the singleton point. For EVERY
integer $q$, the literal nearby-divisibility predicate implies point
cosupport by evaluation at that actual point. Conversely point cosupport
implies nearby divisibility: every carrier/member point in that actual
isolating neighborhood is precisely the same point. Thus BOTH actual
nearby-divisibility and point-cosupport predicates agree.

A real carrier retraction and the actual nonzero germ make its true
exceptional exponent finite. The true maximal-divisibility equivalence
and EXISTING finite ordinary-order/cosupport dictionary now apply to these
independently constructed objects. Apply the two predicate directions at
the actual exponent and at the actual ordinary order. The resulting two
integer bounds prove equality, without an assumed discrete divisor model.
\end{proof}

\begin{theorem}[The true first remaining exceptional factor has old curve contact minus one]
\label{hir:sharp-actual-first-curve-remaining-factor-computed-exponent-germs}
\source{bierstone-milman97-invent-math:page-0087,bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-actual-curve-member-exponent-equals-point-order,hir:sharp-actual-first-curve-ambient-strict-contact-drop,hir:sharp-actual-first-ambient-strict-trace-relative-generators,hir:sharp-actual-first-ambient-strict-trace-greatest-factor-relative-strict}
\lean{Hironaka.HironakaSharpActualCurveExceptionalPointExponent.actual_first_curve_remaining_factor_exponent_and_germs}
\leanok
For ONLY original closed smooth curve $N$, singleton SNC $H$, genuine
density away from $H$, actual discrete $C\subset N\cap H$ and the SAME
actual blowup, put $D=\pi^{-1}C$, $I'=\operatorname{Res}_{N'}\mathcal I_{H'}$
and let $M'$ be its ACTUAL greatest monomial factor along $[D]$.
At EVERY actual $z\in N'\cap D$, writing the actual old contact as
$r=\nu_{\mathcal I_H,N}(\pi z)$, one has
\[
 e_D^{N'}(I',z)+1=r.
\]
Moreover EVERY ambient germ $g$ belongs to the TRUE $M'_z$ iff it is
holomorphic and its restriction to the actual carrier lies in the span
of the actual power $(\mathcal I_D^{\,r-1})_z$. This is a BOTH-direction
full relative germ dictionary, retaining carrier-normal germs.
\end{theorem}
\begin{proof}
The original-input first-step geometry independently supplies actual
strict-carrier smoothness, singleton exceptional SNC/transversality and
true strict-trace coherence/nonzero data. The genuine strict-carrier
dimension theorem internally preserves curve dimension at the actual
point. Apply the first theorem to THESE actual ideals and member; this
identifies the actual remaining exceptional exponent with the actual
strict-trace point order. The independently proved exact strict-trace
contact drop then gives the displayed numerical formula. In particular
its true exponent is $r-1$.

Now unfold the independently defined actual greatest monomial factor.
Its singleton list has exactly the true member $D$; both actual carrier
and incident memberships hold at $z$. Its defining full relative span
condition is therefore precisely the actual $D$ power at its true
exponent. Substitute the already proved numerical value in BOTH germ
membership directions. No power, monomial or desired generator model is
assumed. This gives the genuine remaining factor even when the separate
all-power residual $J'$ is unit. Mixed local centres and chronological
ambient factors, the global $\tau_D$ driver, full sharp $\Sigma$ and
termination are not inferred here.
\end{proof}
