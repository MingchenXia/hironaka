\begin{theorem}[Original level-cut histories construct every DOMAIN2 StepOne empty-prefix equality]
\label{hir:original-bound-two-stepone-empty-prefix-values}
\uses{hir:original-empty-prefix-current-source-lower-data,hir:original-empty-prefix-level-cut-tail-transport,hir:original-positive-empty-prefix-head-all-lower-values,hir:original-zero-empty-prefix-same-head-lower-values,hir:original-positive-empty-prefix-base-values,hir:original-zero-empty-prefix-base-values,hir:step-one-empty-prefix}
\lean{Hironaka.HironakaOriginalBoundTwoStepOneEmptyPrefix.step_one_values_empty_prefix}
\leanok
For an original DOMAIN2 marked ideal with actual maximal order, an actual
empty prefix followed by an ordinary original admissible level-cut history,
and ANY point in its actual current cosupport, the ENTIRE original StepOne
value at lower depth k+1 along the whole history equals that of the true
changed-source marked ideal along the tail. This holds for EVERY k and
EVERY such point. No lower DOMAIN, TEST, canonical segment, source cut,
value equality or source point certificate is input.
\end{theorem}
\begin{proof}
The original TEST/coeff-hom equivalence gives the actual old bar TEST.
The genuine empty-prefix level-cut theorem independently supplies the
source whole recipe; ordinary empty-prefix geometry supplies source
DOMAIN2 and maximal order. Actual append of controlled transforms supplies
the source current point. True level and special identities identify the
first coordinate and both special branches of the original StepOne value.
At a special point the two literal definitions therefore already agree.

At a nonspecial point construct, independently on BOTH genuine histories,
the actual original computed lower DOMAIN1, restricted TEST, mask point
and controlled cosupport. These are true finite-level-cut consequences,
not lower CAN data. The original regimes agree on each actual tail prefix.
If the source run is shorter than the tail, the genuine append-run and
whole split identities give the SAME actual tail, with the empty prefix
prepended only to the old head. At positive level the proved whole
member/mask relative-ideal comparison gives the lower equality at every
requested depth. At zero the independently constructed ordinary lower
geometry supplies exactly the hypotheses of genuine same-head contact
gluing. Thus the two finite lower values agree, retaining every original
boundary position and both independently chosen tangent directions.

If the source run covers the entire tail, its old run covers the entire
empty prefix as proved by actual backwards regime propagation. Both
true split heads are reflexive. The proved positive or zero run-crossing
base-value theorem, according to the actual level, gives the corresponding
lower-value equality from ONLY the original inputs. It internally builds
the intermediate reference geometry before the genuine curve rebase.
Substitute these equalities into the unchanged original nonspecial
StepOne definition. Together with the already identical level this proves
the ENTIRE value in both run cases. No canonical history or supplied
numerical comparison is introduced in any branch.
\end{proof}

\begin{theorem}[Whole original StepOne-cut histories construct their genuine empty-prefix tails]
\label{hir:original-bound-two-stepone-empty-prefix-cut-tail}
\uses{hir:original-bound-two-stepone-empty-prefix-values,hir:original-finite-stepone-cut-history,hir:original-finite-level-cut-history}
\lean{Hironaka.HironakaOriginalBoundTwoStepOneEmptyPrefix.step_one_cut_tail_empty_prefix}
\leanok
For the same original DOMAIN2/maximal-order and actual empty-prefix data,
an entire original StepOne-cut history at lower depth k+1 constructs an
entire original StepOne-cut history of the changed-source marked ideal
along the SAME tail. No source cut, source lower geometry or CAN is input.
The whole-centre comparison remains the original actual cut inequality;
no centre is asserted to equal the whole maximum locus.
\end{theorem}
\begin{proof}
Induct on the genuine tail constructors. The reflexive tail is a cut
history. At an actual next step, the old whole cut supplies its actual
preceding whole cut, original admissibility of the next centre, and the
original StepOne inequality at every old cosupport point against every
actual centre point. The true controlled append identity supplies source
next admissibility; this conclusion comes from geometry, not from a
numeric maximum assertion. The induction hypothesis supplies the source
preceding whole cut.

The old preceding StepOne cut gives the original preceding level-cut
history by its genuine first coordinate. At every source cosupport point,
the true controlled append identity supplies the old cosupport point.
Actual old centre admissibility separately supplies old cosupport
membership of every centre point. Apply the preceding entire-value theorem
at BOTH points, rewrite the original whole-centre inequality, and obtain
the source whole-centre inequality. Combine it with actual source
admissibility and the induction hypothesis to construct the next genuine
source cut. This retains every actual empty step. No next CAN, arbitrary
higher-carrier temporal equality, smooth positive-relative-dimension
naturality or global driver termination is claimed.
\end{proof}
