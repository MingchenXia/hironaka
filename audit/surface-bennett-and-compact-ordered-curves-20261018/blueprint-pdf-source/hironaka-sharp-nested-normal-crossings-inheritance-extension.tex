\section{Actual nested smooth-carrier normal crossings inheritance: Bierstone--Milman Lemma 12.7}

The true recursive boundary-intersection argument of printed page 294 needs a
geometric bridge from an actual smaller smooth carrier to the actual containing
smooth carrier. Here real original coordinates construct that bridge. No

\begin{lemma}[Actual noncontained smaller-carrier germs force free incident boundary coordinates]
\label{hir:sharp-nested-smaller-carrier-noncontained-germs-free-boundary-coordinates}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-original-multiboundary-pointwise-nc-open,bcalc:snc-simultaneous}
\lean{Hironaka.HironakaSharpNestedNormalCrossingsInheritance.exists_actual_free_family_of_germ_noncontainment}
\leanok
At a true point of the actual smaller carrier, its genuine pointwise NC family
and absence of any contained incident boundary germ internally give real common
coordinates in which every actual incident member coordinate is free on that
smaller carrier.
\end{lemma}
\begin{proof}
Use the SAME true NC coordinate family. Each incident actual member has a
one-coordinate zero equation. If that coordinate were a smaller-carrier
constraint, every actual nearby smaller-carrier point would lie in that
member. The real preferred-chart neighborhood and literal coordinate
membership laws would give precisely the forbidden contained germ. Thus the
actual original coordinates are free. This proves the required genuine
coordinate disjointness, rather than assuming target transversality.
\end{proof}

\begin{theorem}[Genuine smaller-carrier NC and noncontained germs construct actual containing-carrier NC]
\label{hir:sharp-actual-nested-normal-crossings-inheritance-lemma-12-7}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-nested-smaller-carrier-noncontained-germs-free-boundary-coordinates,bcalc:snc-simultaneous}
\lean{Hironaka.HironakaSharpNestedNormalCrossingsInheritance.actual_normalCrossingsAt_of_nested_germ_noncontainment}
\leanok
In positive ambient dimension, let actual $W\subset Y$ in the original ambient manifold, with $Y$ genuinely
closed smooth. At a point of $W$, if $W$ has actual NC with the original boundary
family and no incident member contains the genuine $W$ germ, then the SAME
$Y$ has actual NC with that SAME boundary family at the SAME point.
\end{theorem}
\begin{proof}
Use the preceding true smaller-carrier coordinates and independently supplied
smoothness coordinates of the actual containing carrier. Their genuine local
biholomorphic transition maps the smaller coordinate plane into the containing
coordinate plane, because actual $W\subset Y$. The original simultaneous-model
coordinate theorem, applied with an empty list of extra member replacements,
constructs new containing-carrier coordinates by changing only coordinates
among the smaller-carrier constraints. Consequently it preserves every real
free incident boundary coordinate. The containing carrier is now a true
coordinate plane, and each SAME incident original member remains a genuine
coordinate hyperplane. The actual model's centre image is zero: its constrained
coordinates vanish on the containing plane and its remaining coordinates are
preserved at zero. Compose the TRUE local biholomorphic maps with the SAME
preferred original chart. Both actual membership directions, true centering
and one-coordinate boundary cardinalities give literal containing-carrier NC.
No desired target chart, derivative-rank, NC or transversality certificate is input.
\end{proof}

\begin{theorem}[True original smaller-carrier density internally supplies the Lemma 12.7 geometric bridge]
\label{hir:sharp-original-density-nested-normal-crossings-inheritance}
\source{bierstone-milman97-invent-math:page-0088}
\uses{hir:sharp-actual-nested-normal-crossings-inheritance-lemma-12-7}
\lean{Hironaka.HironakaSharpNestedNormalCrossingsInheritance.actual_normalCrossingsAt_of_nested_density}
\leanok
In positive ambient dimension, for actual $W\subset Y$, true smoothness of $Y$, genuine density of $W$ off ALL
original members and actual smaller-carrier pointwise NC at a point of $W$,
the SAME containing carrier has actual NC with the SAME original members at
that point. No contained-germ exclusion or target NC witness is given.
\end{theorem}
\begin{proof}
If an incident original member contained the actual $W$ germ, the true
neighborhood containment and genuine smaller-carrier density off the whole
family would supply an actual nearby $W$ point both inside that member and
outside every original member, a contradiction. Thus original density
internally supplies each real noncontainment condition. Apply the preceding
genuine coordinate inheritance producer to the SAME actual nested carriers
and boundary. This supplies the geometric Lemma 12.7 consumer; it does not
construct the missing recursive resolving history, global first-phase $Z$
analyticity/restricted maximum driver or exceptional $\tau_D$ termination.
\end{proof}
