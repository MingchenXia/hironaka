\section{Actual recursive family values at smooth monomial leaves}

The original recursive value types change with dimension.  Smooth pullback
therefore compares the complete original family by its genuine fibre-dimension
embedding, preserving the whole indexed colex boundary.  We prove this actual
comparison at the monomial branch of every positive recursive depth and at
every original test stage.  This is the zero-nonmonomial-order branch in
W\l odarczyk's Step One/general construction, with the smooth functorial
interpretation of Bierstone--Milman
\cite{wlodarczyk05-hironaka,bierstone-milman08-functoriality}.

\begin{theorem}[Actual original family comparison at a monomial leaf]
\label{hir:smooth-original-family-monomial-leaf}
\source{wlodarczyk05-hironaka,bierstone-milman08-functoriality}
\lean{Hironaka.HironakaSmoothSubmersionActualFamilyMonomialLeaf.IsActualTowerPullback.actual_family_monomial_leaf}
\leanok
\uses{hir:smooth-actual-value-recursive-dimension-maps,hir:smooth-actual-value-original-stage-normalization}
Let the positive ambient dimensions be $n,m$, let $t=m-n$, and let
$f:Y\to X$ and $g:D'\to D$ form the actual smooth pullback of whole histories
$Q,T$.  Let $M$ lie in the original invariant domain of dimension $k+1$,
and let $T$ be an actual test history of $M$.  For $z\in D'$ suppose the
actual nonmonomial order of $M_T$ at $g(z)$ is zero.  Then
\[
 (R^{(m)}_{t+k+1})(f^*M,Q,z)
 =D_{t,k+1}\bigl((R^{(n)}_{k+1})(M,T,g(z))\bigr),
\]
where $D$ is the established strict map on the unchanged original value
types.  The source invariant domain with the true added fibre dimension
is supplied internally.  No source canonical history or value comparison
is assumed.
\end{theorem}
\begin{proof}
The original domain and true test history give a well-formed transformed
marked ideal and its genuine nonzero-along property.  The actual marked
pullback dictionary and smooth nonmonomial-order theorem then give actual
source order zero.  The domain pullback theorem gives dimension bound
$(k+1)+t=t+k+1$ and every other source-domain field internally.
Expand each actual successor-family invariant into its original general
step.  At the proved order-zero branch, that whole value is precisely
$(0,\operatorname{inl}\gamma)$, independently of its deeper companion.
The genuine whole stage gamma theorem gives source gamma equal to the
dimension-$t$ map of target gamma; its proof supplies the SNC cardinality
and actual fibre bounds internally and preserves every feasible subset
and its full colex index.  The original definition of $D_{t,k+1}$ maps
the entire left branch to exactly this value.  Thus the equality concerns
the complete actual original family value at both recursive depths.
\end{proof}

\begin{theorem}[Actual order reflection at two monomial leaves]
\label{hir:smooth-original-family-monomial-leaf-comparisons}
\source{wlodarczyk05-hironaka,bierstone-milman08-functoriality}
\lean{Hironaka.HironakaSmoothSubmersionActualFamilyMonomialLeaf.IsActualTowerPullback.actual_family_monomial_comparisons}
\leanok
\uses{hir:smooth-original-family-monomial-leaf,hir:smooth-actual-value-recursive-dimension-maps}
For two points $z,w$ of the same actual source history whose target
nonmonomial orders are zero, comparison of the two complete source family
values by $<$, $\leq$ or equality is equivalent to the corresponding
comparison of their two complete target family values.
\end{theorem}
\begin{proof}
Apply the preceding actual equality at both points.  Strictness of the
same dimension-$t$ map reflects and preserves strict order, weak order
and equality, yielding the three asserted equivalences.
\end{proof}

\begin{theorem}[Original input constructs all actual prefix comparisons]
\label{hir:smooth-original-family-monomial-leaf-prefixes}
\source{wlodarczyk05-hironaka,bierstone-milman08-functoriality}
\lean{Hironaka.HironakaSmoothSubmersionActualFamilyMonomialLeaf.exists_original_actual_family_monomial_prefixes}
\leanok
\uses{hir:smooth-original-family-monomial-leaf}
Given only the original smooth $f$, original domain $M$ and original test
history $T$, construct the actual whole source history $Q$ and its final
smooth map $g$.  It has the true transformed whole marked record, actual
testness, cosupport preimage and correct source invariant domain.  For
every literal prefix index $j$, construct its actual smooth stage map
$a_j$ internally.  At every source prefix point with target nonmonomial
order zero, the complete actual family value obeys the preceding dimension
formula, retaining the literal original $M$ and both entire prefixes.
\end{theorem}
\begin{proof}
The existing actual tower constructor applied to $f,T$ supplies $Q,g$
and its whole actual Cartesian witness.  The relative marked and cosupport
dictionaries give testness, the entire transformed marked record and
the stated cosupport preimage, using only original well-formedness.
The original domain pullback theorem supplies the correct source domain.
At index $j$, the genuine whole prefix constructor gives $a_j$ and the
actual Cartesian prefix witness.  The original test history supplies
testness of this literal target prefix.  Apply the first theorem to that
actual witness and every indicated point.  Every history, source-domain
field and prefix map is thereby produced internally from the original
inputs; no desired family comparison is a premise.
\end{proof}

Positive nonmonomial-order companion values, independent contact choice,
maximum existence and a full canonical driver remain further obligations.
No global monomialness, source compactness or smooth surjectivity is asserted.
