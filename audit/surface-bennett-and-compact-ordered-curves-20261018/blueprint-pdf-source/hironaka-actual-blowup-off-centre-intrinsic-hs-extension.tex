\begin{lemma}[A genuine biholomorphism pulls back the entire actual reduced vanishing ideal]
\label{hir:actual-biholomorphic-reduced-whole-ideal-and-hs}
\uses{hir:actual-biholomorphic-intrinsic-whole-ambient-hs-invariance,hir:base-change-open,ana:cartan-coherence}
\lean{Hironaka.HironakaActualBlowupOffCentreIntrinsicHS.actual_biholomorphic_pullback_vanishingIdeal,Hironaka.HironakaActualBlowupOffCentreIntrinsicHS.hilbertSamuelAt_vanishing_actual_biholomorphic}
\leanok

$W\subset X$, the genuine pullback of the ENTIRE original vanishing ideal
equals the genuine vanishing ideal of the literal preimage. Consequently
the EXISTING intrinsic reduced HS agrees at every actual point and EVERY order.
\end{lemma}
\begin{proof}
Apply the original genuine inverse-map vanishing-ideal transport theorem
with the actual inverse of $e$ and the identity auxiliary map. The identity
pullback vanishing ideal is the same original vanishing ideal, in both
germ directions, so this proves the full actual ideal equality before
using any HS assertion. Original Cartan coherence supplies the actual
coherent source ideal. The independently proved genuine biholomorphic
whole-stalk theorem now compares the SAME original maximal-ideal-power
quotients at EVERY order with their original complex actions.
\end{proof}

\begin{lemma}[The actual strict carrier on the source centre complement is the true biholomorphic reduced preimage]
\label{hir:actual-blowup-centre-complement-strict-carrier-dictionary}
\uses{hir:base-change-open,ana:strict-transform-blowup}
\lean{Hironaka.HironakaActualBlowupOffCentreIntrinsicHS.actual_strict_carrier_centre_complement}
\leanok

$\pi^{-1}(X\setminus C)$ is the actual preimage under the independently

\begin{proof}

set identifies actual strict membership there with genuine original

map $\pi$, giving BOTH stated set directions. No chosen comparison
carrier, reduced-ideal certificate, or HS equality is an input.
\end{proof}

\begin{theorem}[Every original intrinsic HS order is preserved by the actual strict blowup away from its centre]
\label{hir:actual-blowup-off-centre-intrinsic-reduced-hs}

actual $y\in X'$ with $\pi(y)\notin C$, and EVERY order $\ell$, the EXISTING
intrinsic reduced HS satisfies $H_{\mathcal I_{W'}}(y,\ell)=

\end{theorem}
\begin{proof}

Restrict its genuine reduced ideal to the actual source complement by
the already proved original open HS theorem. Replace that reduced
carrier by the preceding independently proved literal set equality.
Apply the genuine complement biholomorphism and the first theorem,
then apply actual open restriction on the target complement. These three
equalities compare the SAME existing intrinsic HS at every actual order.
Apply them separately at each order of the unchanged whole threshold
profile for BOTH full-condition membership directions. This proves the
actual centre-complement part only; exceptional nonincrease, a full
semicoherent HS presentation and a terminating singular-centre algorithm
remain OPEN.
\end{proof}
