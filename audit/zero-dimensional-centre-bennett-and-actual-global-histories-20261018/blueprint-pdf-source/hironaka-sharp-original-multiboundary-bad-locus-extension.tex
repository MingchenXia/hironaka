\section{The actual original multi-boundary sharp defect is closed and compact}

Here the original boundary is any finite closed list. The actual sharp

\begin{lemma}[The literal original pointwise NC set is open for the whole finite boundary]
\label{hir:sharp-original-multiboundary-pointwise-nc-open}
\source{bierstone-milman97-invent-math:page-0087}
\uses{hir:sharp-closed-coordinate-family-genuine-neighborhoods,hir:sharp-pointwise-normal-crossings-original-open-recognition}
\lean{Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.originalGoodLocus,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.isOpen_originalPointwiseNCSet,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.originalGoodLocus_eq_union,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.isOpen_originalGoodLocus}
\leanok
For closed original carrier $W$ and every actual member of a finite closed
boundary list $E$, the set of points with the literal original pointwise
normal-crossings witness for $W,E$ is open. The whole original good set
$W^c\cup\{x\in W:\operatorname{NC}(W,E,x)\}$ is consequently open.
\end{lemma}
\begin{proof}
At a true pointwise NC point use the independently constructed genuine
finite-closed-family neighborhood. Its real nearby preferred-chart
coordinates retain every actual membership equation. No new incident
boundary member appears, so every required cardinality-one condition is
inherited. Thus a genuine neighborhood lies in the literal original NC
set, proving its openness. The whole good set equals the union of this
open set and the open complement of the closed original carrier, by
splitting on original carrier membership. This proves whole-good-set
openness without a caller local normal form or preservation witness.
\end{proof}

\begin{theorem}[Original pointwise NC and density construct actual whole transverse boundary neighborhoods]
\label{hir:sharp-original-multiboundary-actual-transverse-neighborhood}

\lean{Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.exists_actual_original_transverse_neighborhood}
\leanok
At an actual original pointwise NC carrier point, for an original SNC
boundary and true carrier density away from the whole boundary, original
inputs construct an actual open neighborhood on which the literal
restricted boundary is SNC and transverse to the literal restricted
carrier. No transverse-neighborhood witness is supplied.
\end{theorem}
\begin{proof}
Use the independently constructed original NC open set as the actual
neighborhood. For each real carrier point, pull back its actual original
adapted-coordinate witness through the genuine open inclusion, retaining
the real finite boundary positions by the true list-map index dictionary.
The original boundary SNC pulls back through that same actual open
inclusion. True carrier density pulls back by its genuine open-map
closure dictionary; the original boundary union pulls back to the union
of the same actual list of restricted members. The genuine original
density-to-transversality theorem excludes any incident restricted
boundary coordinate from the carrier-defining coordinates. Thus the
whole produced original open has precisely the asserted actual geometry.
\end{proof}

\begin{lemma}[Actual transverse original member traces are proper and genuinely distinct germ ideals]
\label{hir:sharp-original-multiboundary-distinct-proper-trace-germs}
\source{bierstone-milman97-invent-math:page-0087}
\uses{hir:sharp-original-multiboundary-actual-transverse-neighborhood,bcalc:member-trace-ideal,hir:snc}
\lean{Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.traceSpan,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.traceSpan_unit_iff_notMem,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.exists_traceSpan_separator,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.traceGermSetoid,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.properTraceMembers,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.distinctProperTraceGermCount,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.distinctProperTraceGermCount_eq_boundaryCount,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.exists_actual_original_distinct_trace_neighborhood}
\leanok
For a genuine original transverse SNC carrier/boundary neighborhood and
an actual carrier point, the proper restricted member germ ideals are
exactly the incident original members. Two different incident positions
have different whole restricted germ ideals. Consequently the number
of DISTINCT proper restricted germ ideals there equals the actual
indexed incidence count, by an internally proved injection; this equality
is not asserted at arbitrary bad points.
\end{lemma}
\begin{proof}
At an incident member, every finite restricted ideal span vanishes on
the carrier-member intersection, so it cannot contain the unit germ at
the actual point. At a nonincident closed member, its true open complement
gives the actual unit germ in its ideal, hence in its restricted ideal.
This proves the exact proper-member dictionary.

Use actual simultaneous transverse coordinates for the original carrier
and whole original SNC list. Each incident member has its own distinct
free carrier coordinate. For two different incident positions, the first
member's actual coordinate belongs to its true ideal and hence its
restricted germ ideal. If it belonged to the second restricted ideal,
the whole genuine member-trace dictionary would make it vanish on the
carrier-second-member intersection near the actual point. Actual points
with the first free coordinate nonzero and all other coordinates fixed
at their true center values accumulate at that point. They remain on
the actual carrier and second member, contradicting that vanishing.
Thus the whole two restricted ideal membership predicates differ.

Define equivalence by equality of these whole holomorphic-germ restricted
span predicates, and count the true quotient classes of the proper
member positions. The preceding separator proves that the actual
quotient map is injective on that proper finite set. Its image cardinality
is therefore the cardinality of the incident indexed set. No raw indexed
count is substituted for the distinct-germ count at bad points, and
this does not supply modified max-centre admissibility or termination.
\end{proof}

\begin{theorem}[The actual original sharp defect is closed and compact on a compact carrier]
\label{hir:sharp-original-multiboundary-closed-compact-defect}
\source{bierstone-milman97-invent-math:page-0087}
\uses{hir:sharp-original-multiboundary-pointwise-nc-open}
\lean{Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.originalSharpBadLocus,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.originalSharpBadLocus_eq_compl_good,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.isClosed_originalSharpBadLocus,Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.isCompact_originalSharpBadLocus}
\leanok
The genuine original sharp defect
$\Sigma^* =\{x\in W:\neg\operatorname{NC}(W,E,x)\}$
is precisely the complement of the whole original good set. It is
closed, and when the original carrier is compact it is compact.
\end{theorem}
\begin{proof}
The complement dictionary is a literal pointwise propositional identity:
an original point is bad exactly when it belongs to the carrier and
fails its genuine adapted-coordinate property. The preceding genuine
whole-good-set openness therefore gives closedness. The actual defect
is a closed subset of the true compact original carrier, so it is
compact. No analytical bad-locus certificate or modified invariant is
supplied or claimed.
\end{proof}

\begin{lemma}[For an original smooth carrier the true sharp defect lies over the actual boundary]
\label{hir:sharp-original-multiboundary-defect-boundary-support}
\source{bierstone-milman97-invent-math:page-0087}
\uses{hir:sharp-original-multiboundary-closed-compact-defect,hir:snc}
\lean{Hironaka.HironakaSharpOriginalMultiBoundaryBadLocus.originalSharpBadLocus_subset_boundary}
\leanok
If the original carrier is a closed smooth submanifold, then
$\Sigma^*\subset W\cap\bigcup_{H\in E}H$. This remains the literal true
sharp defect, with every actual already normal-crossing intersection
point excluded.
\end{lemma}
\begin{proof}
At a true carrier point outside all original boundary members, original
smoothness supplies genuine centered carrier-flattening coordinates.
Use those same actual coordinates for the carrier position in the full
family; every boundary position is nonincident, so its membership and
cardinality requirements are vacuous. This constructs the literal
pointwise NC witness for the whole original boundary, contradicting
actual defect membership. Carrier membership already belongs to the
defect's genuine definition. Thus only the stated boundary-supported
original points can be bad. This is a topological and support producer,
not analyticity or admissibility of a newly selected modified centre.
\end{proof}
