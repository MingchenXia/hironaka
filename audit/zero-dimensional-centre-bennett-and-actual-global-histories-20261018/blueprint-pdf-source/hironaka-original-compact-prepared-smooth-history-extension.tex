\begin{theorem}[Simultaneous compact preparation extends the SAME given old source history]
\label{hir:original-compact-prepared-same-source-extension}
\uses{hir:original-current-compact-simultaneous-hs-first-blowup,hir:original-full-cut-actual-source-prefix-extension,hir:original-prepared-joint-source-bound-full-values,hir:submersion-relative-control-original-all-heads}
\lean{Hironaka.HironakaOriginalCompactPreparedSmoothHistory.exists_compact_prepared_same_source_extension}
\leanok
Let $n,m>0$, $j\geq2$, let the original marked ideal $M$ have
DOMAIN$(j)$, and let $T$ be an OLD original FULL-$R_j$ canonical prefix
whose actual current cosupport is compact and nonempty. Supply only a
finite family of actual coherent ideals on its current target and a
GENUINE GIVEN old Cartesian source history $Q$ over $T$.
Internally choose a nonempty original-admissible centre $C$ in the entire
old maximum locus and an actual proper holomorphic target blowup. The
old FULL value and every order of every supplied intrinsic HS profile are
constant on this SAME centre. Construct a real blowup of its inverse image
in the given source endpoint and append it to the SAME given $Q$.
Both appended histories are actual original TESTs, both new whole ordered
boundaries are SNC, and both projection maps are proper holomorphic maps.
The actual lift gives the full Cartesian square, WHOLE controlled marked
record equality and BOTH whole cosupport directions. On THIS exact source
extension, EVERY point over target current cosupport and EVERY $d\geq0$
satisfy the unchanged original FULL comparison at depths $j+d$ and
$(m-n)+(j+d)$ through the genuine recursive dimension map. No centre,
cut, new source history, lower TEST, current point or numerical certificate
is input.
\end{theorem}
\begin{proof}
The original compact-current simultaneous producer first chooses a real
maximum reference, a nonempty original-admissible centre inside the actual
entire maximum locus, its constant original FULL and ALL-order HS profiles,
and the SAME actual proper holomorphic target blowup with whole ordered
SNC. Maximum-locus membership gives EVERY old current-cosupport reference
below EVERY centre point in the original value. This is an internally
proved whole-centre cut, not a numerical hypothesis.

Use old original canonicity to construct the genuine old target TEST;
real centre admissibility appends the new target TEST. Apply the genuine
source-cut and source-blowup producer to the GIVEN old Cartesian $Q$,
this actual centre/blowup and its just-proved entire cut. Old source
DOMAIN, TEST and canonicality, actual source-centre admissibility and
source whole-centre cut are proved by the original smooth dictionaries.
Actual source cosupport thinness then yields the true source blowup.
Its universal lift constructs the new Cartesian history by appending to
this SAME $Q$; original admissibility gives its true TEST, properness,
holomorphicity, wellformedness and whole ordered SNC. No replacement old
source history is selected.

The actual controlled-record dictionary on this genuine Cartesian square
proves equality of the ENTIRE new marked record and the actual lifted
pullback of the target record. The genuine coherent cosupport dictionary
gives both whole ambient cosupport directions. These geometric statements
precede any value assertion. Apply the proved general SOURCE-bound
induction to this SAME new history at each point whose actual lift lies
in the new target cosupport, for every depth. Every lower TEST, independently
chosen OWN-small/large point and actual comparison required there is
already internally constructed. The only canonical prefixes used are the
OLD ones; centre containment in the maximum locus is not promoted to
centre equality or next canonicality.
\end{proof}

\begin{theorem}[Only an initial smooth map selects one source history before all values]
\label{hir:original-compact-prepared-all-bounds-smooth-history}

\lean{Hironaka.HironakaOriginalCompactPreparedSmoothHistory.exists_original_compact_prepared_smooth_history}
\leanok

Internally construct ONE actual source history and endpoint map, then a

\end{theorem}
\begin{proof}

The genuine smooth relative marked-tower existence theorem constructs ONE
old source history, actual endpoint submersion, every Cartesian blowup
square, source TEST and whole controlled/cosupport dictionaries for the

Its construction extends that same history and retains the original
simultaneous centre and genuine lift before any new point or recursive
depth is quantified. Thus the original inputs alone supply the entire
stated one-step smooth preparation and all unchanged original FULL values.
No global source compactness, next canonicality, arbitrary noncanonical
old prefix, terminating schedule or global driver is asserted.
\end{proof}
