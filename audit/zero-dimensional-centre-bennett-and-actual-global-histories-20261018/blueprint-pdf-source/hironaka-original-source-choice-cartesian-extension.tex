\begin{theorem}[Every actual stagewise tower isomorphism is the genuine smooth pullback]
\label{hir:original-source-isomorphism-actual-cartesian-tower}
\uses{mc:tower-isomorphism-basic,hir:submersion-relative-control-joint-tower}
\lean{Hironaka.HironakaOriginalSourceChoiceCartesian.IsTowerIso.actual_cartesian}
\leanok
For a genuine stagewise isomorphism of finite original towers over a true
base biholomorphism, construct the actual smooth Cartesian tower history
whose base and endpoint maps are exactly the supplied biholomorphisms.
Every actual successor, including every empty centre, is retained.
\end{theorem}
\begin{proof}
Induct on the actual isomorphism constructors. The reflexive case is the
genuine smooth submersion given by the base biholomorphism. At a successor,
the actual earlier stage biholomorphism is a submersion and its inverse
image of the actual target centre is exactly the actual source centre by
the isomorphism's centre law. Both given arrows are genuine blowups.
The actual next biholomorphism is holomorphic and satisfies the genuine
blowup square. Actual blowup-lift uniqueness identifies it with the
canonical smooth lift, proving the actual Cartesian successor. This
constructs the full actual history, rather than inferring Cartesianity
from an unsupported commuting square.
\end{proof}

\begin{theorem}[A true source choice composes with the actual smooth history]
\label{hir:original-source-choice-composed-cartesian-tower}

geometric construction.
