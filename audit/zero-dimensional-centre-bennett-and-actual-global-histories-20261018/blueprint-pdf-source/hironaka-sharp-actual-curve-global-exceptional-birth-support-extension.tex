\begin{theorem}[Every actual recipe centre lies over its true FIRST defect]
\label{hir:sharp-actual-curve-recipe-centres-over-first-defect}
\uses{hir:sharp-actual-curve-difference-tail-exceptional-support,hir:sharp-actual-curve-two-phase-projection-first-defect-complement}
\lean{Hironaka.HironakaSharpActualCurveGlobalExceptionalBirthSupport.first_difference_recipe_centresOver}
\leanok
Under the original smooth pure curve, ordered SNC and boundary-complement
density data, let the genuine first blowup of the original FIRST defect
$C_0$ be a genuine original product TEST. For ANY actual literal
ambient-difference tail, construct
\texttt{CentresOver}$(C_0,P S)$ for the ENTIRE retained original history.
No geometric centre-image certificate is an input, and this is not
inferred merely from differential exceptional-image support.
\end{theorem}
\begin{proof}
The true first centre is $C_0$ itself, so its image inclusion is the
literal identity. Induct on the actual tail. At its real successor the
actual constructor says that its centre equals the CURRENT literal
ambient difference. The proved difference-support induction puts that
CURRENT difference in the tail preimage of the difference just after
the first blowup. The separate first-step whole difference dictionary
places the latter set inside the actual first exceptional preimage of
$C_0$. The exact full projection formula now places the SAME successor
centre over $C_0$. Together with induction this is the genuine complete
prefixwise \texttt{CentresOver} assertion. Empty centres/steps satisfy
the same constructor without deletion.
\end{proof}
