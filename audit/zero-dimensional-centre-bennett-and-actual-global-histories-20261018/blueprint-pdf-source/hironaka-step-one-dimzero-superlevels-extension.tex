\begin{lemma}[The actual finite lower value is the genuine constant]
\label{hir:step-one-dimzero-actual-lower-value}
\lean{Hironaka.HironakaStepOneDimZeroAnalyticSuperlevels.lowerValue_ofDimZero_eq}
\leanok

the actual cosupport along any actual test tower of the homogenized
coefficient ideal of a well-formed positive-mark maximal-order ideal,

\end{lemma}
\begin{proof}
The actual nonspecial lower-mask theorem excludes the junk value

Unfold the actual masked lower-value definition on this mask. The
actual invariant of the lower marked ideal along the actual restricted
tail is definitionally the constant $l_0$; no lower ideal, history,
or restricted tower is supplied as a certificate.
\end{proof}

\begin{theorem}[Whole actual Step 1 thresholds at the lower base]
\label{hir:step-one-dimzero-all-superlevels}
\uses{hir:step-one-dimzero-actual-lower-value,hir:step-one-top-threshold-analytic,hir:actual-step-one-level-analytic-superlevels}
\lean{Hironaka.HironakaStepOneDimZeroAnalyticSuperlevels.isComplexAnalyticSubset_stepOneInvM_ofDimZero_superlevel,Hironaka.HironakaStepOneDimZeroAnalyticSuperlevels.isComplexAnalyticSubset_canonical_stepOne_base_superlevel}
\leanok

analytic, for arbitrary $\alpha\in\Lambda\cup\{\infty\}$. In
particular this holds for the actual canonical base

\end{theorem}
\begin{proof}

entry exactly $l_0$. At a special point it is top. If
$\alpha\le l_0$, the superlevel is precisely the actual cosupport
intersected with the actual level superlevel $\{s(y)\ge s\}$.
If $\alpha\nleq l_0$, only special points can contribute at level
exactly $s$, while higher levels always contribute; the entire locus
is the already produced actual $(s,\infty)$ superlevel. Both cases
are analytic by the genuine derivative-ideal cosupport producer and
the preceding actual geometric superlevel theorems. Unfolding the
actual canonical recursion identifies its zero-dimensional base with
$\operatorname{ofDimZero}(\mathbb N,0)$.

The comparison includes top, an empty cosupport, empty or repeated
original members, excessive level thresholds, disconnected geometry,
and zero-dimensional carrier components. Positive ambient dimension
is explicit. This proves the whole maximal-order Step 1 base layer;
it does not identify arbitrary full positive-order canonical companion
thresholds or construct a global noncompact resolving sequence.
\end{proof}
