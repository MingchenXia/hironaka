\section{The actual global curve is the conventional strict closure}

The global curve was constructed from literal geometric strict transforms
on retained actual recipes. We now identify it with the EXISTING
\texttt{strictTransform} of the SAME actual global projection, namely
$\overline{\pi^{-1}W\setminus\operatorname{Exc}(\pi)}$.
This assertion concerns the curve; it does not replace the geometric
strict transforms of arbitrary boundary members by that expression.

\begin{theorem}[Real mark-one TEST carriers equal the conventional strict transform]
\label{hir:sharp-actual-test-carrier-conventional-strict}
\uses{bcalc:inv-domain-stable}
\lean{Hironaka.HironakaSharpActualCurveGlobalStrictClosure.carrier_subset_closure_diff_of_mark_one,Hironaka.HironakaSharpActualCurveGlobalStrictClosure.carrier_eq_strictTransform}
\leanok
For ANY genuine original marked ideal in an invariant DOMAIN, of mark
one, and ANY genuine original TEST tower, its ENTIRE actual transformed
carrier equals the EXISTING conventional strict transform of its
original carrier by the SAME literal composite projection. No density,
carrier equality or centre-avoidance certificate is supplied.
\end{theorem}
\begin{proof}
At every actual prefix its true domain is preserved, so its coherent
ideal has a genuine nonzero-along-carrier germ at every carrier point.
At a point of the next centre, propagate that real germ membership to
an actual neighborhood. Mark one and actual centre inclusion in
cosupport imply that the germ vanishes on the centre, while its genuine
nonzero-along witness gives frequent nearby carrier points where it is
nonzero. These points lie off the centre. Away from the centre a carrier
point already belongs to the complement. Thus the ENTIRE actual current
carrier lies in the closure of its difference with the actual centre.

Induct on the literal tower. The empty composite gives the original
closed carrier. At a real successor the established density identifies
the actual geometric strict transform with the conventional strict
transform for that SAME blowup. The genuine holomorphic strict-transform
composition theorem and induction identify this with the conventional
strict transform under the SAME whole composite. Empty centres and all
recorded empty steps remain in this induction.
\end{proof}

\begin{theorem}[The actual chart differential sees the ENTIRE global exceptional locus]
\label{hir:sharp-actual-global-exceptional-local-dictionary}
\uses{hir:sharp-actual-endpoint-local-range-biholomorphism,hir:sharp-actual-original-global-complex-endpoint}
\lean{Hironaka.HironakaSharpActualCurveGlobalStrictClosure.exceptionalLocus_localInclusion,Hironaka.HironakaSharpActualCurveGlobalStrictClosure.preimage_exceptionalLocus_gluedProjection}
\leanok
For an actual covering endpoint-history atlas, the inverse image of the
ENTIRE exceptional locus of its global projection by each actual chart
inclusion is EXACTLY the exceptional locus of the SAME whole finite
local projection. No local exceptional-locus certificate is assumed.
\end{theorem}
\begin{proof}
Factor the actual chart inclusion into the genuine range
biholomorphism followed by the real open inclusion. Both have genuinely
bijective differentials, hence the entire chart inclusion has empty
exceptional locus by the actual chain rule. The base open inclusion
also has empty exceptional locus. Apply the chain rule to the global
projection composed with the chart inclusion, and separately to the
base inclusion composed with the finite local projection. The exact
WHOLE projection square identifies these actual functions. Removing
only the proved EMPTY exceptional terms gives the asserted ENTIRE
set equality in both directions.
\end{proof}

\begin{theorem}[Actual chart restriction commutes with the conventional strict closure]
\label{hir:sharp-actual-global-conventional-strict-local-dictionary}
\uses{hir:sharp-actual-global-exceptional-local-dictionary,hir:sharp-actual-endpoint-saturated-local-range}
\lean{Hironaka.HironakaSharpActualCurveGlobalStrictClosure.preimage_strictTransform_gluedProjection}

transform under the actual global projection, by EACH actual chart

\end{theorem}
\begin{proof}

The second theorem gives the separate whole exceptional-locus
preimage equality. Subtract these actual sets and take closure. This
is exactly the EXISTING strict-transform definition on both sides.
No equality with geometric strictAlong of an arbitrary $B$ is inferred.
\end{proof}

\begin{theorem}[ONLY original curve data identify the SAME global curve with strict closure]
\label{hir:sharp-actual-original-global-curve-strict-closure}
\uses{hir:sharp-actual-test-carrier-conventional-strict,hir:sharp-actual-global-conventional-strict-local-dictionary,hir:sharp-actual-original-endpoint-comparison-atlas,hir:sharp-actual-glued-strict-set-local-dictionary}
\lean{Hironaka.HironakaSharpActualCurveGlobalStrictClosure.original_localStrictSet_eq_strictTransform,Hironaka.HironakaSharpActualCurveGlobalStrictClosure.originalGluedStrictCurve_eq_strictTransform}
\leanok
For ONLY the original smooth pure curve, positive ambient label, ordered
SNC family and actual boundary-complement density, the already
constructed global curve is EXACTLY
\[
 \overline{\pi^{-1}W\setminus\operatorname{Exc}(\pi)}
\]
for the SAME actual proper holomorphic global projection $\pi$.
\end{theorem}
\begin{proof}
At every actual base window, construct the WHOLE original product marked
ideal of mark one: true smoothness and pure dimension, genuine original
SNC and actual open density give its original invariant domain internally.
The retained SAME recipe supplies its genuine original TEST. The first
theorem identifies that actual local carrier, hence its literal local
strictAlong of the curve, with the conventional strict transform of
the SAME full finite projection. The previous theorem identifies this
with the trace of the conventional GLOBAL strict transform.

The independently constructed global curve has exactly that local
strictAlong pullback on every actual chart. Genuine joint surjectivity
now compares membership of the two whole global subsets, proving the
displayed equality. No new endpoint or formal model is substituted.
This closes the curve strict-closure identification. A single global
finite blowup history, global scheduling and the full sharp driver are
not supplied by this identification.
\end{proof}
