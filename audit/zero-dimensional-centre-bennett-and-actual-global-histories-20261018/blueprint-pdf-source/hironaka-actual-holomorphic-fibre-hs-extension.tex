\section{Actual fibre HS semicontinuity for genuine holomorphic families}

Let $D\subset\mathbb C^r\times\mathbb C^n$ be an actual open domain and
$G_1,\ldots,G_s$ actual holomorphic functions on $D$. Let
$U\subset\mathbb C^r$ be any actual open for which $(p,0)\in D$ at every
$p\in U$. The ideal $I_p$ is the entire ideal generated by the actual
normal-variable germs $z\mapsto G_i(p,z)$ in
$\mathcal O_{\mathbb C^n,0}$. Its HS is the EXISTING quotient dimension
of this actual fibre ideal; it is not the HS of the total-space ideal.
Parameter and fibre dimensions are independent, including dimension zero.
This supplies the finite-jet semicontinuity used in the specialization
arguments of \cite[Lemmas 7.25--7.26, pp.~270--271]{bierstone-milman97-invent-math}.
The present argument uses actual convergent holomorphic families on their
real domains rather than replacing them by supplied formal-series data.

\begin{lemma}[True normal derivatives vary holomorphically in the original parameters]
\label{hir:actual-independent-parameter-normal-derivative-holomorphic}
\lean{Hironaka.HironakaActualHolomorphicFibreHS.actualIndependentParameter_iteratedFDeriv_slice,Hironaka.HironakaActualHolomorphicFibreHS.actualNormalDerivative_analytic}
\leanok
\uses{hir:actual-macaulay-jet-columns-holomorphic}
For every actual holomorphic $F:D\to\mathbb C$, every $j\ge0$, and every
fixed normal vector tuple $v_1,\ldots,v_j\in\mathbb C^n$, the actual
function
\[
 p\longmapsto D_z^j F(p,0)(v_1,\ldots,v_j)
\]
is holomorphic on the SAME actual parameter open $U$.
\end{lemma}
\begin{proof}
At $(p,0)$ the actual affine slice $z\mapsto(p,z)$ is translation by
$(p,0)$ composed with the true continuous complex-linear second-factor
inclusion. The iterated chain rule therefore identifies the normal
derivative with the actual joint derivative evaluated on the vectors
$(0,v_1),\ldots,(0,v_j)$. The iterated joint derivative is holomorphic
on $D$. Restrict it along the actual holomorphic first-factor slice
$p\mapsto(p,0)$, then apply the genuine continuous linear evaluation on
this fixed tuple. This gives holomorphicity on $U$, with the actual affine
slice identity on a genuine neighbourhood at each original parameter.
No parameter derivative or total-space jet replaces the normal derivative.
\end{proof}

\begin{theorem}[The actual whole fibre ideal has its genuine finite Macaulay rank]
\label{hir:actual-holomorphic-family-whole-fibre-macaulay-dictionary}
\lean{Hironaka.HironakaActualHolomorphicFibreHS.actualFibre_holomorphic,Hironaka.HironakaActualHolomorphicFibreHS.actualFibreIdeal,Hironaka.HironakaActualHolomorphicFibreHS.actualFibreIdeal_eq_original_span,Hironaka.HironakaActualHolomorphicFibreHS.actualFibreMacaulayMatrix,Hironaka.HironakaActualHolomorphicFibreHS.actualFibreMacaulayMatrix_entry_analytic,Hironaka.HironakaActualHolomorphicFibreHS.hilbertSamuelValue_actualFibreIdeal_eq_rank}
\leanok
\uses{hir:actual-independent-parameter-normal-derivative-holomorphic,hir:actual-whole-generated-ideal-finite-jet-columns,hir:actual-hilbert-samuel-macaulay-rank,hir:actual-translated-point-quotient-macaulay-rank}
For every $p\in U$ the actual functions $G_i(p,\cdot)$ give genuine
holomorphic germs and the entire original fibre ideal $I_p$. At every
cutoff $q$, its entire jet image is exactly the span of the actual
coordinate-word-times-generator columns. The matrix formed by evaluating
their actual normal derivatives on original coordinate tuples has
holomorphic entries on $U$, and
\[
 H_{I_p}(\ell)=d_{n,\ell+1}-\operatorname{rank}M_{\ell+1}(p),
\]
where $d_{n,q}$ is the actual full original jet-image dimension, independent
of $p$. This formula refers to the entire original fibre quotient.
\end{theorem}
\begin{proof}
The genuine open joint domain contains $(p,0)$, so restriction to its actual
second-factor slice supplies holomorphicity of every original generator
near zero. Form their entire ideal span in the original holomorphic germ
ring. The already proved whole-ideal finite-column theorem applies to this
same ideal and these same original germs at every cutoff. Coordinate
evaluation is injective on the actual finite multilinear jet target, so
it preserves the rank of their entire image. The resulting scalar matrix
is precisely the displayed derivative matrix. Each of its entries is the
normal derivative of the actual jointly holomorphic function obtained
by multiplying $G_i$ by the corresponding original normal coordinate word;
the preceding lemma proves its holomorphicity on the same $U$. Finally the
actual whole quotient/rank identity gives the stated EXISTING HS value.
All original ideal directions and scalar actions precede the dimension
calculation.
\end{proof}

\begin{theorem}[Every actual fibre HS superlevel is closed on the same real parameter open]
\label{hir:actual-holomorphic-family-fibre-hs-closed-superlevels}
\lean{Hironaka.HironakaActualHolomorphicFibreHS.isClosed_actualFibreHS_superlevel,Hironaka.HironakaActualHolomorphicFibreHS.isClosed_actualFibreHS_entire_superlevel}
\leanok
\uses{hir:actual-holomorphic-family-whole-fibre-macaulay-dictionary,hir:actual-hilbert-samuel-point-value-minor-loci}
For every $\ell,k\ge0$, the set
$\{p\in U:k\le H_{I_p}(\ell)\}$ is closed in the actual parameter open
$U$. Consequently for ANY actual numerical profile $h$, the literal set
$\{p\in U:\forall\ell,\ h(\ell)\le H_{I_p}(\ell)\}$ is also closed
in $U$.
\end{theorem}
\begin{proof}
Let $d=d_{n,\ell+1}$. The actual column range is contained in the full
original jet image, so its rank is at most $d$. If $d<k$ the first set is
empty. Otherwise the actual quotient/rank formula identifies its defining
inequality with rank at most $d-k$, equivalently vanishing of EVERY
$(d-k+1)$-square minor of the actual finite matrix. Each such determinant
is continuous on $U$ because its actual entries are holomorphic there.
Its zero set is closed, and intersecting these sets gives the stated
closed superlevel, including empty row or column sets. The literal
all-order set is the intersection of these closed sets over all $\ell$.
This is coordinatewise all-order closure; no finite-valuedness,
lexicographic semicontinuity or transformed standard-basis claim follows
from that intersection alone.
\end{proof}
