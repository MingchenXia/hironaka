Throughout, the ambient dimension is positive.

\begin{theorem}[Actual relative-ideal representatives preserve arbitrary-prefix curve FULL rebasing]
\label{hir:original-curve-full-relative-reference-rebase}
\uses{hir:original-curve-full-arbitrary-prefix-rebase,hir:general-representative,bcalc:inv-domain-stable}
\lean{Hironaka.HironakaOriginalCurveLowerReferenceRebase.curve_full_rebase_of_restrictEquiv}
\leanok
Let an original marked ideal $M$ be in DOMAIN$(1)$ and let
$P\mathbin{\cdot}T$ be a genuine TEST of $M$. If a coherent original
marked ideal $N$ is genuinely restricted-equivalent to $M_P$, then $N$
is in DOMAIN$(1)$, $T$ is an actual TEST of $N$, and the ENTIRE current
cosupports agree. At every point in this current cosupport and every
$k\ge0$,
\[
 \operatorname{FULL}_{k+1}(M,P\mathbin{\cdot}T)
 =\operatorname{FULL}_{k+1}(N,T).
\]
There is no canonicality, empty-prefix or numerical-equivalence hypothesis.
\end{theorem}
\begin{proof}
Split the genuine concatenated TEST into its actual prefix and tail TEST.
True DOMAIN preservation supplies DOMAIN$(1)$ for $M_P$. Symmetry of the
actual restricted equivalence and coherence of $N$ give DOMAIN$(1)$ for
$N$. The original whole relative equivalence gives admissible-centre
and cosupport equality along EVERY actual tail, hence transfers the real
TEST $T$ and identifies its entire current cosupport. The exact whole
append identity identifies the current record on $P\mathbin{\cdot}T$
with the current record starting from $M_P$.

The preceding arbitrary-prefix curve theorem identifies the first FULL
value with that for $M_P$ along $T$. The actual general-value
representative theorem applies to EVERY value function used for the
lower field, EVERY history, and EVERY point: nonmonomial orders, real
regime runs and actual companion records agree for restricted-equivalent
original ideals, including the monomial branch. Apply it to the actual
StepOne lower field at depth $k$. This identifies the latter FULL value
with that for $N$ along the SAME tail. Combining the two true numerical
identities proves the displayed equality at every positive depth.
\end{proof}

\begin{theorem}[The original kept-contact reference rebases numerically without lower CAN]
\label{hir:original-curve-kept-contact-full-rebase}
\uses{hir:original-curve-full-relative-reference-rebase,hir:step-one-compare}
\lean{Hironaka.HironakaOriginalCurveLowerReferenceRebase.contactKept_curve_full_rebase}
\leanok
Let $J$ be well formed with positive mark, with a genuine tangent direction
on the original open $U$, and let $P\mathbin{\cdot}B$ be an actual TEST
of the original $\bar J$. Let $W\subseteq P^{-1}U$ be open and suppose
ALL actual centres of $B$ avoid $W$. Suppose the genuine original
kept-contact reference at $(P,W)$ lies in DOMAIN$(1)$, and its real
restricted concatenation $B|_W\mathbin{\cdot}T$ is a TEST. The newly
formed original kept-contact reference at $(P\mathbin{\cdot}B,B^{-1}W)$
is in DOMAIN$(1)$ and has genuine tail TEST $T$, the same entire current
cosupport, and the SAME original FULL values at EVERY positive depth.
The stated lower DOMAIN and TEST are ordinary geometric hypotheses;
no lower CAN, numerical rebase or desired-reference identity is input.
\end{theorem}
\begin{proof}
The original coefficient/contact rebase calculus, applied to the actual
upper TEST, tangent direction, open containment and true ALL-centre
avoidance, internally produces a genuine whole restricted equivalence
between the new kept-contact reference and the transform of the old one
along $B|_W$. Actual upper TEST geometry gives the closed smooth current
carrier and coherent transformed ideal. Actual coefficient-ideal
coherence followed by genuine open pullback proves coherence of the NEW
kept-contact reference. Apply the first theorem to the old kept-contact
DOMAIN$(1)$ reference, the SAME true restricted prefix $B|_W$, the SAME
actual tail TEST, and this internally produced relative equivalence.
It gives precisely the new domain, tail TEST, whole cosupport and all
positive-depth original numerical equalities. No canonicality is inferred.
\end{proof}

\begin{theorem}[The original member reference has the same noncanonical numerical rebase]
\label{hir:original-curve-member-reference-full-rebase}
\uses{hir:original-curve-full-relative-reference-rebase,bcalc:inv-domain-stable,hir:step-one-compare}
\lean{Hironaka.HironakaOriginalCurveLowerReferenceRebase.memberRestrict_curve_full_rebase}
\leanok

$E_0$ consist of members of its ordered boundary. For an actual TEST $B$
of $M$, an open $W$ avoided by ALL centres, and a point over $W$, form the
actual original member reference using the members through its basepoint,
restricted to $W$. If this reference is in DOMAIN$(1)$ and
$B|_W\mathbin{\cdot}T$ is its genuine TEST, then the actual member
reference formed from $M_B$ and the actual strict transforms of $E_0$,
restricted to $B^{-1}W$, has DOMAIN$(1)$, tail TEST $T$, equal ENTIRE
current cosupport and the SAME original FULL values at EVERY positive
depth. No canonical or numerical certificate is required.
\end{theorem}
\begin{proof}
The actual original member-restriction rebase theorem internally gives
the genuine whole relative equivalence for these literal members and
strict transforms, using the true original TEST and ALL-centre avoidance.
Actual TEST preservation supplies the well formed transformed $M_B$.
The genuine member-restriction geometry and subsequent real open
restriction therefore prove coherence of the newly formed reference.
Apply the first theorem to the ordinary old DOMAIN$(1)$ reference and
its actual restricted-prefix-and-tail TEST, with this actual relative
equivalence and newly proved coherence. Every stated conclusion follows
on the SAME tail, at the SAME endpoint and every positive depth. Empty
restricted centre positions are retained in the actual history.
\end{proof}
