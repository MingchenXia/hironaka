\end{proof}

\begin{lemma}[Vanishing actual normal derivatives produce a genuine normal-power expression]
\label{hir:relative-normal-actual-normal-vanishing-taylor}
\uses{mc:taylor-tail,hir:relative-normal-actual-recursive-power-dictionary}
\lean{Hironaka.HironakaRelativeNormalTaylorCoefficients.inNormalPow_of_normal_derivatives_zero}
\leanok
If all original normal coordinate derivatives of orders $<q$ of an actual
holomorphic function vanish on the genuine coordinate plane near zero, then
that original function has an actual recursive normal-power expression of
degree $q$ near zero. Only normal derivatives are assumed.
\end{lemma}
\begin{proof}
Induct on the number of normal coordinates, uniformly in $q$. With none,
positive $q$ includes the empty derivative, so the original function is zero
near zero and has the genuine zero expression; $q=0$ is holomorphicity.
Otherwise let $z_j$ be the first normal coordinate and let $p_j$ kill it. The
actual convergent Taylor theorem gives, on a genuine neighbourhood,
\[
 f(z)=\sum_{a<q}\frac{z_j^a}{a!}
       (\partial_j^a f)(p_jz)+z_j^q h(p_jz,z_j)
\]
with a jointly holomorphic true remainder $h$. Every other normal basis
vector is fixed by $p_j$. The true linear chain rule identifies its iterated
derivatives of $(\partial_j^a f)\circ p_j$ with the corresponding derivatives
of $f$ with $a$ copies of the direction $j$ appended. On the smaller plane
with $z_j=0$ these vanish below order $q-a$, by the actual original hypothesis.
The induction hypothesis gives a genuine degree-$(q-a)$ expression in the
remaining normal coordinates for each coefficient. Allowing also $z_j$
preserves that expression; multiplication by $z_j^a$ raises its true degree
to $q$. The last term has its direct degree-$q$ expression because the
remainder is genuinely holomorphic. Finite sum, actual constant scalars and
the true original Taylor neighbourhood equality complete the result.
\end{proof}
