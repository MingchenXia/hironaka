\section{Actual empty original-history windows at positive curve order}

The ordered boundary in \cite[Section~5, Step~II]{bierstone-milman08-functoriality}
contains every new exceptional member, including empty positions. On a
carrier of dimension at most one the genuine nonmonomial part is a unit
at every incident transverse boundary point. Thus a positive-order point
has an actual base neighborhood where the ENTIRE given history has empty
centres. These statements concern ANY ORIGINAL test, without a canonical
history assumption or a supplied empty-history certificate.

\begin{theorem}[An actual point outside the entire accumulated boundary internally supplies an empty original-history window]
\label{hir:original-off-boundary-actual-empty-history-window}
\uses{hir:stage-cosupport-off-boundary,hir:principalization,hir:principalization-local,hir:admissible-calculus,bcalc:restrict-empty-tower}
\lean{Hironaka.HironakaOriginalCurvePositiveEmptyWindow.exists_actual_off_boundary_empty_window}
\leanok
For ANY marked record with closed original boundary members, ANY actual
finite blowup tower $T$, and an actual point $y$ outside its ENTIRE
accumulated ordered boundary, internally construct an actual base open
$U$ containing $T(y)$ such that the restriction of the SAME ENTIRE tower
to $U$ has only empty centres. No compactness, marked admissibility,
base neighborhood, inverse or empty-history certificate is supplied.
\end{theorem}
\begin{proof}
The finite union $F$ of actual current boundary members is closed: old
members are closed initially, strict transforms are closed, and new
members are inverse images of closed centres. The actual tower is proper,
so its literal image $T(F)$ is closed. The current boundary contains the
actual exceptional locus. A fibre through the given point $y\notin F$
is therefore a singleton. Consequently $T(y)\notin T(F)$: a point of $F$
in that fibre would equal $y$. Put $U=X\setminus T(F)$.

Prove that all actual centres avoid $U$ by induction on the SAME tower.
At a last actual blowup $\pi$, surjectivity supplies a lift of every point
of the preceding boundary. Its lift lies in the new boundary, since the
inverse image of the old boundary is contained in the new ordered
boundary. Hence the image of the preceding boundary is contained in the
final image $T(F)$. The induction hypothesis applies to the SAME open
$U$. Surjectivity also lifts every point of the last centre to the new
exceptional member; its image in the original base therefore belongs to
$T(F)$. That last centre is disjoint from the actual inverse image of
$U$. This proves avoidance for every centre, retaining the actual maps
and every empty step. The genuine restricted-centre dictionary now says
that the ENTIRE restricted tower has only empty centres.
\end{proof}

\begin{theorem}[ONLY a genuine dimension-at-most-one domain makes the actual nonmonomial part a unit on the whole boundary]
\label{hir:original-curve-domain-boundary-nonmonomial-unit}
\uses{hir:nonmonomial-transform,hir:sharp-actual-curve-no-factor-member-unit,bcalc:nonmonomial-order-local,hir:general-step-wf}
\lean{Hironaka.HironakaOriginalCurvePositiveEmptyWindow.curve_domain_nonmonomial_unit_on_boundary,Hironaka.HironakaOriginalCurvePositiveEmptyWindow.original_test_curve_boundary_full_monomial_value}
\leanok
ONLY a genuine invariant domain of dimension bound one implies that at
EVERY actual carrier point on its entire ordered boundary the ACTUAL
nonmonomial ideal contains $1$ and has order zero. In particular, ONLY
an original dimension-bound-one domain and ANY ORIGINAL test internally
give the ACTUAL full original general invariant at every such current
point as its literal monomial branch $(0,\gamma)$.
No pure-curve, relative-principal, nonfactor, unit, order or desired full
value certificate is input.
\end{theorem}
\begin{proof}
Construct the true parts of the original marked ideal first. Actual
wellformedness and nonzero-along-carrier hypotheses give coherence of the
nonmonomial ideal, its genuine nonzero germs along the carrier, and an
actual germ outside the relative ideal of EACH incident boundary member.
At the chosen point, the real dimension bound supplies regular dimension
$j\leq1$. If $j=1$, the genuine transverse curve isolating neighborhood
and the actual no-factor witness force a nonzero value of that witness;
its holomorphic inverse gives $1$ in the actual nonmonomial ideal.
If $j=0$, a genuine isolating neighborhood in the carrier and the actual
frequent nonzero witness force that witness to be nonzero at the point
itself, and its true holomorphic inverse again supplies $1$.

Testing order at least one on this SAME unit germ is impossible, since
its value is one. The actual order is therefore zero. For ANY original
test, genuine domain preservation supplies all preceding hypotheses on
the ACTUAL current record and entire ordered boundary. Finally unfold
the unchanged original dimension-one general invariant: the first entry
is the ACTUAL nonmonomial order just proved zero, so its actual defining
conditional selects precisely the literal monomial $\gamma$ branch.
No companion TEST or noncanonical higher-value interface is used.
\end{proof}

\begin{theorem}[ONLY original curve-domain ANY-test data give an actual empty entire-history window at every positive first entry]
\label{hir:original-any-test-positive-curve-actual-empty-window}
\uses{hir:original-off-boundary-actual-empty-history-window,hir:original-curve-domain-boundary-nonmonomial-unit,bcalc:tower-restrict,hir:centre-function}
\lean{Hironaka.HironakaOriginalCurvePositiveEmptyWindow.exists_original_test_positive_curve_empty_window}
\leanok
ONLY an original dimension-bound-one domain, ANY genuine ORIGINAL test
and an actual current cosupport point of positive actual nonmonomial
order internally supply a base open containing its actual original
image on which the SAME ENTIRE restricted ORIGINAL history has empty
centres. Its actual restricted original record remains in dimension
bound one and the SAME actual restricted tower is genuinely its TEST.
No canonicality, selected window, pure current carrier, replacement
history or empty-history certificate is input.
\end{theorem}
\begin{proof}
The current ORIGINAL cosupport point lies in the actual current carrier.
Genuine domain preservation supplies its dimension-bound-one domain.
If the point belonged to any actual current boundary member, the
preceding theorem would make its actual nonmonomial order zero,
contradicting its given positivity. It is therefore outside the ENTIRE
actual accumulated boundary. Original wellformedness gives closedness of
all ORIGINAL boundary members, so the first theorem internally constructs
the required actual base open and empty ENTIRE restricted tower. True
open restriction of the original domain gives the restricted domain, and
true open restriction of the ORIGINAL TEST gives the SAME actual
restricted TEST. The chosen point belongs to the actual endpoint open
because its original image belongs to the constructed base open.

This is a genuine local geometric input for the positive GENERAL branch.
Comparing the companion formed at its actual original order-run year,
its actual restricted tail and the unchanged full noncanonical GENERAL
value remains a separate obligation. No higher full-value locality,
exceptional or infinitesimal semicoherence, or general driver termination
is asserted here.
\end{proof}
