\begin{lemma}[Repivoting the same actual chart preserves the whole coordinate geometry]
\label{hir:submersion-blowup-pivot-same-coordinate-support}
\leanok
\lean{Hironaka.HironakaSmoothSubmersionBlowupPivotCompatibility.repivot,Hironaka.HironakaSmoothSubmersionBlowupPivotCompatibility.repivot_eq_self_of_pivot,Hironaka.HironakaSmoothSubmersionBlowupPivotCompatibility.matching_pivot_extended_support}
\uses{hir:submersion-adapted-blowup-entire-monomial-dictionary,hir:submersion-adapted-blowup-actual-smooth-chart-map,bex:blowup-space}
Replace only the normal pivot in an actual flattening blowup chart. Its
base domain and all unnormalized coordinate functions remain the same. Repivoting to the original pivot returns the identical entire chart record.
For actual matching source and target charts with the genuine block normal
index and pivot dictionary, let the source chart parameter project into
the target chart target. At every actual source-chart point $q$, with actual
flat-chart image $z$, EVERY normal coordinate $i$ has nonzero extended value
at $z$ exactly when its corresponding rotated source coordinate has nonzero
extended value at $q$. Thus repivoting to an actual target pivot containing
$z$ produces a true source pivot chart containing $q$.
\end{lemma}
\begin{proof}
The repivoted chart is the same literal flattening record with only its
pivot and its normal-index proof replaced; its base domain and every raw
coordinate are definitionally unchanged. For the old pivot, both extended
values are nonzero by actual chart membership. For another normal index,
the genuine target right-inverse gives target parameter equal to the drop
of the source parameter. Evaluating coordinate $i$ gives equality of the
target and rotated source parameter entries. The actual monomial chart
formulas write these entries as extended-value numerator divided by their
respective old-pivot extended value. Both denominators are genuinely
nonzero. Therefore the numerators are nonzero simultaneously. This uses
only the ordinary entire chart formulas, including at every point of the
exceptional divisor, not a density argument away from it. The source base
remains in the identical domain, hence its new chart membership follows.
\end{proof}

\begin{theorem}[Canonical original blowup points are uniquely determined by BOTH projections]
\label{hir:submersion-blowup-pivot-canonical-joint-unique}

and the original two projection equalities now give equal bases and equal
flat-chart images in one SAME chart. The true split-coordinate joint-point
uniqueness from the local-cone producer forces equality. Empty centres and
zero-dimensional cases use the actual off-centre branch; an exceptional
case supplies the genuine normal pivot internally.
\end{proof}
