\begin{theorem}[Literal original indices and levels at every actual stage]
\label{hir:submersion-history-original-members}
\lean{Hironaka.HironakaSmoothSubmersionNonmonomialHistory.origMembers_eq_current_boundary,Hironaka.HironakaSmoothSubmersionNonmonomialHistory.IsActualTowerPullback.original_members_dictionary,Hironaka.HironakaSmoothSubmersionNonmonomialHistory.IsActualTowerPullback.level_dictionary}
\uses{hir:step-one-value-off-centre,bcalc:member-intersection-tower,bcalc:boundary-count-canonical,hir:submersion-relative-control-joint-tower}
\leanok
Let a genuine smooth submersion pull back an actual original multiple test
blowup tower of an original well formed marked datum. At each actual pair
of stages, the original-member list of StepOne is the literal preimage list
of the original target list; its level at every source point equals the
original target level at its actual image. Empty and repeated old entries
and every created exceptional suffix remain literal.
\end{theorem}
\begin{proof}
The genuine joint tower producer gives equality of the entire transformed
marked datum with the actual marked pullback at every stage, hence equality
of the entire boundary lists. The original members of StepOne are exactly
the first original number of entries of that boundary: homogenization and
coefficient formation preserve the entire boundary, and the true boundary
transform appends the exceptional entry after strict-transforming every
existing entry. Thus taking the original length commutes with the actual
preimage list, whose length equals the original length. Each finite indexed
entry contains a source point precisely when its original target contains
the image. The literal indexed count is equal, proving equality of levels.
No initial label, count, boundary equality or chosen value certificate is
input. This statement asserts neither equality of special loci nor a
higher invariant value.
\end{proof}
