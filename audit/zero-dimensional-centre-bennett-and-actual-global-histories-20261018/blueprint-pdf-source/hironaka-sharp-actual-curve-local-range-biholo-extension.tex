\begin{lemma}[The actual range homeomorphism has a genuine holomorphic inverse]
\label{hir:sharp-actual-endpoint-local-range-inverse-holomorphic}

\lean{Hironaka.HironakaSharpActualCurveLocalRangeBiholomorphism.localRangeOpen,Hironaka.HironakaSharpActualCurveLocalRangeBiholomorphism.localHomeomorphism,Hironaka.HironakaSharpActualCurveLocalRangeBiholomorphism.localHomeomorphism_point,Hironaka.HironakaSharpActualCurveLocalRangeBiholomorphism.localHomeomorphism_inverse_point,Hironaka.HironakaSharpActualCurveLocalRangeBiholomorphism.localHomeomorphism_contMDiff,Hironaka.HironakaSharpActualCurveLocalRangeBiholomorphism.localHomeomorphism_symm_contMDiff}

\end{lemma}
\begin{proof}
The proved local open embedding gives the genuine range homeomorphism,
with both inverse point laws. Its forward map is holomorphic by the actual
local inclusion theorem followed by the real range-subtype lift. For an
actual point in the range, let its genuine inverse be x. Take the true local

inverse point equation puts the range point in c's true source and identifies

The actual chart-atlas membership and genuine maximal-atlas inverse theorem

at that point. On the actual open preimage of c's source, write a point as an
included local point. Injectivity of the true open embedding and the genuine

The real lifted-chart formula then says that the composition is exactly the
actual homeomorphism inverse on this genuine neighborhood. Thus that actual
inverse is holomorphic everywhere, without an inverse-regularity certificate.
\end{proof}
