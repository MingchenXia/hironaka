\begin{theorem}[Actual global boundary members have their exact local readouts]
\label{hir:sharp-actual-global-birth-boundary-local-dictionary}

\[

\end{theorem}
\begin{proof}
The original-only retained atlas first constructs all true local spaces,
overlaps, comparison maps and global inclusions. If $\iota_i(z)\in D_k$,

These are both whole-set membership implications; an arbitrary map
commuting with the projection is not substituted for the OLD transition.
The already constructed local range biholomorphism has the OLD inclusion

\end{proof}

\begin{theorem}[The genuine global family is closed and locally finite]
\label{hir:sharp-actual-global-birth-boundary-locally-finite}
\uses{hir:sharp-actual-global-birth-boundary-local-dictionary,hir:sharp-actual-original-birth-boundary-local-cutoff,hir:sharp-actual-original-global-complex-endpoint}

For the SAME original-only constructed $Y$ and family $(D_k)_{k\in\mathbb N}$,
EVERY $D_k$ is genuinely closed and the actual indexed family is locally
finite. More precisely, on the actual open range of chart $i$, every
$D_k$ with
\[
 k\geq |E|+|A_i^{\mathrm{prefix}}A_i^{\mathrm{tail}}|
\]
is disjoint from that whole range. The finite bound may depend on $i$.
Actual empty positions remain present in the indexed family.
\end{theorem}
\begin{proof}
Each true local readout is closed, including actual empty birth slots and
all default EMPTY positions. By the first theorem, the pullback of $Y\setminus
D_k$ to every actual local chart is the complement of that closed local
set. These pullbacks are open. The ACTUAL quotient-topology open-set
criterion therefore proves that $Y\setminus D_k$ is open, giving closedness
of the independently defined global set. Closedness of separate chart
images alone is not used to infer this conclusion.

For local finiteness choose a real chart representative of an arbitrary
global point. Its genuine local inclusion has open range containing that
point. Let $b_i$ be the literal initial-list length plus the entire actual
local history length, including every empty step. For any $k\geq b_i$,
the real local cutoff makes $B_{i,k}$ EMPTY. The exact local pullback from
the first theorem then implies the ENTIRE range is disjoint from $D_k$:
any hypothetical intersection has a genuine chart preimage and would
give membership in EMPTY. Consequently only indices in the actual finite
set $\{0,\ldots,b_i-1\}$ can meet this neighborhood. This proves genuine
local finiteness of the global indexed family with no uniform bound,
global finite list, nonempty-count compression or auxiliary compactness.
\end{proof}
