\source{bierstone-milman08-functoriality}

\end{lemma}
\begin{proof}

transition. It lies in the original first chart target, and the actual
first inverse chart's embedded point lies in the actual image of the
second chart source. Thus the original first inverse point belongs to

and its true underlying inverse value is the original first inverse chart.
The actual overlap biholomorphism sends it to the second local space.
Its whole embedding equation and genuine second embedding injectivity

Consequently the second original chart is genuinely holomorphic there.
Compose the actual restricted inverse chart, genuine overlap map, actual

true lifted transition source, the same restricted chart inverse formula,
whole embedding equation and true embedding injectivity identify this
actual coordinate composite with the actual lifted transition. Pointwise
congruence on that source gives holomorphicity within the actual source.
This works at every such coordinate point; an empty transition source
requires no false nonempty overlap assertion.
\end{proof}
