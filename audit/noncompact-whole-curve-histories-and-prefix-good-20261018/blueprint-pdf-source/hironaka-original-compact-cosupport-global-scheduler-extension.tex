\section{Actual global canonical scheduling from compact initial cosupport on a possibly noncompact ambient}

The genuinely original marked ideal, invariant and global tower are retained.
Only the INITIAL actual cosupport is assumed compact; neither the ambient
manifold nor the carrier is assumed compact. This produces actual stages,
global maximum centres and actual blowup maps before termination is proved.
It closes this geometric scheduling subclass. The general noncompact-cosupport
extension/smoothification of BM97 Theorem 13.4 and Lemma 13.7, arbitrary global
full thresholds and original coefficient semicoherence remain OPEN.

\begin{lemma}[Actual proper projections keep every genuine current cosupport compact]
\label{hir:original-compact-cosupport-current-compact}
\uses{hir:invariant-driver-seq,hir:principalization-local}
\source{bierstone-milman97-invent-math:page-0092}
\lean{Hironaka.HironakaOriginalCompactCosupportGlobalScheduler.current_cosupport_compact}
\leanok
Let $m$ be an original invariant-domain marked ideal whose INITIAL cosupport
$K$ is compact. For EVERY genuine marked test tower $T$, its actual entire
current cosupport is compact, and its actual projection maps it into $K$.
No current-stage compactness is a caller input.
\end{lemma}
\begin{proof}
The actual test-tower transform is well formed, so its entire current
cosupport is closed. Genuine cosupport inheritance through each admissible
blowup, composed along the actual finite tower, places that cosupport inside
the preimage of the INITIAL $K$. The actual tower projection is proper,
by genuine properness of every actual blowup and composition. The preimage
of $K$ is therefore compact. The true closed subset just identified is
compact, with exactly the stated original projection containment. No
compactification or replacement of the original ambient is used.
\end{proof}

\begin{theorem}[Constructed global canonical growing sequence with actual global maxima and projections]
\label{hir:original-compact-cosupport-actual-global-canonical-sequence}
\uses{hir:original-compact-cosupport-current-compact,hir:centre-function-seq,hir:growing-sequence-actual-centres}
\source{bierstone-milman08-functoriality}
\lean{Hironaka.HironakaOriginalCompactCosupportGlobalScheduler.exists_actual_global_canonical_sequence}
\leanok
ONLY an actual resolution invariant, its original domain input and compact
INITIAL cosupport internally construct a genuine global GrowingSeq starting
at the literal identity tower. EVERY global recorded prefix is canonical for
the SAME original invariant/input. At EVERY successor there is a genuine
global blowup map whose centre is EXACTLY the ENTIRE actual global maximum
locus on the current original cosupport. These stages, centres and maps are
constructed without a scheduling, maximum-existence or terminal certificate.
\end{theorem}
\begin{proof}
Consider actual global finite towers together with their true canonicality.
Canonicality internally gives actual original test-tower geometry. The first
lemma supplies compactness of every actual current cosupport. When that
cosupport is nonempty, true original upper semicontinuity on this compact
set internally attains a global maximum. Its ENTIRE maximum locus is the
original invariant's genuine admissible centre. If the current cosupport
is empty, its literal maximum locus is empty and genuinely admissible.
Original nonzero geometry makes each such centre thin; the actual blowup
existence theorem constructs its real global manifold, map and blowup proof.
Appending it preserves true canonicality for the SAME original input.
Choose these actual successors and iterate from the literal identity tower.
The actual dependent stages and successor equalities give a genuine
GrowingSeq; every chosen successor retains its actual map and literal
maximum-locus equation. All choices precede any termination argument.
\end{proof}

\begin{theorem}[The actual constructed sequence terminates and all later prefixes remain original resolutions]
\label{hir:original-compact-cosupport-actual-global-eventual-resolution}
\uses{hir:original-compact-cosupport-actual-global-canonical-sequence,hir:centre-function-seq}
\source{bierstone-milman08-functoriality}
\lean{Hironaka.HironakaOriginalCompactCosupportGlobalScheduler.exists_actual_global_canonical_sequence}
\leanok
That actual constructed global sequence has an index $N$ such that EVERY
later recorded prefix is a genuine resolution of the SAME original marked
input. In particular there is an actual finite global canonical terminal
tower on the original possibly noncompact ambient.
\end{theorem}
\begin{proof}
Suppose no recorded current cosupport were empty. Compactness from the first
lemma then makes EVERY actual global maximum centre nonempty. Every point
of each such centre lies in actual current cosupport, so its actual original
projection belongs to the SAME compact INITIAL $K$. Consequently the literal
count of genuine centres meeting $K$ increments by one at every successor.
Induction on the actual iteration proves that the count at index $i$ is
exactly $i$. Apply the ORIGINAL invariant's proved per-sequence local
finiteness to THIS already constructed global canonical sequence and THIS
compact $K$. It gives a finite bound on these exact counts, contradicted by
the next natural index. Thus an actual recorded stage has empty cosupport.
Genuine test-tower cosupport inheritance through each subsequent actual
step keeps its current cosupport empty; induction gives this for EVERY
later index. Their canonical prefixes are genuine test towers, so these are
actual original resolutions. No numerical bound, terminal history or empty
auxiliary-transform assertion was supplied by the caller.
\end{proof}

\begin{proof}

\end{proof}
