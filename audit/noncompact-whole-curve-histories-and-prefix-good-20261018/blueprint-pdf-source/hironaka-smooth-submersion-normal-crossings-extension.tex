\begin{lemma}[Actual normalized complement and full lifted coordinates]
\label{hir:submersion-nc-full-lifted-coordinates}
\uses{hir:submersion-monomial-dimension}
\lean{Hironaka.HironakaSmoothSubmersionNormalCrossings.complementCoordinates,Hironaka.HironakaSmoothSubmersionNormalCrossings.first_block_coordinate,Hironaka.HironakaSmoothSubmersionNormalCrossings.liftedCoordinatesAdd,Hironaka.HironakaSmoothSubmersionNormalCrossings.liftedCoordinatesAdd_dictionary,Hironaka.HironakaSmoothSubmersionNormalCrossings.exists_lifted_coordinates}
\leanok
Let $f:Y^m\to X^n$ be a genuine complex submersion at an actual y. For every
actual centred holomorphic coordinate change Phi at f(y), there is a genuine
centred preferred-chart change Xi at y and an injection $rho:Fin(n)\to Fin(m)$
such that its true domain maps into Phi's true domain and, throughout that
whole domain, Xi's rho(j) coordinate is Phi's j coordinate composed with f.
\end{lemma}
\begin{proof}
Use the actual submersion witnesses: open maximal-atlas charts phi and psi,
and an actual continuous complex-linear equivalence
$L:C^m\simeq C^n\times F$, such that $psi f phi^{-1}$ is first projection on the
entire true submersion chart domain. The projection through L is surjective,
so finite dimension gives n<=m. Second projection through L is likewise
surjective, so F is finite dimensional. The actual equivalence gives
m=n+dim F; hence dim F=m-n. An actual complex basis of F and finite-dimensional
continuity produce a continuous linear equivalence $F\simeq C^{(m-n)}$.
The canonical first/last finite-index split identifies $C^m$ with
$C^n\times C^{(m-n)}$, with its first-coordinate injection rho.

Compose the target preferred chart, Phi, and the inverse of psi to form the
actual local biholomorphism $Gamma=Phi e_X psi^{-1}$. This is defined on the
true open chart overlap and is holomorphic in both directions, by maximal
atlas compatibility and the two genuine Phi holomorphic directions. Form
Gamma times the fibre translation $v\mapsto v-v_0$, $v_0=(L phi(y))_2$.
Compose the entire true partial-homeomorphism chain

split inverse (with the chosen actual F-coordinate equivalence).
Every composition is restricted to its true open source and target, so
this chain is an actual local biholomorphism. Its source contains $e_Y(y)$,
as Gamma sends psi(f(y)) to zero; fibre translation sends $v_0$ to zero.
It therefore gives a genuine centred preferred-chart Xi. On its entire
true source, the original submersion chart equation gives first-coordinate
identity. The last finite coordinates are unconstrained. Source restriction
ensures the domain maps into the true original Phi domain. No inverse
function or local-coordinate certificate is assumed; all charts, complements,
restrictions and inverse functions are constructed from actual witnesses.
This argument includes n=0, m=n, empty complement and zero-dimensional source;
it only asserts pointwise existence where an actual y exists.
\end{proof}
