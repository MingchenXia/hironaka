\section{Actual sharp-curve difference recipes restrict to true opens}

Fix positive ambient dimension and the original smooth curve, ordered
SNC and whole-family density data. An open restriction retains every
actual centre position, including those whose true traces become empty.
We restrict the real difference recipe, rather than recovering a
centre rule from an arbitrary terminal geometry witness.

\begin{theorem}[The actual concatenated restricted prefix has the true difference preimage]
\label{hir:sharp-original-curve-restricted-full-prefix-difference}
\uses{hir:sharp-original-curve-literal-difference-open-restriction,hir:sharp-original-curve-defects-stage-isomorphism,mc:tower-isomorphism-restrict-append}
\lean{Hironaka.HironakaSharpActualCurveRecipeOpenRestriction.original_curve_restricted_full_prefix_difference}
\leanok
Let $P,S$ be actual towers whose actual full concatenation is a genuine
original product TEST, and let $U$ be ANY original base open. Construct
the genuine TEST of the actual concatenation
\[
                 (P|_U)(S|_{P^{-1}U})
\]
for the literal original product pulled back to $U$. Its independently
computed whole difference is exactly the inverse image of the actual
whole difference on $PS$ under the endpoint open inclusion. Both
original input records and all ordered member positions are the actual
ones. No TEST or difference identity of that concatenation is supplied.
\end{theorem}
\begin{proof}
The original open-input producer gives the actual closed smooth curve,
ordered SNC family, whole-family density and regularity on $U$.
The actual whole product pullback identity identifies the restricted
initial record in all four fields. Genuine TEST restriction therefore
gives the TEST of $(PS)|_U$.

The actual restriction-of-concatenation theorem constructs a stagewise
isomorphism from $(PS)|_U$ to $(P|_U)(S|_{P^{-1}U})$. Its endpoint map
is the genuine opens-congruence map induced by equality of the two
actual open preimages, and its underlying map is the identity on the
ambient endpoint points. The true coherent identity pullback and
actual tower TEST transport give the concatenated restricted TEST.
Actual difference naturality under this stagewise isomorphism and the
independently proved original difference open-restriction theorem give
the desired whole preimage identity. Surjectivity of the genuine
opens-congruence map supplies the reverse set direction. No replacement
ideal or difference certificate is used.
\end{proof}

\begin{theorem}[Every actual literal difference recipe restricts with all its positions]
\label{hir:sharp-original-curve-actual-difference-recipe-open-restriction}
\uses{hir:sharp-original-curve-restricted-full-prefix-difference,hir:sharp-original-curve-literal-ambient-difference-history-order-bound,hir:geo-transform-basic}
\lean{Hironaka.HironakaSharpActualCurveRecipeOpenRestriction.original_curve_difference_recipe_restrict}
\leanok
Let $P$ be any genuine original product TEST and $S$ an actual literal
difference recipe on it. For EVERY original base open $U$, the real
restricted tail $S|_{P^{-1}U}$ is the actual literal difference recipe
on the actual prefix $P|_U$ for the true pulled-back original data.
Its length is EXACTLY the original length of $S$. Centres whose traces
are empty remain actual successors.
\end{theorem}
\begin{proof}
Induct on the actual tail constructors. The reflexive tail has the
trivial recipe and length zero. At a successor, the original recipe
supplies the actual shorter recipe and the literal equality of its
next centre with the computed difference of the full shorter prefix.
The genuine recipe TEST producer supplies that full original TEST
before the first theorem is invoked.

Actual tower restriction uses exactly the trace of this real next
centre and the actual restricted blowup map. The first theorem
identifies that centre trace with the independently computed difference
of the concatenated restricted shorter prefix. Together with the
induction hypothesis this is precisely the successor recipe condition.
The existing restriction length theorem retains every actual successor,
including an empty trace; it proves the exact length equality.
\end{proof}

\begin{theorem}[Actual terminal recipes stay terminal on every true base open]
\label{hir:sharp-original-curve-terminal-difference-recipe-open-restriction}
\uses{hir:sharp-original-curve-actual-difference-recipe-open-restriction,hir:sharp-original-curve-restricted-full-prefix-difference}
\lean{Hironaka.HironakaSharpActualCurveRecipeOpenRestriction.original_curve_terminal_difference_recipe_restrict}
\leanok
Under the preceding original inputs, suppose the ACTUAL difference at
$PS$ is empty. On every original base open, construct the genuine
restricted literal recipe, its original TEST and its independently
computed empty endpoint difference, with all actual positions retained.
No restricted endpoint or terminality witness is supplied.
\end{theorem}
\begin{proof}
The actual recipe theorem supplies the full original TEST. Apply the
first theorem to obtain the true restricted concatenated TEST and its
whole difference preimage identity, and the second theorem to obtain
the actual restricted recipe with exact length. The preimage of the
given computed empty difference is empty. This proves actual restricted
terminality for the same towers, maps and original ordered family.
Comparisons on overlaps and their cocycles still require the genuine
retained local two-phase recipes; no arbitrary existential endpoint is
identified with such a recipe here.
\end{proof}
