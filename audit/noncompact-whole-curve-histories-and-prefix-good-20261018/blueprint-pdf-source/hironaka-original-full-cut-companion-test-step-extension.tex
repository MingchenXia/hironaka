\section{A genuine companion TEST after a full-value-cut preparation step}

A canonical prefix has a true order-run companion TEST. A further original
admissible blowup need not extend canonicality. The geometric condition below
is retained explicitly: the ENTIRE next centre lies above the chosen old
full reference value. It is not replaced by a pointwise condition at one
centre point, and no candidate TEST is supplied.

\begin{theorem}[A genuine upper-cut centre extends the old run-compAt TEST]
\label{hir:original-upper-cut-next-companion-actual-test}
\uses{bcalc:nonmonomial-order-tail,mc:restrict-tower,bcalc:companion-domain,bcalc:inv-domain-stable}
\lean{Hironaka.HironakaOriginalFullCutCompanionTestStep.compAt_test_step_of_upper_cut}
\leanok
Let $M$ have genuine DOMAIN$b$ in positive ambient dimension. Let $F$ be an
honest ordered original value function whose order dominates nonmonomial
order. Take an actual original TEST $T$ that is CAN for $F$, and a point $y$
of its actual current cosupport with attained positive order $q$. Compute
its original order run $r$, head $H$, tail $S$ and true order open $W$.
Let $C$ be a genuine original admissible centre at the current stage and let
$\pi$ be an actual blowup of $C$. Assume the geometric whole-centre condition
$F(T,y)\le F(T,c)$ for EVERY $c\in C$. Then construct a genuine TEST of the
SAME original compAt formed at $H$, along the literal restriction to $W$ of
the old tail followed by this actual blowup. No CAN assertion for the new
upper prefix and no companion TEST hypothesis are required.
\end{theorem}
\begin{proof}
The old canonical-prefix theorem constructs its genuine restricted order-run
companion TEST, retaining every actual original and empty position. Split
the genuine upper TEST into its real head and tail. Original domain
inheritance constructs both current domains; the true order open gives the
initial bound by $q$. Original admissibility of $C$ extends the genuine upper
TEST, hence its restriction supplies a true smooth trace centre, containment
in the actual restricted upper cosupport, and NC with its whole current
ordered boundary.

For every point of that trace centre, order dominance applied to the old
reference point and the whole-centre upper-cut inequality gives current
nonmonomial order at least $q$. The genuine companion cosupport dictionary
on the independently constructed old companion TEST is the intersection of
that order superlevel and the actual restricted upper cosupport. The actual
whole controlled open dictionary identifies these upper transforms with the
literal open pullbacks, proving trace-centre containment in the actual
companion cosupport. Its whole ordered boundary is the same transformed
ordered boundary as the restricted upper record, so the true old NC condition
also holds for the companion. Together with the actual smooth trace centre
this is genuine companion admissibility. Append the actual restricted
blowup to its real old companion TEST. No maximum or canonicality of the new
upper centre was used; the whole-centre cut condition was used explicitly.
\end{proof}

\begin{theorem}[The unchanged original full value internally supplies order dominance]
\label{hir:original-full-value-cut-next-companion-test-domain}
\uses{hir:original-upper-cut-next-companion-actual-test,hir:canonical-centres,bcalc:inv-domain-stable}
\lean{Hironaka.HironakaOriginalFullCutCompanionTestStep.original_full_value_cut_compAt_test}
\leanok
Specialize to the unchanged constructed original full GENERAL value at depth
$k+1$, an original DOMAIN$k+1$ record and its actual CAN TEST prefix. Given
ONLY a genuine next original admissible centre, its actual blowup and the
same ENTIRE original full-value-cut condition, construct the old run-compAt
actual extended TEST and its genuine current DOMAIN$k+1$ after that step.
No caller order-dominance or candidate-domain/TEST certificate is supplied.
\end{theorem}
\begin{proof}
The unchanged original full value is lexicographically $(\nu,\ldots)$.
Its genuine order-dominance proof is therefore internal: comparison of two
actual full values implies comparison of their actual first entries.
Apply the preceding theorem to this exact original full function and the
stated original geometric centre. Initial compAt domain follows from the
actual positive companion construction at the genuine head domain. Genuine
TEST inheritance along the newly proved extended masked TEST gives its
entire current domain, including actual smooth carrier, coherent nonzero
ideal, ordered SNC, transversality, dimension bound and positive mark. This
is a real domain/TEST construction after a possibly noncanonical step.
\end{proof}

\begin{theorem}[Both directions of the old-order cosupport survive the actual preparation step]
\label{hir:original-full-value-cut-next-companion-whole-cosupport}
\uses{hir:original-full-value-cut-next-companion-test-domain,hir:general-step}
\lean{Hironaka.HironakaOriginalFullCutCompanionTestStep.original_full_value_cut_compAt_next_cosupport}
\leanok
For exactly the preceding original data, at EVERY actual point of the new
masked endpoint, membership in the SAME old compAt current cosupport is
equivalent to membership in the actual new upper original cosupport AND
nonmonomial order equal to the OLD attained reference order $q$. The new
upper prefix is not assumed CAN, and the order is not silently recomputed
from a different reference point or rebased history.
\end{theorem}
\begin{proof}
First construct the genuine extended companion TEST by the preceding
original-only value producer. Original admissibility independently gives
the upper next TEST and the actual old-head plus extended-tail TEST. Apply
the genuine whole compAt cosupport theorem to those exact two TEST histories
and the true original order mask. Its initial actual order bound and the
proved companion TEST supply both inclusions and the exact order equality.
Finally use the literal old head/tail controlled-transform equation to
identify the upper endpoint with the actual new original prefix. No desired
cosupport equality is an assumption. Supplying the whole-centre cut condition
from a concrete preparation-centre producer remains a subsequent obligation;
these assertions do not close arbitrary noncanonical GENERAL naturality,
transformed semicoherence or a global scheduler.
\end{proof}
