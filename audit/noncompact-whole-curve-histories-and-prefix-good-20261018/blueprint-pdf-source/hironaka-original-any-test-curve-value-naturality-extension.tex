\section{Genuine full original curve-value locality on arbitrary original tests}

The open and isomorphism functoriality in
\cite[Theorem~1.3 and Section~5]{bierstone-milman08-functoriality} must be
applied to the ORIGINAL history after preparation, not silently replaced
by a canonical history. In carrier dimension at most one the actual full
formula now gives genuine value locality at EVERY positive recursive
depth on ANY original test. This uses actual original order and monomial
geometry, rather than the canonical-only full-value interface.

\begin{theorem}[ONLY original curve ANY-test data give exact full-value open restriction at every recursive depth]
\label{hir:original-any-test-curve-full-value-open-naturality}
\uses{hir:original-any-test-curve-entire-full-invariant-formula,hir:open-restriction-tower,bcalc:nonmonomial-order-local,bcalc:nonmonomial-order-monomial-transport}
\lean{Hironaka.HironakaOriginalAnyTestCurveValueNaturality.original_curve_any_test_full_value_restrict}
\leanok
ONLY an original bound-one domain, ANY genuine ORIGINAL test, ANY true
base open and an actual endpoint-open point mapping into the original
current cosupport internally give the SAME restricted original domain
and TEST before exact equality of the unchanged original FULL values
at EVERY positive recursive depth $k+1$. No canonicality, desired value
comparison, replacement history or source-domain certificate is supplied.
\end{theorem}
\begin{proof}
Genuine original open restriction internally gives the bound-one source
domain and the SAME restricted TEST. Actual current whole-record open
equality and real coherent-cosupport pullback give source cosupport
membership. Apply the genuine full original curve formula to both actual
histories at the SAME recursive depth.

The existing true nonmonomial-order open dictionary identifies their
actual first entries, without canonicality. If that entry is positive,
both actual full formulas have the SAME finite companion entry
$\uparrow(0,\top)$ in the actual bound-$k$ value type, so they are equal.
If it is zero, the actual ordered monomial invariant pulls back under
the genuine endpoint open inclusion, using coherence of the actual
current ideal. Whole original record restriction identifies the actual
mark and ENTIRE ordered family before this comparison. Its actual
$\gamma$ values therefore agree, giving equality in the zero branch.
These two actual branches prove the full original value equality.
\end{proof}

\begin{theorem}[ONLY original curve ANY-test data give exact full values on genuine isomorphic and internally transported towers]
\label{hir:original-any-test-curve-full-value-tower-isomorphism}
\uses{hir:original-any-test-curve-entire-full-invariant-formula,hir:tower-isomorphism,bcalc:nonmonomial-order-transport,bcalc:nonmonomial-order-monomial-transport}
\lean{Hironaka.HironakaOriginalAnyTestCurveValueNaturality.original_curve_any_test_full_value_isTowerIso,Hironaka.HironakaOriginalAnyTestCurveValueNaturality.original_curve_any_test_full_value_transport}

and ANY original target TEST internally supply the genuine source

the original domain/ANY original target TEST. It internally uses the
ACTUAL transported tower and ACTUAL back biholomorphism to give this
full equality; no chosen source history or tower comparison is supplied.
\end{theorem}
\begin{proof}
True biholomorphic domain pullback internally supplies the original
bound-one source domain. The genuine tower-isomorphism TEST dictionary
gives its actual source TEST before any value comparison. Whole actual
current-record transport and real coherent-cosupport pullback give the
required source cosupport point. Apply the already proved actual full
curve formula to both histories.

The genuine existing nonmonomial-order tower-isomorphism theorem
identifies their actual first entries. In the positive branch both full
values consequently have the SAME actual finite companion entry
$\uparrow(0,\top)$. In the zero branch, whole current-record transport
first identifies the actual source record with the TRUE endpoint
biholomorphic pullback of the actual target record. Actual target
coherence makes its every member germ holomorphic, so the real ordered
monomial-invariant pullback theorem identifies the actual $\gamma$
values and marks as well. Thus both actual full formulas agree in both
branches, without using any canonical value theorem.

For the final original-only consumer, the genuine geometric transport
constructor supplies the actual source tower, actual back biholomorphism
and genuine tower isomorphism internally, preserving every original map,
centre and empty step. Apply the just-proved theorem to these actual
objects. The result concerns carrier dimension at most one, even though
the recursive depth is arbitrary. Higher-dimensional noncanonical
full-value locality, exceptional or infinitesimal semicoherence and
canonical continuation after arbitrary preparation remain OPEN.
\end{proof}
