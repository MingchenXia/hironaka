\begin{lemma}[Actual finite Hilbert--Samuel prefixes form a descending analytic chain]

For original coherent $A$, let $S_{h,k}=\{y:\forall\ell\leq k,
 h_\ell\leq H_A(y,\ell)\}$. Each is genuinely complex analytic, and
$S_{h,k+1}\subseteq S_{h,k}$ on the entire original manifold.
\end{lemma}
\begin{proof}
Start with the genuine original order-zero superlevel. At the true successor
intersect the preceding prefix with the original order-$k+1$ superlevel.
The existing original coherence producer supplies finite holomorphic rank
minor equations for each intrinsic superlevel. Actual finite intersections
retain a finite holomorphic equation family, hence analyticity. Induction
identifies both membership directions with all original orders through $k$.
Every successor is contained in its preceding factor, proving antitonicity.
\end{proof}

\begin{proof}

This proves the whole literal condition for every $\ell$, on the SAME
neighborhood. No caller stationary-germ, uniform neighborhood or finite

\end{proof}

\begin{theorem}[Every actual compact window has one finite order controlling all original whole conditions]
\label{hir:actual-ambient-hs-whole-superlevel-compact-window-cutoff}
\uses{hir:actual-ambient-hs-whole-prefix-local-stationarity}
\lean{Hironaka.HironakaActualWholeAmbientHSSuperlevel.exists_original_compact_window_whole_ambient_hs_prefix}
\leanok
For every actual compact subset $K$ of the original manifold, there is one
internally constructed order $k$ such that for EVERY $y\in K$,
$y\in S_h$ if and only if $y\in S_{h,k}$. The original ambient manifold
need not be compact.
\end{theorem}
\begin{proof}
The true local-stationarity neighborhoods cover $K$. Its actual compactness
chooses a finite subcover. Take the maximum of their genuine finite orders,
using zero for an empty subcover. Whole membership implies that maximum
prefix. Conversely every point of $K$ lies in some chosen original
neighborhood. The maximum prefix is contained in its neighborhood's own
prefix by actual antitonicity. Its local whole/prefix equivalence therefore
gives whole membership. The same maximum works for every original point
of $K$, including the empty window without an extra premise.
\end{proof}
