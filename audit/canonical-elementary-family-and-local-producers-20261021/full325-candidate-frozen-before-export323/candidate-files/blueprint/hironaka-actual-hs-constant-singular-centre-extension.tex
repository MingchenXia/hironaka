\begin{theorem}[Only original nonsmooth pure geometry produces the actual singular HS maximum and its entire constant locus]

\lean{Hironaka.HironakaActualHSConstantSingularCentre.exists_actual_original_singular_constant_maximal_hs_locus}

$d<n$ which is not a closed submanifold, there is actual $a$ in the
ENTIRE current singular set maximizing the EXISTING intrinsic reduced
all-order HS profile on that set. Its literal whole ambient reference

set, and EVERY actual point of it has the SAME ENTIRE intrinsic HS profile

\end{theorem}
\begin{proof}

closed analytic carrier would be regular of its actual pure dimension,
giving a genuine closed submanifold, contrary to the ORIGINAL nonsmooth
hypothesis. The existing genuine first-HS dictionary makes this ENTIRE

Original Cartan coherence and the preceding compact maximum theorem
therefore internally choose $a$ on this actual compact nonempty singular
set. The existing original order-zero/first-order dictionary places the
ENTIRE all-order reference threshold at $a$ in this SAME current singular
set. Its actual analytic compact geometry is already independently
proved. On that set, the actual maximal-profile theorem proves both
whole threshold/equality directions, so every actual reference-locus
point has the SAME original HS at EVERY order. No HS-constant or
maximal-stratum certificate is an input.
\end{proof}
