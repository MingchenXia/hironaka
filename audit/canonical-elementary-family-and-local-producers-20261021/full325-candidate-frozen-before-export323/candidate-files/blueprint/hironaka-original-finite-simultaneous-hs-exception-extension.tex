\begin{lemma}[A true original-open inclusion transports actual analytic thin exceptions in BOTH centre membership directions]
\label{hir:actual-original-open-inclusion-analytic-thin-exception}
\uses{hir:actual-original-centre-denominator-analytic-thin-window,ana:analytic-preimage}
\source{bierstone-milman97-invent-math:page-0095}
\lean{Hironaka.HironakaOriginalFiniteSimultaneousHSException.actual_open_inclusion_analytic_thin}
\leanok
For actual original opens $D\subset U$, the genuine inclusion sends the
literal centre trace of $D$ to the literal trace in $U$. The actual inverse
image of an analytic exception is analytic. If the exception is genuinely
thin in the centre trace of $U$, its true inverse image is thin in the
centre trace of $D$. No desired transported set equality or thinness
certificate is input.
\end{lemma}
\begin{proof}
The actual inclusion preserves underlying original points, and its true
manifold charts make it holomorphic. Analyticity follows genuine
holomorphic inverse image. For thinness, take an actual open $O$ in $D$
whose whole centre trace lies in the pulled-back exception. Its image in
the ORIGINAL manifold is open, since $D$ is a genuine original open.
The inverse image of that actual open in $U$ is open. EVERY centre point
there comes from an actual point of $O$, by the real underlying-point
image dictionary. The supplied true trace containment therefore places
this entire centre part in the original exception. Its genuine thinness
makes that part empty, so the actual part in $D$ is empty as well.
\end{proof}

\begin{theorem}[ONLY actual original analytic regular-centre geometry and a finite family of coherent original ideals give one strictly smaller analytic exception for ALL their existing intrinsic HS orders]
\label{hir:original-finite-family-simultaneous-all-intrinsic-hs-exception}
\uses{hir:actual-original-open-inclusion-analytic-thin-exception,hir:original-actual-centre-analytic-exception-all-intrinsic-hs,rem:thin-dimension-drop}
\source{bierstone-milman97-invent-math:page-0095}
\lean{Hironaka.HironakaOriginalFiniteSimultaneousHSException.exists_original_finite_simultaneous_intrinsic_hs_exception,Hironaka.HironakaOriginalFiniteSimultaneousHSException.exists_original_finite_analytic_family_simultaneous_hs_exception}
\leanok
ONLY an original analytic centre regular of dimension $d$ at its actual
reference point and a genuine FINITE family of coherent original ideals
internally construct ONE original open $D$ containing that point and ONE
actual analytic subset $E$ of its literal centre trace. This actual $E$
is thin in the trace, EVERY regular exception point has dimension $<d$,
and the reference point lies in the closure of the true complement.
For EVERY family position and EVERY order the EXISTING original intrinsic
HS value is constant on this ENTIRE common complement. There is no caller
window, exception, normal-flatness, rank, HS-constancy or finite-prefix
certificate. The empty family is included. In particular the actual
vanishing ideals of any finite analytic chain supply the coherent-family
inputs internally.
\end{theorem}
\begin{proof}
For EACH actual family position first construct its genuine retained
nonzero-germ denominator and its actual analytic thin exception by the
preceding original-input producer. These windows and profiles are chosen
BEFORE any common exception is specified. The true original regular-centre
flattening also supplies an actual open on which EVERY centre point has
the SAME true dimension $d$. Intersect these FINITELY many genuine opens;
the reference point remains in this real original open. Transport each
actual exception by its genuine inclusion, as in the preceding lemma,
and take their literal finite union.

The finite union is analytic and contained in the true centre trace.
Each actual closed exception is thin there. The proved finite avoidance
lemma gives a nonempty open centre part avoiding ALL of them in every
open part which meets the centre. Thus their literal union is genuinely
thin. Real regularity supplies the whole trace dimension bound, and the
proved thin analytic dimension theorem gives the STRICT dimension drop.
Thinness and actual reference centre membership supply the asserted
closure of the true complement. Outside the literal union EVERY actual
individual denominator exception is avoided, so EACH original all-order
HS profile applies at the SAME underlying original point. This proves
simultaneous constancy for ALL positions and ALL orders, without selecting
an order cutoff. For a genuine finite analytic chain, actual Cartan
coherence of EACH reduced vanishing ideal supplies all family premises;
no transformed-chain comparison is assumed or concluded.
\end{proof}
