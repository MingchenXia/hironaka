\section{Actual target-chart compatibility of the original smooth arrows}

The full original global-target Cartesian square provides a genuine
uniqueness comparison on a common smaller source open. This proves target
chart independence for the internally constructed local arrows, before
any global source map is asserted.

\begin{lemma}[A genuine Cartesian terminal square restricts on its actual source base]
\label{hir:actual-holomorphic-cartesian-tower-source-open-restriction}
\lean{Hironaka.HironakaSmoothSubmersionOriginalTargetChartCompatibility.holomorphicSquarePullback_source_open_restriction}
\leanok
\uses{hir:open-restriction-tower,hir:submersion-contact-restriction-open-charts}
For an actual finite tower $S:E\to Y$, opens $W\subseteq U\subseteq Y$,
and a holomorphically Cartesian square with source $S^{-1}U\to U$, the
literal restriction of that same arrow to $S^{-1}W$ is holomorphically
Cartesian with the same entire target projection and the restricted base map.
\end{lemma}
\begin{proof}
Compose any actual smaller source-base cone with the inclusion $W\to U$.
The larger square supplies its unique holomorphic lift to $S^{-1}U$.
The entire source leg says its original tower projection is the smaller
base map, so it actually lands in $S^{-1}W$. Regard this same lift as a
holomorphic map to the true open subtype $S^{-1}W$. The literal restricted
tower projection formula gives its smaller source leg, while inclusion
into the larger final open retains the same target leg. Any smaller
candidate composed with that actual inclusion is a larger candidate,
using the same restricted projection formula. Larger uniqueness and
actual subtype injectivity identify the smaller candidates. No smaller
lift, domain membership, or restricted universal property is assumed.
\end{proof}

\begin{theorem}[All actual target charts give the same original smooth arrow on their true intersection]
\label{hir:original-local-smooth-global-arrow-target-chart-compatibility}
\lean{Hironaka.HironakaSmoothSubmersionOriginalTargetChartCompatibility.originalLocalTerminalSmoothGlobalArrow_target_compatibility}
\leanok
\source{bierstone-milman08-functoriality,wlodarczyk05-hironaka}
\uses{hir:actual-holomorphic-cartesian-tower-source-open-restriction,hir:original-local-smooth-arrow-actual-global-target-cartesian,hir:smooth-terminal-whole-pullback-map-intrinsic-uniqueness}
For only original marked-domain input and a genuine smooth map, fix any
actual original source local tower and any two actual original target
atlas indices. On the literal source tower preimage of both target base
opens, the two internally produced arrows into the same original global
target terminal manifold are equal as entire maps. No target comparison
or compatibility witness is a caller input.
\end{theorem}
\begin{proof}
Intersect the two actual nested source opens. Each true global-target
square of the preceding producer restricts to this same smaller source
open by the lemma. The two restricted original base maps are literally
the same $f$ composed with the same source inclusions. Their entire
original projection equations also agree, by the actual restricted tower
projection formula. Both squares therefore have the same actual finite
source tower restricted to the intersection and the same original global
target projection. Intrinsic finite-source Cartesian-map uniqueness
identifies the two entire restricted maps. That uniqueness uses genuine
actual tower geometry; neither the sought compatibility nor an independent
target transition certificate is assumed.
\end{proof}
