\section{Actual positive companions on a discrete original preparation step}

A discrete preparation centre supplies genuine singleton trace windows.
Intersect such a window with the actual nonmonomial-order mask, BEFORE
forming the positive companion. This produces a real local companion
test step even when the given ORIGINAL prefix and the next centre are
not canonical. The companion is formed from the actual CURRENT original
record; no claim that its lower history equals the earlier frozen full
original history is made. This is the local positive-order reduction in
\cite[Step II.B]{bierstone-milman08-functoriality}, used on the actual test
transformations discussed at printed page 222 of
\cite{bierstone-milman97-invent-math}.

\begin{theorem}[ONLY actual discrete admissibility and positive point order construct a true companion window]
\label{hir:original-discrete-positive-actual-companion-window}
\source{bierstone-milman97-invent-math:page-0016}
\uses{bcalc:nonmonomial-order-local,bcalc:companion-domain,hir:companion-basic,hir:companion-reduction-along}
\lean{Hironaka.HironakaOriginalDiscretePositiveCompanion.exists_discrete_positive_companion_window}
\leanok
Let an original marked ideal lie in a genuine invariant domain, let $C$
be an actual discrete admissible centre, and let $c\in C$ have positive
ACTUAL nonmonomial order $q$. These original inputs internally construct
an actual open $U\ni c$ with $U\cap C=\{c\}$ and order at most $q$ on
its original cosupport. For the actual restriction $J=M|_U$, its genuine
companion $O=\mathcal O(J,q)$ is in the same domain, is of maximal order,
and the literal trace of $C$ is an admissible centre for THIS actual
companion. No window, bound, companion domain or admissibility certificate
is supplied.
\end{theorem}
\begin{proof}
Actual discreteness supplies an ambient open whose centre trace is the
singleton $c$. Original domain nonzero geometry makes the point order
finite. The actual order-$q+1$ superlevel is closed and does not contain
$c$, because $q$ is its actual order. Intersect the singleton window with
its genuine open complement. The resulting $U$ still contains $c$ and
has the same singleton trace; by construction no point of $U$ has order
at least $q+1$. Thus the true original cosupport order is bounded by $q$.

Actual restriction inherits the original domain. The real open
nonmonomial-order dictionary transfers the proved bound to $J$. Genuine
positive-companion coherence/nonzero/mark geometry gives its domain;
the proved bound gives maximal order. Restrict actual original centre
admissibility to $U$. Every point of this centre trace equals $c$ in the
original ambient space, so its real order is exactly $q$. Genuine open
order and cosupport dictionaries therefore place it in
$\{\operatorname{ord}\mathcal N(J)\ge q\}\cap\operatorname{cosupp}J$.
The true companion reduction at length zero identifies this with
$\operatorname{cosupp}O$. The trace remains closed smooth and its actual
normal crossings hold for the SAME ordered boundary, which the companion
retains. These are all genuine companion admissibility conditions.
\end{proof}

\begin{theorem}[The SAME actual restricted blowup is a companion test step with the full actual current order-level dictionary]
\label{hir:original-discrete-positive-same-blowup-companion-test}
\source{bierstone-milman97-invent-math:page-0016}
\uses{hir:original-discrete-positive-actual-companion-window,hir:nonmonomial-transform,hir:companion-reduction-along,bcalc:nonmonomial-order-tail}
\lean{Hironaka.HironakaOriginalDiscretePositiveCompanion.exists_discrete_positive_same_blowup_companion_test}
\leanok
For ANY actual blowup of that same original discrete centre, the preceding
original-only inputs internally construct such a $U$ and its literal
preimage open $V$. The actual restricted map $\rho:V\to U$ is a genuine
blowup of the literal centre trace and a true one-step test history of
$O$. Its transformed companion cosupport is EXACTLY the intersection of
the SAME transformed original restriction cosupport and its actual
nonmonomial-order-$q$ superlevel. No selected blowup, companion test or
post-transform threshold comparison is input.
\end{theorem}
\begin{proof}
Use the preceding actual window and companion admissibility. True
restriction of the given actual blowup gives its literal map on the real
preimage open and its actual blowup property. Append the real trace and
map to the reflexive companion history, using the already proved actual
companion admissibility. The original bound permits the genuine
nonmonomial-part transform theorem and true companion reduction on THIS
actual one-step history. These independently supply the real transformed
original test history, common carrier, transformed nonmonomial-marked
numerator coherence, its inclusion in the current intrinsic nonmonomial
ideal and the reverse restricted span.

On that SAME current carrier the two true inclusions give BOTH relative
order-$q$ cosupport directions. The mark remains $q$. Thus the actual
transformed old-nonmonomial marked ideal cosupport is exactly the actual
current original nonmonomial-order-$q$ superlevel. Substitute into the
proved whole companion cosupport reduction, which intersects it with the
true transformed original cosupport. Every point is in the actual
preimage open, so no inverse or pullback is evaluated outside its true
domain. Empty centre positions and all ordered members are retained.
\end{proof}

\begin{theorem}[ANY ORIGINAL test prefix internally supplies its actual positive preparation companion step]
\label{hir:original-noncanonical-prefix-discrete-positive-companion-step}
\source{bierstone-milman97-invent-math:page-0016}
\uses{hir:original-discrete-positive-same-blowup-companion-test,hir:original-general-composite-residual-first-entry-thresholds}
\lean{Hironaka.HironakaOriginalDiscretePositiveCompanion.original_test_prefix_discrete_positive_companion_step}
\leanok
ONLY original invariant-domain data, ANY genuine ORIGINAL test prefix,
a real discrete admissible next centre, a point in it of positive actual
current order and ANY actual next blowup internally give the preceding
real window, maximal-order domain companion and SAME-map test/threshold
dictionary. The original prefix and next step need not be canonical.
No current domain or companion-history certificate is supplied.
\end{theorem}
\begin{proof}
True original test-domain inheritance internally constructs the current
original domain on the unchanged current carrier, numerator and ordered
exceptional list. Apply the preceding theorem to precisely that actual
record and precisely the given next centre and map. Its window and
companion are therefore internally produced from the SAME original
prefix. No original invariant is restarted or identified with a current
reflexive invariant. This supplies the genuine local positive companion
test geometry only. Comparing its lower history with an earlier frozen
original full-history value, the zero-order monomial branch, full
noncanonical recursive presentation equivalence, exceptional/infinitesimal
semicoherence and termination remain separate obligations.
\end{proof}
