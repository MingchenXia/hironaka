and original admissibility restrict to the SAME true current records.

record, whose real coherence/nonzero domain is supplied independently.

and nonmonomial-order/open equalities transport the result back to the
SAME unrestricted new point. Off the centre the genuine blowup-complement
order theorem gives equality directly, and actual cosupport transport gives
old membership. Thus no global constant order or canonicality is assumed.
\end{proof}
