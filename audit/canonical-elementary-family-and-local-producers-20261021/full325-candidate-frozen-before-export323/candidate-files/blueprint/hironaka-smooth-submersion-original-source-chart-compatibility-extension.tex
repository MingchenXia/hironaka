\section{The actual source chart comparisons satisfy the original gluing relation}

The genuine entire source-chart Cartesian squares can be compared after
real original base and final-space biholomorphisms. Actual original overlap
comparisons supply those biholomorphisms and their whole projections
internally, so the source gluing condition is a theorem rather than data.

\begin{lemma}[Genuine source-base and final biholomorphisms transport an actual Cartesian square]
\label{hir:actual-cartesian-square-source-base-biholomorphic-transport}
\lean{Hironaka.HironakaSmoothSubmersionOriginalSourceChartCompatibility.holomorphicSquarePullback_source_biholomorphism}
\leanok
A holomorphic Cartesian square remains Cartesian under biholomorphisms of
its source base and source final manifold which commute with the whole
source projection and identify the two entire base maps.
\end{lemma}
\begin{proof}
Compose a cone on the new source base with the true source-base
biholomorphism. Its whole base-map equality gives a cone for the original
square, whose unique holomorphic lift exists by the actual universal
property. Compose that lift with the inverse source-final
biholomorphism. The whole source projection equation and source-base
injectivity give the new source leg; the final inverse equation gives
the target leg. Every new candidate composed with the source-final
biholomorphism is an original candidate. Original uniqueness and actual
biholomorphism injectivity identify the new lifts. Both directions are
holomorphic because these are genuine biholomorphisms.
\end{proof}

\begin{theorem}[Entire original source-chart smooth maps obey their actual terminal transition]
\label{hir:original-entire-source-terminal-chart-smooth-map-overlap-compatibility}
\lean{Hironaka.HironakaSmoothSubmersionOriginalSourceChartCompatibility.originalSourceChartSmoothMap_overlap}
\leanok
\source{bierstone-milman08-functoriality,wlodarczyk05-hironaka}
\uses{hir:actual-cartesian-square-source-base-biholomorphic-transport,hir:original-entire-source-terminal-chart-global-target-cartesian,hir:original-independent-local-terminal-overlap-unique-comparison,hir:smooth-terminal-whole-pullback-map-intrinsic-uniqueness}
For only original marked-domain input and a genuine smooth map, the entire
internally produced source-chart comparisons into the same original global
target agree through every actual original source terminal overlap
transition. No source transition or gluing compatibility is a caller input.
\end{theorem}
\begin{proof}
Restrict the two genuine entire source-chart squares to their actual common
original source base open. The literal source-open restriction construction
retains each whole Cartesian law: a larger lift's source leg places it in
the smaller true final preimage, and actual subtype inclusion transfers
both existence and uniqueness. The two nested common bases are genuinely
biholomorphic by their actual original common-open identification. Original
canonical terminal comparison constructs the actual final
biholomorphism, with its entire original projection identity. This is
exactly a commuting pair of true source-base and final biholomorphisms;
both restricted base maps have the same underlying original $f$.

The preceding lemma therefore transports the second restricted Cartesian
square onto the first actual restricted source tower. Both arrows now
have that same finite source tower, the same original global target
projection, the same restricted original base map, and their genuine
whole projection identities. Intrinsic finite-source Cartesian-map
uniqueness identifies them. At an actual original overlap point, the
original transition's true common-open point dictionary identifies its
value with the constructed final comparison. Thus the entire equality
is exactly the original source transition gluing relation.
\end{proof}
