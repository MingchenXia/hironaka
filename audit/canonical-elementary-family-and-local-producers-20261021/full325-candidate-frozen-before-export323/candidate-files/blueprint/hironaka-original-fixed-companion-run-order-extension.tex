The ambient dimension is positive. The original ideal may have ANY carrier

\begin{theorem}[The genuine fixed-mask geometry bounds the actual query run]
\label{hir:original-fixed-order-mask-query-run-bound}
\uses{hir:original-finite-order-cut-current-companion-tests,bcalc:nonmonomial-order-regime,hir:tower-split}
\lean{Hironaka.HironakaOriginalFixedCompanionRunOrder.order_cut_fixed_mask_run}
\leanok
At any genuine upper current cosupport point z whose actual tail projection
lies in W and whose actual current order is at least q, the original order
is exactly q and the actual q-order run of z is at least the actual q-order
run of the fixed reference p. No companion TEST, run inequality or canonical
segment is supplied as a certificate.
\end{theorem}
\begin{proof}
The literal original order-cut history internally supplies its genuine upper
TEST and the genuine companion TEST on the computed fixed run's actual
restricted tail. On W the actual original order mask excludes order q+1.
The existing genuine regime theorem applies to exactly this head, mask and
tail. Its inputs are actual upper and companion TESTs, actual query
cosupport and mask membership, and the ordinary lower bound q on the query
order; it has no canonicality premise. It gives the actual q-regime and a
run at least the true tail length. The whole head-append-tail identity
identifies its original history with the SAME input history. The genuine
run is at most the true tower length, so the exact tail-length formula
identifies that length with the fixed reference's computed run. This
proves the stated actual run inequality and exact order.
\end{proof}

\begin{theorem}[Actual fixed companion cosupport internally supplies every query hypothesis before run comparison]
\label{hir:original-fixed-companion-cosupport-query-run-bound}
\uses{hir:original-fixed-order-mask-query-run-bound,hir:original-finite-order-cut-current-companion-tests,hir:general-compare}
\lean{Hironaka.HironakaOriginalFixedCompanionRunOrder.order_cut_fixed_companion_point_run}
\leanok
For EVERY actual point of the genuine controlled fixed companion's current
cosupport, its underlying original endpoint lies in the actual upper q-order
regime and its actual q-order run is at least that of the fixed reference.
Neither upper membership, exact query order, old-mask membership, companion
TEST nor desired run inequality is a caller hypothesis.
\end{theorem}
\begin{proof}
Construct the original upper TEST and its true head and tail TESTs from the
order-cut recipe. Internally construct the actual companion restricted-tail
TEST by the genuine original companion producer. Its whole controlled
cosupport dictionary identifies the queried actual companion point with
upper current cosupport and exact original order q. The actual subtype point
already has the genuine old-mask tail-projection membership. Thus all the
query hypotheses of the preceding theorem are supplied by geometry before
its run comparison is used. Apply that theorem to the SAME history,
reference and underlying endpoint. This supplies the run ordering needed
for genuine earlier/later middle-history construction; it does not assert
membership of arbitrary upper centre points in the old mask, extend an
old companion cut to a larger later mask, supply a noncanonical FULL
companion-cut history, or conclude next CAN or driver termination.
\end{proof}
