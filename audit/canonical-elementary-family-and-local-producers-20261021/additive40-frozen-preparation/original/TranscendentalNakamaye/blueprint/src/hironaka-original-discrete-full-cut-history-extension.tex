\section{An actual relative cleanup of a discrete initial strict full cut}

The whole original cosupport may be connected, positive-dimensional and
noncompact. The only discrete set is its literal INITIAL strict full-value
upper cut. All local histories, cut compactness and termination bounds below
are internally produced. The construction erases that reference cut in the
actual local canonical histories; it does not assert a whole-space canonical
history after parallel blowups.

\begin{theorem}[Original strict-cut refinements internally construct one actual history]
\label{hir:original-discrete-full-cut-actual-history}
\uses{hir:original-discrete-full-cut-global-refinement}
\lean{TranscendentalNakamaye.Pending.HironakaOriginalDiscreteFullCutHistory.exists_discrete_cut_sequence,TranscendentalNakamaye.Pending.HironakaOriginalDiscreteFullCutHistory.CutParallelSteps}
\leanok
Given a proved resolution invariant, an original marked ideal of its domain,
and a reference value whose actual initial strict cut is discrete, there is
an actual global growing blowup sequence. Every recorded prefix is a true
original test tower. Its restrictions on the internally chosen isolating
windows are actual canonical histories for the literal original restricted
records. Every next global centre is the whole parallel union of the
selected maxima constructed in the preceding chapter.
\end{theorem}
\begin{proof}
Take as internal states actual finite towers together with the proved
original testness and all actual restricted canonical histories. The empty
original tower is an initial state. The preceding genuine global refinement
provides the next state, its true global blowup map and the literal equation
for its whole chosen centre. Iterate this internally constructed transition
and retain every actual absolute position, including the empty ones. The
actual step equations construct a genuine growing sequence; the state
fields prove every asserted test and restricted canonical property.
No history or schedule is supplied by the caller.
\end{proof}

\begin{theorem}[Actual compact high-cut counts force local erasure and genuine local finiteness]
\label{hir:original-discrete-full-cut-local-erasure}
\uses{hir:original-discrete-full-cut-actual-history,hir:original-discrete-full-cut-compact-current-high-locus,hir:original-full-cut-canonical-initial-bound,hir:centre-function-seq}
\lean{TranscendentalNakamaye.Pending.HironakaOriginalDiscreteFullCutHistory.exists_discrete_cut_locally_finite_history}
\leanok
The SAME internally constructed sequence locally erases the strict upper
reference cut on each isolating window. Its actual centre images lie in
the original strict cut, are closed and form a locally finite family.
Every original base point has a genuine open window and actual index after
which every whole restricted finite tail is empty.
\end{theorem}
\begin{proof}
Fix an actual original high point and its internal isolating window.
Apply per-sequence canonical local finiteness to the actual restricted
sequence and the compact singleton original point. This supplies a bound
$m$ on its true counts of centres meeting that singleton's inverse image.
If a high point survives at stage $j+1$, the actual canonical step's
nonincrease and true cosupport projection produce a high point at stage $j$.
At every stage with a high point, compactness of the ENTIRE high cut gives
a nonempty selected whole maximum. Its actual initial bound puts it over
the same isolated point. The true next count therefore increments by one.
Induction gives $j\leq\mathrm{count}_j$ whenever a high point survives at
stage $j$. Hence every stage $j\geq m+1$ has empty high cut. Its entire
selected local centre is then empty.

All global centre images lie in the same original closed strict cut.
Outside that cut its open complement misses every image. At an original
high point, its isolating window misses all sufficiently late images by
the just proved whole local trace and empty selected-centre equation.
Thus the actual images are locally finite, with no uniform stopping time.
Each image is closed because its genuine centre is closed and its actual
finite prefix projection is proper. The actual local-finiteness window
producer then gives a genuine avoided open and every whole empty finite
restricted tail of the SAME recorded history.
\end{proof}

\begin{theorem}[Only original full-invariant data supply the actual relative cleanup]
\label{hir:original-canonical-discrete-full-cut-cleanup}
\uses{hir:original-discrete-full-cut-local-erasure,hir:canonical-centres}
\lean{TranscendentalNakamaye.Pending.HironakaOriginalDiscreteFullCutHistory.exists_original_discrete_full_cut_cleanup}
\leanok
For an original marked ideal $M$ of the original dimension-$n$ domain and
an actual reference value in the original full invariant, discreteness of
its literal initial strict cut internally supplies the preceding actual
global locally finite cleanup. No auxiliary ideal, compact original
cosupport, chosen cover, incoming history, local termination witness or
stage-comparison certificate is a premise. Empty cuts and arbitrary
noncompact original low-value regions are included.
\end{theorem}
\begin{proof}
Use the genuinely constructed original canonical resolution invariant in
ambient dimension $n$ and apply the proved relative-history producer to
that SAME original $M$ and reference value. Its actual initial strict cut
is precisely the literal set in the hypothesis. All windows, whole centres,
actual global maps, original test histories, restricted canonical histories,
local reference-cut erasure and genuine locally finite images are outputs
of that producer. Empty initial cuts yield only empty centres throughout.
The whole original cosupport is never replaced by the discrete high cut.
The higher-dimensional joint-profile cleanup needed for unrestricted G3
remains a separate producer; this theorem is its relative dimension-zero
seed and makes no full G3 closure claim.
\end{proof}
