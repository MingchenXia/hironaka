\section{Complete actual exceptional-fibre relations over the original analytic tangent ring}

Write $B=\mathcal O_{\mathbb C^d,0}$, $P=B[z_1,\ldots,z_t]$ and
$R=\mathcal O_{\mathbb C^{d+t},0}$. The ring map below is literal
original tangent pullback on coefficients and actual normal-coordinate
evaluation on variables. For a prescribed normal pivot $j$, put
$e=z_j$ in the actual analytic target ring.

\begin{theorem}[Every actual relative exceptional-fibre relation is generated by whole pivot-free polynomial syzygies]
\label{hir:actual-relative-exceptional-fibre-complete-polynomial-syzygies}
\uses{hir:actual-relative-polynomial-analytic-flatness,hir:actual-flat-quotient-ring-base-change}
\lean{Hironaka.HironakaActualRelativeExceptionalFibreRelations.exists_relative_exceptional_polynomial_syzygies}
\leanok
For any finite index set, let $p_i\in P$ have no pivot variable and
let $A_i\in R$ be actual analytic germs. If the actual whole sum
$\sum_i\operatorname{ev}(p_i)A_i$ belongs to $(e)$, there are finitely
many actual analytic $B_l$ and whole pivot-free $c_{il}\in P$ with
\[
 A_i-\sum_l\operatorname{ev}(c_{il})B_l\in(e),\qquad
 \sum_i p_ic_{il}=0.
\]
Every coefficient of every $c_{il}$ remains an actual original tangent
germ. Every exponent in its actual support has pivot component zero.
No syzygy-generation or completed-relation certificate is a premise.
\end{theorem}
\begin{proof}
Pass the given whole analytic sum to the actual quotient $R/(e)$.
The whole image of $(z_j)$ is exactly $(e)$ by the literal variable
evaluation and genuine image-of-span formula. Entire actual relative
polynomial evaluation is flat by the proved whole Taylor/completion
producer. Genuine flat quotient base change therefore gives flatness
over $P/(z_j)$. This proved flatness and the finite equational
criterion produce finitely many polynomial-quotient syzygies and
actual analytic quotient multipliers expressing all the given $A_i$
classes. The genuine quotient maps are surjective, so choose actual
polynomial representatives and actual analytic representatives for
these finitely many elements.

Set $z_j=0$ in each polynomial representative, retaining every other
normal variable and every entire coefficient in $B$. This is the
literal polynomial algebra retraction through the complementary
variables. It leaves each class modulo $(z_j)$ unchanged, fixes every
given pivot-free $p_i$, and has image supported on exponents whose
pivot component is zero. The sum of each represented quotient syzygy
belonged to the whole ideal $(z_j)$, which this retraction kills.
Applying the genuine ring homomorphism to that entire sum therefore
gives the displayed whole polynomial syzygy, rather than only a
relation in the quotient. Its representatives have unchanged quotient
classes, so the original quotient multiplier equations give exactly
the displayed actual analytic principal-ideal congruences. All finite
families and actual multipliers have been produced from the original
relation; no desired generation data has been assumed.
\end{proof}

These are complete whole relative polynomial exceptional-fibre relations.
Rehomogenization over the actual tangent coefficient ring and actual
normalized analytic syzygy lifting must still be supplied before relative
exceptional regularity or normalized saturation is concluded.
